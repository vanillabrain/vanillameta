# Studio T1 기준 시안

## 구현 범위

개발 모드의 `/_design/studio`에 합성 데이터 전용 시안을 제공한다. 일반 제품 경로의 로그인·소유권·데이터 조회는 그대로 두고, production에서는 시안 route와 lazy import를 제외한다. API 요청·파일 업로드·LLM·저장·게시·복제를 실행하지 않는다. 이를 인증된 실데이터 화면의 검증으로 보고하지 않는다.

StudioDesignPreview는 가상 데이터·상태를 소유하고 StudioShell은 props로 받아 표시한다. T2의 StudioDocumentV1이나 저장 계약을 대신하는 모델이 아니다. 모든 저장/생성/전송 버튼은 비활성으로 표시하고 공유는 ‘미리보기’임을 명시한다. 제목 입력만 local 시안 상태를 바꾼다.

## 네 상태

- 시작: 프롬프트 중심, 파일/기존 데이터는 연결 전 표시, 샘플 시안으로 결과 상태 전환.
- 결과: 숫자+기존 MetricTrend, 시계열·채널별 차트, 데이터·기간·필터 문맥, 우측 AI 패널.
- 설정: 동일 캔버스 옆 선택 블록의 제목·지표·차원·표현·계산 기준. 제목은 시안에서만 변경.
- 공유: 범위·snapshot·기간·미게시 상태를 확인하는 dialog. 실제 링크·게시 완료 알림 없음.

정상/로딩/오류는 ‘상태 시안’ 선택기로 전환한다. 이전 결과를 보존하는 오류 안내의 배치만 확인하며 실제 장애 복구를 통과한 것은 아니다.

## 디자인 결정과 레퍼런스

- Claude Artifacts의 대화+결과물 병치를 참고하되 고정 폭 4열 대신 캔버스와 우측 패널 2영역으로 제한.
- Rill Canvas의 선택 위젯 속성 패널과 기간·지표 문맥을 참고. 개발자 파일 트리·YAML은 노출하지 않음.
- 기존 브랜드 primary `#0f5ab2`와 Pretendard, MUI/ECharts 기반을 유지. MetricTrend SVG를 재사용하며 별도 시각화 라이브러리를 설치하지 않음.
- 중립 배경·가는 테두리·제한된 강조색. 강한 액션은 공유 미리보기 하나. 미연결 버튼은 짙은 회색 채움 대신 옅은 배경·경계로 구분.
- **Studio 국소 크기 예외:** 일반 툴바 버튼32px/12px로 기존 입력32px와 정렬한다. 기존 AnalysisUi28px 토큰은 그대로 유지한다. 모바일 버튼·단일 입력은 최소44px 조작 영역. 페이지/카드 제목과 숫자에는 별도 위계를 둔다.
- 우측 패널320px. 900px 미만에서는 MUI temporary Drawer를 사용하고 결과 상태에서 기본 닫힘. 키보드 trap/Escape·복귀는 기존 MUI 동작을 활용.
- 모바일 네 상태 버튼은 같은 너비 grid, 상태 선택기는 별도 행. 캔버스는 단일열. 긴 블록 제목은 줄바꿈하며 설정 입력의 값은 가로 탐색 가능.

전체 경쟁 UX·픽셀 동등성은 이번 시안의 목표가 아니다. 실제 운영 대시보드에서의 배치 편집, 필터 추가, AI 문맥 전달은 후속 단계다.
