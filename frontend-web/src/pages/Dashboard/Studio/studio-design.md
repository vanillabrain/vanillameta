# Studio T1 기준 시안

## 구현 범위

개발 모드의 `/_design/studio`에 합성 데이터 전용 시안을 제공한다. 일반 제품 경로의 로그인·소유권·데이터 조회는 그대로 두고, production에서는 시안 route와 lazy import를 제외한다. API 요청·파일 업로드·LLM·저장·게시·복제를 실행하지 않는다. 이를 인증된 실데이터 화면의 검증으로 보고하지 않는다.

StudioDesignPreview는 가상 데이터·상태를 소유하고 StudioShell은 props로 받아 표시한다. T2의 StudioDocumentV1이나 저장 계약을 대신하는 모델이 아니다. 모든 저장/생성/전송 버튼은 비활성으로 표시하고 공유는 ‘미리보기’임을 명시한다. 제목 입력만 local 시안 상태를 바꾼다.

## 네 상태

- 시작: 프롬프트 중심, 파일/기존 데이터는 연결 전 표시, 샘플 시안으로 결과 상태 전환.
- 결과: 숫자+기존 MetricTrend, 시계열·채널별 차트, 데이터·기간·필터 문맥, 우측 AI 패널.
- 설정: 동일 캔버스 옆 선택 블록의 제목·지표·차원·표현·계산 기준. 제목은 시안에서만 변경.
- 공유: 범위·snapshot·기간·미게시 상태를 확인하는 dialog. 실제 링크·게시 완료 알림 없음.

정상/로딩/오류는 ‘상태 시안’ 선택기로 전환한다. 이전 결과를 보존하는 오류 안내의 배치만 확인하며 실제 장애 복구를 통과한 것은 아니다.

## 디자인 결정과 레퍼런스

- Claude Artifacts의 대화+결과물 병치를 참고하되 고정 폭 4열 대신 캔버스와 우측 패널 2영역으로 제한.
- Rill Canvas의 선택 위젯 속성 패널과 기간·지표 문맥을 참고. 개발자 파일 트리·YAML은 노출하지 않음.
- 기존 브랜드 primary `#0f5ab2`와 Pretendard, MUI/ECharts 기반을 유지. MetricTrend SVG를 재사용하며 별도 시각화 라이브러리를 설치하지 않음.
- 중립 배경·가는 테두리·제한된 강조색. 강한 액션은 공유 미리보기 하나. 미연결 버튼은 짙은 회색 채움 대신 옅은 배경·경계로 구분.
- **Studio 국소 크기 예외:** 일반 툴바 버튼32px/12px로 기존 입력32px와 정렬한다. 기존 AnalysisUi28px 토큰은 그대로 유지한다. 모바일 버튼·단일 입력은 최소44px 조작 영역. 페이지/카드 제목과 숫자에는 별도 위계를 둔다.
- 우측 패널320px. 900px 미만에서는 MUI temporary Drawer를 사용하고 결과 상태에서 기본 닫힘. 키보드 trap/Escape·복귀는 기존 MUI 동작을 활용.
- 모바일 네 상태 버튼은 같은 너비 grid, 상태 선택기는 별도 행. 캔버스는 단일열. 긴 블록 제목은 줄바꿈하며 설정 입력의 값은 가로 탐색 가능.

전체 경쟁 UX·픽셀 동등성은 이번 시안의 목표가 아니다. 실제 운영 대시보드에서의 배치 편집, 필터 추가, AI 문맥 전달은 후속 단계다.

공식 레퍼런스와 채택/제외 이유: [방향 검토](../../../../../docs/design/prompt-canvas-direction-review-20261015.md).

## T3 로컬 편집 연결

위 T1 상태 시안에 T2 문서·history와 실제 grid 편집을 연결했다. 합성 데이터 전용 DEV 경로는 유지한다. 핸들/설정 선택, drag·resize stop, 순서·크기 preset, 제목/설명·숫자 표시, 추가/복제/삭제·undo/redo가 브라우저 안에서 작동한다. 새로고침하면 초기화되며 서버 저장·AI·게시 연결은 아직 없다.

12/8/1열 배치는 창 폭별로 별도 보존한다. 패널 폭은 ResizeObserver로 측정하되 breakpoint는 창 폭1440/768/390 기준으로 선택해 패널 토글이 배치를 바꾸지 않게 했다. 순서 버튼은 명시적으로 현재 폭의 블록들을 세로 정렬하고 한 번에 undo한다. 기본 numeric5행(296px), chart6행(358px)로 하단 데이터 표 접근을 유지한다. 카드 resize는 충돌을 허용하지 않는다. 애니메이션으로 카드가 순간 겹치지 않게 grid 위치 전환만 제거했다. 다른 제품 화면은 변경하지 않았다.

실제 화면·키보드·디자인 검증과 제한: [T3 기록](../../../../../docs/testing/dashboard-studio.md).

## T4 제품 저장 연결

인증된 `/dashboard/:dashboardId/studio`와 기존 보기 진입을 추가했다. Studio 문서/history에는 SQL/rows를 넣지 않고 owner-only catalog/preview로 실제 기존 renderer를 사용한다. legacy h2 숫자는 compact exact formatter, Studio 차트에는 WidgetViewer.hideHeader를 명시해 빈 제목 공간과 축 잘림을 없앤다. 이 옵션 기본값false로 기존 화면은 유지한다.

저장은 클릭 시에만 실행하고 같은 요청 재시도·명시적인 3방향 충돌 재적용을 제공한다. 모바일 conflict action44px/줄바꿈을 국소 적용했다. 새 블록은 기존 정의 복제만 가능하며 전체 삭제 후에도 baseline 정의로 다시 추가할 수 있다. 생성/AI/게시를 동작하는 것처럼 표시하지 않는다. 실제 검증과 제한은 T4 MD 기록을 참조한다.


## T5 실제 선택 AI 패널

단일 입력·선택 문맥(블록/전체 기간/필터 없음/집계/UTC/요청 모델), 실제 대기·중지, 초안 적용/보호/오류 안내를 기존 Studio 보조 패널에 연결했다. AI SDK useChat와 기존 완성 응답 transport를 재사용하며 가짜 토큰 스트리밍·자동 저장/게시 없음. MUI 유지, 새 의존성 없음. 모바일 outlined 입력 라벨은 shrink로 내용과 분리하고 전송/중지44px, 데스크톱36px. 최종1440/768/390px·키보드·포커스·overflow0/라벨 수치를 MD T5에 기록. 차트 애니메이션 중간 캡처는 최종 수치 디자인 판정에서 제외. 실제 모델은 gpt-6-luna 지정 요청3개이며 Rill139만행 동등성·실기기·VoiceOver 완료를 의미하지 않는다.
