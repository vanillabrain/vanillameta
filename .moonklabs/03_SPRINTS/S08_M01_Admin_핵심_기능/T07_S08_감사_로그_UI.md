## 목표
관리자가 시스템의 감사 로그를 효율적으로 조회하고 분석할 수 있는 직관적인 사용자 인터페이스를 구현합니다.

## 상세 요구사항

### 1. 로그 조회 화면 (테이블 뷰)
- 시간순 정렬된 감사 로그 목록
- 페이지네이션 지원
- 컬럼별 정렬 기능
- 로그 레벨별 색상 구분

### 2. 필터링 (날짜, 사용자, 액션 타입)
- 날짜 범위 선택 (기본 7일)
- 사용자별 필터링
- 액션 타입별 필터링
- 리소스 타입별 필터링
- 로그 레벨별 필터링
- 실시간 검색 기능

### 3. 로그 상세 보기
- 모달 또는 사이드 패널 상세 뷰
- JSON 형태의 상세 정보 표시
- 관련 로그 링크 제공
- 시간대 변환 지원

### 4. 로그 내보내기 (CSV)
- 필터링된 결과 내보내기
- 대용량 데이터 처리
- 다운로드 진행률 표시
- 내보내기 히스토리 관리

// src/components/admin/audit/AuditLogManagement.tsx
export const AuditLogManagement: React.FC = () => {
  const [selectedLog, setSelectedLog] = useState<AuditLog | null>(null);
  const [showDetailModal, setShowDetailModal] = useState(false);
  const [showExportModal, setShowExportModal] = useState(false);
  const [filters, setFilters] = useState<AuditLogFilters>({
    page: 1,
    limit: 20,
    dateFrom: dayjs().subtract(7, 'days').toDate(),
    dateTo: new Date(),
    sortBy: 'createdAt',
    sortOrder: 'DESC',
  });

  const { data: logs, isLoading, refetch } = useQuery({
    queryKey: ['audit-logs', filters],
    queryFn: () => adminApiClient.getAuditLogs(filters),
  });

  const { data: stats } = useQuery({
    queryKey: ['audit-stats', filters.dateFrom, filters.dateTo],
    queryFn: () => adminApiClient.getAuditStats({
      dateFrom: filters.dateFrom,
      dateTo: filters.dateTo,
    }),
  });

  const { data: availableActions } = useQuery({
    queryKey: ['audit-actions'],
    queryFn: () => adminApiClient.getAvailableActions(),
  });

  const { data: availableResourceTypes } = useQuery({
    queryKey: ['audit-resource-types'],
    queryFn: () => adminApiClient.getAvailableResourceTypes(),
  });

  const handleFilterChange = (newFilters: Partial<AuditLogFilters>) => {
    setFilters(prev => ({ ...prev, ...newFilters, page: 1 }));
  };

  const handleLogClick = (log: AuditLog) => {
    setSelectedLog(log);
    setShowDetailModal(true);
  };

  const exportMutation = useMutation({
    mutationFn: (exportParams: ExportAuditLogsDto) =>
      adminApiClient.exportAuditLogs(exportParams),
    onSuccess: (blob, variables) => {
      const url = window.URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = `audit-logs-${dayjs().format('YYYY-MM-DD')}.csv`;
      a.click();
      window.URL.revokeObjectURL(url);
      toast.success('감사 로그가 성공적으로 내보내졌습니다.');
    },
  });

  return (
    <div className="audit-log-management">
      <div className="audit-header">
        <h1>감사 로그</h1>
        <div className="audit-actions">
          <ProtectedComponent permission="admin.audit.export">
            <Button
              icon={<DownloadOutlined />}
              onClick={() => setShowExportModal(true)}
            >
              내보내기
            </Button>
          </ProtectedComponent>
          <Button
            icon={<ReloadOutlined />}
            onClick={() => refetch()}
            loading={isLoading}
          >
            새로고침
          </Button>
        </div>
      </div>

      {stats && <AuditLogStatsCards stats={stats} />}

      <div className="audit-content">
        <AuditLogFilters
          filters={filters}
          onFilterChange={handleFilterChange}
          availableActions={availableActions}
          availableResourceTypes={availableResourceTypes}
        />

        <AuditLogTable
          logs={logs?.data || []}
          loading={isLoading}
          onLogClick={handleLogClick}
        />

        <Pagination
          current={filters.page}
          total={logs?.meta.total || 0}
          pageSize={filters.limit}
          showSizeChanger
          pageSizeOptions={['10', '20', '50', '100']}
          onChange={(page, pageSize) =>
            handleFilterChange({ page, limit: pageSize })
          }
          showQuickJumper
          showTotal={(total, range) =>
            `${range[0]}-${range[1]} of ${total} 로그`
          }
        />
      </div>

      {showDetailModal && selectedLog && (
        <AuditLogDetailModal
          log={selectedLog}
          onClose={() => {
            setShowDetailModal(false);
            setSelectedLog(null);
          }}
        />
      )}

      {showExportModal && (
        <ExportAuditLogsModal
          initialFilters={filters}
          onClose={() => setShowExportModal(false)}
          onExport={(exportParams) => {
            exportMutation.mutate(exportParams);
            setShowExportModal(false);
          }}
          loading={exportMutation.isLoading}
        />
      )}
    </div>
  );
};
```

// src/components/admin/audit/AuditLogFilters.tsx
interface AuditLogFiltersProps {
  filters: AuditLogFilters;
  onFilterChange: (filters: Partial<AuditLogFilters>) => void;
  availableActions?: string[];
  availableResourceTypes?: string[];
}

export const AuditLogFilters: React.FC<AuditLogFiltersProps> = ({
  filters,
  onFilterChange,
  availableActions,
  availableResourceTypes,
}) => {
  const [form] = Form.useForm();
  const [isExpanded, setIsExpanded] = useState(false);

  const presetRanges = {
    '지난 1시간': [dayjs().subtract(1, 'hour'), dayjs()],
    '지난 24시간': [dayjs().subtract(1, 'day'), dayjs()],
    '지난 7일': [dayjs().subtract(7, 'days'), dayjs()],
    '지난 30일': [dayjs().subtract(30, 'days'), dayjs()],
  };

  const handleQuickFilter = (preset: string) => {
    const [from, to] = presetRanges[preset];
    onFilterChange({
      dateFrom: from.toDate(),
      dateTo: to.toDate(),
    });
    form.setFieldsValue({
      dateRange: [from, to],
    });
  };

  const handleFormChange = (changedValues: any, allValues: any) => {
    const newFilters: Partial<AuditLogFilters> = {};

    if (changedValues.dateRange) {
      newFilters.dateFrom = changedValues.dateRange[0]?.toDate();
      newFilters.dateTo = changedValues.dateRange[1]?.toDate();
    }

    if (changedValues.search !== undefined) {
      newFilters.search = changedValues.search;
    }

    if (changedValues.userId !== undefined) {
      newFilters.userId = changedValues.userId;
    }

    if (changedValues.action !== undefined) {
      newFilters.action = changedValues.action;
    }

    if (changedValues.resourceType !== undefined) {
      newFilters.resourceType = changedValues.resourceType;
    }

    if (changedValues.category !== undefined) {
      newFilters.category = changedValues.category;
    }

    if (changedValues.level !== undefined) {
      newFilters.level = changedValues.level;
    }

    onFilterChange(newFilters);
  };

  const clearFilters = () => {
    const defaultFilters = {
      search: undefined,
      userId: undefined,
      action: undefined,
      resourceType: undefined,
      category: undefined,
      level: undefined,
      dateFrom: dayjs().subtract(7, 'days').toDate(),
      dateTo: new Date(),
    };
    
    onFilterChange(defaultFilters);
    form.resetFields();
    form.setFieldsValue({
      dateRange: [dayjs().subtract(7, 'days'), dayjs()],
    });
  };

  return (
    <div className="audit-log-filters">
      <div className="quick-filters">
        <Space>
          <span>빠른 필터:</span>
          {Object.keys(presetRanges).map(preset => (
            <Button
              key={preset}
              size="small"
              type={
                dayjs(filters.dateFrom).isSame(presetRanges[preset][0], 'day') &&
                dayjs(filters.dateTo).isSame(presetRanges[preset][1], 'day')
                  ? 'primary'
                  : 'default'
              }
              onClick={() => handleQuickFilter(preset)}
            >
              {preset}
            </Button>
          ))}
        </Space>
      </div>

      <Form
        form={form}
        layout="inline"
        onValuesChange={handleFormChange}
        className="filter-form"
        initialValues={{
          dateRange: [dayjs(filters.dateFrom), dayjs(filters.dateTo)],
        }}
      >
        <Form.Item name="dateRange" label="기간">
          <RangePicker
            showTime={{ format: 'HH:mm' }}
            format="YYYY-MM-DD HH:mm"
            placeholder={['시작일', '종료일']}
          />
        </Form.Item>

        <Form.Item name="search" label="검색">
          <Input
            placeholder="액션, 사용자명, 상세 내용 검색"
            prefix={<SearchOutlined />}
            allowClear
          />
        </Form.Item>

        <Button
          type="link"
          onClick={() => setIsExpanded(!isExpanded)}
          icon={isExpanded ? <UpOutlined /> : <DownOutlined />}
        >
          {isExpanded ? '접기' : '고급 필터'}
        </Button>
      </Form>

      {isExpanded && (
        <div className="advanced-filters">
          <Form
            form={form}
            layout="inline"
            onValuesChange={handleFormChange}
          >
            <Form.Item name="userId" label="사용자">
              <UserSelect
                placeholder="사용자 선택"
                allowClear
                style={{ width: 200 }}
              />
            </Form.Item>

            <Form.Item name="action" label="액션">
              <Select
                placeholder="액션 선택"
                allowClear
                style={{ width: 200 }}
              >
                {availableActions?.map(action => (
                  <Select.Option key={action} value={action}>
                    {getActionDisplayName(action)}
                  </Select.Option>
                ))}
              </Select>
            </Form.Item>

            <Form.Item name="resourceType" label="리소스 타입">
              <Select
                placeholder="리소스 타입 선택"
                allowClear
                style={{ width: 200 }}
              >
                {availableResourceTypes?.map(type => (
                  <Select.Option key={type} value={type}>
                    {getResourceTypeDisplayName(type)}
                  </Select.Option>
                ))}
              </Select>
            </Form.Item>

            <Form.Item name="category" label="카테고리">
              <Select
                placeholder="카테고리 선택"
                allowClear
                style={{ width: 200 }}
              >
                {Object.values(AuditLogCategory).map(category => (
                  <Select.Option key={category} value={category}>
                    {getCategoryDisplayName(category)}
                  </Select.Option>
                ))}
              </Select>
            </Form.Item>

            <Form.Item name="level" label="레벨">
              <Select
                placeholder="레벨 선택"
                allowClear
                style={{ width: 150 }}
              >
                {Object.values(AuditLogLevel).map(level => (
                  <Select.Option key={level} value={level}>
                    <Tag color={getLevelColor(level)}>{level.toUpperCase()}</Tag>
                  </Select.Option>
                ))}
              </Select>
            </Form.Item>

            <Form.Item>
              <Button onClick={clearFilters}>
                필터 초기화
              </Button>
            </Form.Item>
          </Form>
        </div>
      )}
    </div>
  );
};

                    }
                    description={
                      <div className="related-log-description">
                        {relatedLog.resourceType && (
                          <span>
                            {getResourceTypeDisplayName(relatedLog.resourceType)}
                            {relatedLog.resourceId && `: ${relatedLog.resourceId}`}
                          </span>
                        )}
                      </div>
                    }
                  />
                </List.Item>
              )}
            />
          ) : (
            <Empty description="관련 로그가 없습니다" />
          )}
        </div>
      ),
    },
  ];

  return (
    <Modal
      title={
        <div className="log-modal-title">
          <span>감사 로그 상세</span>
          <Tag color={getLevelColor(log.level)}>
            {log.level.toUpperCase()}
          </Tag>
        </div>
      }
      open={true}
      onCancel={onClose}
      width={800}
      footer={[
        <Button key="close" onClick={onClose}>
          닫기
        </Button>,
      ]}
      className="audit-log-detail-modal"
    >
      <Tabs
        activeKey={activeTab}
        onChange={setActiveTab}
        items={tabItems}
      />
    </Modal>
  );
};
```
