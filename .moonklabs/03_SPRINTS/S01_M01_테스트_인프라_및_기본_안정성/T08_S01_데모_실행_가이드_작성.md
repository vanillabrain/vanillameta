# Task: 데모 실행 가이드 작성

## Description
VanillaMeta를 처음 접하는 사용자나 개발자가 쉽게 데모를 실행하고 주요 기능을 체험할 수 있도록 상세한 데모 실행 가이드를 작성합니다. 환경 구축부터 주요 기능 테스트까지 단계별로 안내하는 문서를 제공합니다.

## Goal / Objectives
- 새로운 사용자가 30분 이내에 데모 환경 구축 가능
- 주요 기능에 대한 실습 가이드 제공
- 문제 해결을 위한 트러블슈팅 가이드 포함
- 개발자 온보딩 과정 표준화

## Acceptance Criteria
- [ ] 환경 구축 단계별 가이드 작성 (로컬/Docker)
- [ ] 주요 기능 데모 시나리오 5개 이상 작성
- [ ] 스크린샷 및 예시 포함한 시각적 가이드
- [ ] 자주 발생하는 문제에 대한 트러블슈팅 섹션
- [ ] 데모 데이터 준비 및 활용 가이드
- [ ] 영어/한국어 버전 문서 제공

## Subtasks
- [ ] 현재 데모 관련 문서 분석 및 정리
- [ ] 환경 구축 가이드 작성 (로컬/Docker)
- [ ] 주요 기능별 데모 시나리오 작성
- [ ] 스크린샷 및 이미지 준비
- [ ] 샘플 데이터 및 설정 파일 준비
- [ ] 트러블슈팅 가이드 작성
- [ ] 문서 검토 및 피드백 반영
- [ ] 다국어 버전 문서 작성

## 기술 가이드

### 문서 구조 및 위치
- **메인 가이드**: `/docs/데모_실행_가이드.md`
- **영문 가이드**: `/docs/DEMO_GUIDE.md`
- **이미지 자료**: `/docs/images/demo/`
- **샘플 데이터**: `/docs/sample-data/`

### 기존 문서 분석
- 현재 README.md 파일의 데모 관련 내용
- 개발자 가이드 문서들
- Docker 실행 가이드
- API 문서 및 사용 예시

### 데모 시나리오 구성
1. **데이터베이스 연결**: MySQL/PostgreSQL 샘플 DB 연결
2. **대시보드 생성**: 기본 템플릿으로 대시보드 만들기
3. **위젯 추가**: 다양한 차트 타입으로 위젯 생성
4. **공유 기능**: 대시보드 공유 링크 생성 및 활용
5. **사용자 관리**: 계정 생성 및 권한 관리

### 문서 작성 표준
- Markdown 형식 활용
- 단계별 번호 매기기
- 코드 블록 및 명령어 강조
- 스크린샷 캡션 및 설명
