# T03_S10: 백업 관리 UI

## 태스크 개요
- **Sprint**: S10 - Admin 운영 기능
- **Priority**: High
- **Estimated Time**: 3일
- **Dependencies**: T01_S10 (백업 시스템 설계), T02_S10 (백업 실행 엔진)

## 목표
관리자가 백업 작업을 관리할 수 있는 사용자 인터페이스를 구현합니다. 백업 스케줄 설정, 수동 백업 실행, 백업 히스토리 조회, 백업 파일 다운로드 기능을 포함합니다.

## 상세 요구사항

### 1. 백업 스케줄 설정
- **스케줄 관리**: cron 표현식으로 백업 스케줄 설정
- **백업 타입 선택**: 전체/증분/부분 백업 선택
- **보존 정책**: 백업 파일 보존 기간 설정
- **알림 설정**: 백업 완료/실패 시 알림 설정

### 2. 수동 백업 실행
- **즉시 백업**: 스케줄과 관계없이 즉시 백업 실행
- **백업 옵션**: 포함할 데이터 선택 (DB, 파일, 설정)
- **실시간 진행률**: 백업 진행 상황 실시간 표시
- **백업 취소**: 진행 중인 백업 작업 취소

### 3. 백업 히스토리 조회
- **백업 목록**: 페이지네이션된 백업 히스토리
- **필터링**: 날짜, 타입, 상태별 필터링
- **상세 정보**: 백업 메타데이터 및 로그 조회
- **검색**: 백업 ID, 설명으로 검색

### 4. 백업 파일 다운로드
- **파일 다운로드**: S3에서 백업 파일 다운로드
- **미리보기**: 백업 내용 미리보기
- **압축 해제**: 온라인에서 압축 파일 내용 확인
- **무결성 검증**: 다운로드 전 파일 무결성 확인

### 3. 수동 백업 실행 UI

```tsx
// ManualBackupTrigger.tsx
import React, { useState } from 'react';
import { Modal, Form, Checkbox, Button, Alert, Progress } from '@/components/ui';
import { useBackupTrigger } from '@/hooks/useBackupTrigger';

interface BackupOptions {
  includeDatabase: boolean;
  includeFiles: boolean;
  includeConfig: boolean;
  includeLogs: boolean;
  specificTables: string[];
  specificDashboards: string[];
}

export const ManualBackupTrigger: React.FC<{
  visible: boolean;
  onClose: () => void;
}> = ({ visible, onClose }) => {
  const [options, setOptions] = useState<BackupOptions>({
    includeDatabase: true,
    includeFiles: true,
    includeConfig: true,
    includeLogs: false,
    specificTables: [],
    specificDashboards: []
  });

  const { 
    triggerBackup, 
    progress, 
    isRunning, 
    error 
  } = useBackupTrigger();

  const handleStartBackup = async () => {
    try {
      await triggerBackup({
        type: 'manual',
        options
      });
    } catch (err) {
      console.error('백업 실행 실패:', err);
    }
  };

  return (
    <Modal
      title="수동 백업 실행"
      visible={visible}
      onCancel={onClose}
      footer={null}
      width={600}
    >
      {!isRunning ? (
        <Form layout="vertical">
          <Alert
            message="백업 옵션을 선택하세요"
            description="필요한 데이터만 선택하여 백업 시간을 단축할 수 있습니다."
            type="info"
            showIcon
            className="mb-4"
          />

          <Form.Item label="백업 대상">
            <div className="space-y-3">
              <Checkbox
                checked={options.includeDatabase}
                onChange={(e) => setOptions({ ...options, includeDatabase: e.target.checked })}
              >
                <div>
                  <div className="font-medium">데이터베이스</div>
                  <div className="text-sm text-gray-500">모든 테이블과 데이터</div>
                </div>
              </Checkbox>

              <Checkbox
                checked={options.includeFiles}
                onChange={(e) => setOptions({ ...options, includeFiles: e.target.checked })}
              >
                <div>
                  <div className="font-medium">업로드 파일</div>
                  <div className="text-sm text-gray-500">사용자가 업로드한 파일들</div>
                </div>
              </Checkbox>

              <Checkbox
                checked={options.includeConfig}
                onChange={(e) => setOptions({ ...options, includeConfig: e.target.checked })}
              >
                <div>
                  <div className="font-medium">시스템 설정</div>
                  <div className="text-sm text-gray-500">대시보드, 위젯, 데이터소스 설정</div>
                </div>
              </Checkbox>

              <Checkbox
                checked={options.includeLogs}
                onChange={(e) => setOptions({ ...options, includeLogs: e.target.checked })}
              >
                <div>
                  <div className="font-medium">로그 파일</div>
                  <div className="text-sm text-gray-500">최근 30일간의 애플리케이션 로그</div>
                </div>
              </Checkbox>
            </div>
          </Form.Item>

          {error && (
            <Alert
              message="백업 실행 오류"
              description={error}
              type="error"
              showIcon
              className="mb-4"
            />
          )}

          <div className="flex justify-end space-x-2">
            <Button onClick={onClose}>
              취소
            </Button>
            <Button 
              type="primary" 
              onClick={handleStartBackup}
              disabled={!Object.values(options).some(Boolean)}
            >
              백업 시작
            </Button>
          </div>
        </Form>
      ) : (
        <BackupProgressDisplay 
          progress={progress} 
          onCancel={() => {
            // 백업 취소 로직
            cancelBackup();
            onClose();
          }}
        />
      )}
    </Modal>
  );
};

// 백업 진행률 표시 컴포넌트
const BackupProgressDisplay: React.FC<{
  progress: BackupProgress;
  onCancel: () => void;

  return (
    <div>
      <div className="mb-4">
        <div className="flex justify-between items-center mb-2">
          <span className="text-sm font-medium">백업 진행률</span>
          <span className="text-sm text-gray-500">{progress.percentage}%</span>
        </div>
        <Progress 
          percent={progress.percentage} 
          status={progress.stage === 'failed' ? 'exception' : 'active'}
        />
      </div>

      <div className="mb-4">
        <div className="text-sm text-gray-600 mb-1">현재 작업</div>
        <div className="text-base">{getStageDescription(progress.stage)}</div>
        <div className="text-sm text-gray-500">{progress.currentTask}</div>
      </div>

      <div className="flex justify-between text-sm text-gray-500 mb-4">
        <span>시작 시간: {formatDateTime(progress.startedAt)}</span>
        {progress.estimatedCompletion && (
          <span>예상 완료: {formatDateTime(progress.estimatedCompletion)}</span>
        )}
      </div>

      {progress.errors.length > 0 && (
        <Alert
          message="경고"
          description={
            <ul className="list-disc list-inside">
              {progress.errors.map((error, index) => (
                <li key={index}>{error}</li>
              ))}
            </ul>
          }
          type="warning"
          showIcon
          className="mb-4"
        />
      )}

      <div className="flex justify-end">
        <Button 
          onClick={onCancel}
          disabled={progress.stage === 'completed' || progress.stage === 'failed'}
        >
          {progress.stage === 'completed' ? '완료' : 
           progress.stage === 'failed' ? '닫기' : '취소'}
        </Button>
      </div>
    </div>
  );
};
```

```tsx
// BackupHistoryTable.tsx
import React, { useState, useEffect } from 'react';
import { Table, Tag, Button, Space, Input, Select, DatePicker, Modal } from '@/components/ui';
import { useBackupHistory } from '@/hooks/useBackupHistory';
import { BackupDetailModal } from './BackupDetailModal';

export const BackupHistoryTable: React.FC = () => {
  const [filters, setFilters] = useState({
    type: '',
    status: '',
    dateRange: null,
    search: ''
  });
  
  const [selectedBackup, setSelectedBackup] = useState(null);
  const [detailModalVisible, setDetailModalVisible] = useState(false);

  const {

    loading, 
    pagination, 
    fetchBackups,
    downloadBackup,
    deleteBackup 
  } = useBackupHistory(filters);

  const columns = [

      key: 'id',
      width: 120,
      render: (id: string) => (
        <Button

            setDetailModalVisible(true);
          }}
        >
          {id.substring(0, 8)}...
        </Button>
      )
    },
    {
      title: '타입',

      key: 'type',
      width: 100,
      render: (type: string) => {
        const colors = {
          full: 'blue',
          incremental: 'green',
          partial: 'orange',
          manual: 'purple'
        };
        return <Tag color={colors[type]}>{getTypeLabel(type)}</Tag>;
      }
    },
    {
      title: '상태',
      dataIndex: 'status',
      key: 'status',
      width: 100,
      render: (status: string) => {
        const colors = {
          completed: 'success',
          running: 'processing',
          failed: 'error',
          pending: 'default'
        };
        return <Tag color={colors[status]}>{getStatusLabel(status)}</Tag>;
      }
    },
    {
      title: '크기',
      dataIndex: 'fileSize',
      key: 'fileSize',
      width: 100,
      render: (size: number) => formatFileSize(size)
    },
    {
      title: '시작 시간',
      dataIndex: 'startedAt',
      key: 'startedAt',
      width: 150,
      render: (date: Date) => formatDateTime(date)
    },
    {
      title: '소요 시간',
      dataIndex: 'duration',
      key: 'duration',
      width: 100,
      render: (_, record) => {
        if (record.startedAt && record.completedAt) {
          const duration = new Date(record.completedAt).getTime() - new Date(record.startedAt).getTime();
          return formatDuration(duration);
        }
        return record.status === 'running' ? '진행 중' : '-';
      }
    },
    {
      title: '작업',
      key: 'actions',
      width: 150,
      render: (_, record) => (
        <Space size="small">
          <Button 
            size="small" 
            onClick={() => downloadBackup(record.id)}
            disabled={record.status !== 'completed'}
          >
            다운로드
          </Button>
          <Button 
            size="small" 
            onClick={() => {
              setSelectedBackup(record);
              setDetailModalVisible(true);
            }}
          >
            상세
          </Button>
          <Button 
            size="small" 
            danger
            onClick={() => handleDeleteBackup(record.id)}
            disabled={record.status === 'running'}
          >
            삭제
          </Button>

      okType: 'danger',
      cancelText: '취소',

          />

            placeholder="백업 타입"

            options={[
              { value: 'full', label: '전체 백업' },
              { value: 'incremental', label: '증분 백업' },
              { value: 'partial', label: '부분 백업' },
              { value: 'manual', label: '수동 백업' }
            ]}
          />
          
          <Select
            placeholder="상태"
            value={filters.status}
            onChange={(status) => setFilters({ ...filters, status })}
            allowClear
            options={[
              { value: 'completed', label: '완료' },
```

```tsx
              ? formatDuration(new Date(backup.completedAt).getTime() - new Date(backup.startedAt).getTime())
              : '-'
            }
          </Descriptions.Item>
          <Descriptions.Item label="생성자">
            {backup.createdBy}
          </Descriptions.Item>
          <Descriptions.Item label="S3 위치">
            <code className="text-xs">{backup.s3Location}</code>
          </Descriptions.Item>
          <Descriptions.Item label="체크섬">
            <code className="text-xs">{backup.checksum}</code>
          </Descriptions.Item>
        </Descriptions>
      )
    },
    {
      key: 'contents',
      label: '백업 내용',
      children: (
        <div>
          {backup.metadata && (
            <div className="space-y-4">
              {backup.metadata.tables && (
                <div>
                  <h4 className="font-medium mb-2">데이터베이스 테이블 ({backup.metadata.tables.length}개)</h4>
                  <div className="flex flex-wrap gap-1">
                    {backup.metadata.tables.map(table => (
                      <Tag key={table}>{table}</Tag>
                    ))}
                  </div>
                </div>
              )}
              
              {backup.metadata.fileCount && (
                <div>
                  <h4 className="font-medium mb-2">파일</h4>
                  <p>{backup.metadata.fileCount}개 파일</p>
                </div>
              )}
              
              {backup.metadata.compressionRatio && (
                <div>
                  <h4 className="font-medium mb-2">압축률</h4>
                  <Progress 
                    percent={Math.round((1 - backup.metadata.compressionRatio) * 100)} 
                    format={() => `${Math.round(backup.metadata.compressionRatio * 100)}% 압축`}
                  />
                </div>
              )}
            </div>
          )}
        </div>
      )
    },
    {
      key: 'logs',
      label: '로그',
      children: (
        <div className="max-h-96 overflow-y-auto">
          <pre className="text-xs bg-gray-50 p-4 rounded">
            {backup.logs || '로그가 없습니다.'}
          </pre>
        </div>
      )
    }
  ];

  return (
    <Modal
      title={`백업 상세 정보 - ${backup.id}`}
      visible={visible}
      onCancel={onClose}
      footer={null}
      width={800}
    >
      <Tabs items={items} />
    </Modal>
  );
};
```

```typescript
import { useState, useEffect } from 'react';
import { backupService } from '@/services/backupService';

export const useBackupHistory = (filters: BackupFilters) => {
  const [backups, setBackups] = useState<BackupMetadata[]>([]);
  const [loading, setLoading] = useState(false);
  const [pagination, setPagination] = useState({
    current: 1,
    pageSize: 10,
    total: 0
  });

  useEffect(() => {
    fetchBackups();
  }, [filters, pagination.current, pagination.pageSize]);

  const fetchBackups = async () => {
    setLoading(true);
    try {
      const response = await backupService.getBackupHistory({
        ...filters,
        page: pagination.current,
        limit: pagination.pageSize
      });
      
      setBackups(response.data);
      setPagination(prev => ({
        ...prev,
        total: response.total
      }));
    } catch (error) {
      console.error('백업 히스토리 조회 실패:', error);
    } finally {
      setLoading(false);
    }
  };

  const downloadBackup = async (backupId: string) => {
    try {
      const downloadUrl = await backupService.getDownloadUrl(backupId);
      window.open(downloadUrl, '_blank');
    } catch (error) {
      console.error('백업 다운로드 실패:', error);
    }
  };

  const deleteBackup = async (backupId: string) => {
    try {
      await backupService.deleteBackup(backupId);
      fetchBackups(); // 목록 새로고침
    } catch (error) {
      console.error('백업 삭제 실패:', error);
    }
  };

  return {
    backups,
    loading,
    pagination,
    fetchBackups,
    downloadBackup,
    deleteBackup
  };
};
```

### 2. useBackupTrigger 훅

```typescript
// hooks/useBackupTrigger.ts
import { useState, useEffect } from 'react';
import { backupService } from '@/services/backupService';
import { useWebSocket } from '@/hooks/useWebSocket';

export const useBackupTrigger = () => {
  const [isRunning, setIsRunning] = useState(false);
  const [progress, setProgress] = useState<BackupProgress | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [currentBackupId, setCurrentBackupId] = useState<string | null>(null);

  // WebSocket으로 실시간 진행률 수신
  const { subscribe, unsubscribe } = useWebSocket();

  useEffect(() => {
    if (currentBackupId) {
      const handleProgress = (data: BackupProgress) => {
        if (data.backupId === currentBackupId) {
          setProgress(data);
          
          if (data.stage === 'completed' || data.stage === 'failed') {
            setIsRunning(false);
            setCurrentBackupId(null);
          }
        }
      };

      subscribe('backup-progress', handleProgress);
      
      return () => {
        unsubscribe('backup-progress', handleProgress);
      };
    }
  }, [currentBackupId, subscribe, unsubscribe]);

  const triggerBackup = async (request: BackupTriggerRequest) => {
    setError(null);
    setIsRunning(true);
    
    try {
      const response = await backupService.triggerBackup(request);
      setCurrentBackupId(response.backupId);
      
      setProgress({
        backupId: response.backupId,
        stage: 'initializing',
        percentage: 0,
        startedAt: new Date(),
        estimatedCompletion: null,
        currentTask: '백업 초기화 중...',
        errors: []
      });
    } catch (err) {
      setError(err.message);
      setIsRunning(false);
    }
  };

  const cancelBackup = async () => {
    if (currentBackupId) {
      try {
        await backupService.cancelBackup(currentBackupId);
        setIsRunning(false);
        setCurrentBackupId(null);
        setProgress(null);
      } catch (err) {
        setError(err.message);
      }
    }
  };

  return {
    triggerBackup,
    cancelBackup,
    isRunning,
    progress,
    error
  };
};
```
