# T06_S10: 로그 분석 도구

## 태스크 개요
- **Sprint**: S10 - Admin 운영 기능
- **Priority**: High
- **Estimated Time**: 4일
- **Dependencies**: T05_S10 (감사 로그 고도화), Elasticsearch/OpenSearch 설정

## 목표
감사 로그와 시스템 로그를 효과적으로 분석할 수 있는 고급 분석 도구를 구현합니다. 로그 검색 고도화, 로그 시각화, 컴플라이언스 리포트, 로그 아카이빙 기능을 포함합니다.

## 상세 요구사항

### 1. 로그 검색 고도화 (전문 검색)
- **고급 검색 쿼리**: Elasticsearch 기반 전문 검색
- **필터링**: 시간, 사용자, 액션, 심각도별 필터링
- **자동완성**: 검색어 자동완성 기능
- **저장된 검색**: 자주 사용하는 검색 쿼리 저장

### 2. 로그 시각화 (차트, 그래프)
- **대시보드**: 로그 데이터 시각화 대시보드
- **차트 타입**: 시간별 트렌드, 사용자별 활동, 액션별 분포
- **실시간 모니터링**: 실시간 로그 스트림 시각화
- **커스텀 위젯**: 사용자 정의 시각화 위젯

### 3. 컴플라이언스 리포트
- **표준 리포트**: GDPR, SOX, HIPAA 등 규제 준수 리포트
- **자동 생성**: 주기적 자동 리포트 생성
- **PDF 내보내기**: 감사용 PDF 리포트 생성
- **리포트 템플릿**: 커스터마이징 가능한 리포트 템플릿

### 4. 로그 아카이빙
- **자동 아카이빙**: 오래된 로그 자동 아카이빙
- **압축 저장**: 압축을 통한 스토리지 최적화
- **검색 가능**: 아카이브된 로그도 검색 가능
- **복원 기능**: 필요시 아카이브 로그 복원

export class LogAnalysisService {
  private readonly searchEngine: ElasticsearchService;
  private readonly visualizationService: VisualizationService;
  private readonly reportGenerator: ReportGenerator;
  private readonly archiveService: ArchiveService;
  private readonly queryBuilder: QueryBuilder;

  async searchLogs(searchRequest: LogSearchRequest): Promise<LogSearchResult> {
    try {
      // 1. 검색 쿼리 빌드
      const query = await this.queryBuilder.buildQuery(searchRequest);
      
      // 2. Elasticsearch 검색 실행
      const results = await this.searchEngine.search(query);
      
      // 3. 결과 가공 및 하이라이팅
      const processedResults = await this.processSearchResults(results);
      
      // 4. 검색 이력 저장
      await this.saveSearchHistory(searchRequest, results.total);
      
      return processedResults;
      
    } catch (error) {
      this.logger.error(`Log search failed: ${error.message}`);
      throw new LogAnalysisError(`Search failed: ${error.message}`);
    }
  }

  async generateVisualization(request: VisualizationRequest): Promise<VisualizationResult> {
    try {
      // 1. 데이터 집계 쿼리 실행
      const aggregationQuery = this.queryBuilder.buildAggregationQuery(request);
      const data = await this.searchEngine.aggregate(aggregationQuery);
      
      // 2. 시각화 데이터 변환
      const chartData = await this.visualizationService.transformData(data, request.chartType);
      
      // 3. 차트 생성
      const visualization = await this.visualizationService.createChart(chartData, request);
      
      return visualization;
      
    } catch (error) {
      this.logger.error(`Visualization generation failed: ${error.message}`);
      throw error;
    }
  }
}

export class ElasticsearchService {
  private readonly client: Client;
  private readonly indexName: string = 'vanillameta-audit-logs';
  
  constructor() {
    this.client = new Client({
      node: process.env.ELASTICSEARCH_URL || 'http://localhost:9200',
      auth: {
        username: process.env.ELASTICSEARCH_USERNAME,
        password: process.env.ELASTICSEARCH_PASSWORD
      }
    });
  }
  
  async search(query: ElasticsearchQuery): Promise<SearchResult> {
    try {
      const response = await this.client.search({
        index: this.indexName,
        body: query,
        from: query.from || 0,
        size: query.size || 50
      });
      
      return {
        hits: response.body.hits.hits,
        total: response.body.hits.total.value,
        aggregations: response.body.aggregations,
        took: response.body.took
      };
      
    } catch (error) {
      this.logger.error(`Elasticsearch query failed: ${error.message}`);
      throw error;
    }
  }
  
  async autocomplete(field: string, query: string): Promise<string[]> {
    try {
      const response = await this.client.search({
        index: this.indexName,
        body: {
          suggest: {
            autocomplete: {
              prefix: query,
              completion: {
                field: `${field}.suggest`,
                size: 10
              }
            }
          }
        }
      });
      
      return response.body.suggest.autocomplete[0].options.map(
        option => option.text
      );
      
    } catch (error) {
      this.logger.error(`Autocomplete failed: ${error.message}`);
      return [];
    }
  }
}

export class QueryBuilder {
  buildQuery(request: LogSearchRequest): ElasticsearchQuery {
    const query: any = {
      bool: {
        must: [],
        filter: [],
        should: [],
        must_not: []
      }
    };
    
    // 1. 텍스트 검색
    if (request.searchText) {
      query.bool.must.push({
        multi_match: {
          query: request.searchText,
          fields: [
            'action^2',
            'description^2',
            'user.username^1.5',
            'metadata.*',
            'sql_queries.query_text'
          ],
          type: 'best_fields',
          fuzziness: 'AUTO'
        }
      });
    }
    
    // 2. 시간 범위 필터
    if (request.timeRange) {
      query.bool.filter.push({
        range: {
          timestamp: {
            gte: request.timeRange.start,
            lte: request.timeRange.end
          }
        }
      });
    }
    
    // 3. 사용자 필터
    if (request.userIds && request.userIds.length > 0) {
      query.bool.filter.push({
        terms: {
          'user.id': request.userIds
        }
      });
    }
    
    // 4. 액션 필터
    if (request.actions && request.actions.length > 0) {
      query.bool.filter.push({
        terms: {
          'action.keyword': request.actions
        }
      });
    }
    
    // 5. 심각도 필터
    if (request.severities && request.severities.length > 0) {
      query.bool.filter.push({
        terms: {
          severity: request.severities
        }
      });
    }
    
    // 6. IP 주소 필터
    if (request.ipAddress) {
      query.bool.filter.push({
        term: {
          'ip_address': request.ipAddress
        }
      });
    }
    
    // 7. 하이라이팅 설정
    const highlight = {
      fields: {
        action: {},
        description: {},
        'user.username': {},
        'sql_queries.query_text': {}
      },
      pre_tags: ['<mark>'],
      post_tags: ['</mark>']
    };
    
    // 8. 정렬 설정
    const sort = request.sortBy ? [
      { [request.sortBy]: { order: request.sortOrder || 'desc' } }
    ] : [
      { timestamp: { order: 'desc' } }
    ];
    
    return {
      query,
      highlight,
      sort,
      from: request.offset || 0,
      size: request.limit || 50
    };
  }
  
  buildAggregationQuery(request: VisualizationRequest): ElasticsearchQuery {
    const baseQuery = this.buildQuery(request.searchRequest);
    
    let aggregation: any = {};
    
    switch (request.chartType) {
      case 'timeline':
        aggregation = {
          timeline: {
            date_histogram: {
              field: 'timestamp',
              calendar_interval: request.interval || '1h',
              min_doc_count: 0
            }
          }
        };
        break;
        
      case 'user_activity':
        aggregation = {
          users: {
            terms: {
              field: 'user.username.keyword',
              size: request.limit || 20
            }
          }
        };
        break;
        
      case 'action_distribution':
        aggregation = {
          actions: {
            terms: {
              field: 'action.keyword',
              size: request.limit || 20
            }
          }
        };
        break;
        
      case 'severity_breakdown':
        aggregation = {
          severities: {
            terms: {
              field: 'severity',
              size: 10
            }
          }
        };
        break;
        
      case 'heatmap':
        aggregation = {
          hours: {
            date_histogram: {
              field: 'timestamp',
              calendar_interval: '1h'
            },
            aggs: {
              days: {
                date_histogram: {
                  field: 'timestamp',
                  calendar_interval: '1d'
                }
              }
            }
          }
        };
        break;
    }
    
    return {
      ...baseQuery,
      aggs: aggregation,
      size: 0 // 집계만 필요하므로 documents는 반환하지 않음
    };
  }
}

export class VisualizationService {
  async transformData(rawData: any, chartType: ChartType): Promise<ChartData> {
    switch (chartType) {
      case 'timeline':
        return this.transformTimelineData(rawData);
      case 'user_activity':
        return this.transformUserActivityData(rawData);
      case 'action_distribution':
        return this.transformActionDistributionData(rawData);
      case 'severity_breakdown':
        return this.transformSeverityData(rawData);
      case 'heatmap':
        return this.transformHeatmapData(rawData);
      default:
        throw new Error(`Unsupported chart type: ${chartType}`);
    }
  }
  
  private transformTimelineData(rawData: any): TimelineChartData {
    const buckets = rawData.aggregations.timeline.buckets;
    
    return {
      type: 'timeline',
      labels: buckets.map(bucket => new Date(bucket.key).toISOString()),
      datasets: [{
        label: 'Log Events',
        data: buckets.map(bucket => bucket.doc_count),
        borderColor: '#3b82f6',
        backgroundColor: 'rgba(59, 130, 246, 0.1)',
        tension: 0.1
      }]
    };
  }
  
  private transformUserActivityData(rawData: any): BarChartData {
    const buckets = rawData.aggregations.users.buckets;
    
    return {
      type: 'bar',
      labels: buckets.map(bucket => bucket.key),
      datasets: [{
        label: 'Activity Count',
        data: buckets.map(bucket => bucket.doc_count),
        backgroundColor: buckets.map((_, index) => 
          `hsl(${(index * 360 / buckets.length)}, 70%, 60%)`
        )
      }]
    };
  }
  
  private transformActionDistributionData(rawData: any): PieChartData {
    const buckets = rawData.aggregations.actions.buckets;
    
    return {
      type: 'pie',
      labels: buckets.map(bucket => bucket.key),
      datasets: [{
        data: buckets.map(bucket => bucket.doc_count),
        backgroundColor: buckets.map((_, index) => 
          `hsl(${(index * 360 / buckets.length)}, 70%, 60%)`
        )
      }]
    };
  }
  
  private transformHeatmapData(rawData: any): HeatmapChartData {
    const hourBuckets = rawData.aggregations.hours.buckets;
    
    const heatmapData = [];
    
    for (let hour = 0; hour < 24; hour++) {
      for (let day = 0; day < 7; day++) {
        const bucket = hourBuckets.find(b => {
          const date = new Date(b.key);
          return date.getHours() === hour && date.getDay() === day;
        });
        
        heatmapData.push({
          x: day,
          y: hour,
          v: bucket ? bucket.doc_count : 0
        });
      }
    }
    
    return {
      type: 'heatmap',
      data: heatmapData,
      xLabels: ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'],
      yLabels: Array.from({ length: 24 }, (_, i) => `${i}:00`)
    };
  }
  
  async createChart(chartData: ChartData, options: ChartOptions): Promise<Chart> {
    // Chart.js나 D3.js를 사용한 차트 생성
    const chart = new Chart(chartData, {
      ...options,
      responsive: true,
      plugins: {
        legend: {
          display: options.showLegend !== false
        },
        tooltip: {
          enabled: true,
          mode: 'index',
          intersect: false
        }
      },
      scales: chartData.type !== 'pie' ? {
        x: {
          display: true,
          title: {
            display: true,
            text: options.xAxisLabel || 'Time'
          }
        },
        y: {
          display: true,
          title: {
            display: true,
            text: options.yAxisLabel || 'Count'
          }
        }
      } : undefined
    });
    
    return chart;
  }
}

export class ReportGenerator {
  private readonly templateEngine: TemplateEngine;
  private readonly pdfGenerator: PdfGenerator;
  
  async generateComplianceReport(request: ComplianceReportRequest): Promise<ComplianceReport> {
    try {
      // 1. 리포트 타입에 따른 데이터 수집
      const reportData = await this.collectReportData(request);
      
      // 2. 리포트 템플릿 렌더링
      const htmlContent = await this.renderReportTemplate(request.type, reportData);
      
      // 3. PDF 생성
      const pdfBuffer = await this.pdfGenerator.generatePdf(htmlContent);
      
      // 4. 리포트 메타데이터 저장
      const report = await this.saveReport({
        id: this.generateReportId(),
        type: request.type,
        period: request.period,
        generatedBy: request.userId,
        generatedAt: new Date(),
        fileSize: pdfBuffer.length,
        checksum: await this.calculateChecksum(pdfBuffer)
      });
      
      // 5. 파일 저장
      await this.saveReportFile(report.id, pdfBuffer);
      
      return report;
      
    } catch (error) {
      this.logger.error(`Report generation failed: ${error.message}`);
      throw error;
    }
  }
  
  private async collectReportData(request: ComplianceReportRequest): Promise<ReportData> {
    const data: ReportData = {
      period: request.period,
      generatedAt: new Date(),
      summary: {},
      details: {},
      compliance: {}
    };
    
    switch (request.type) {
      case 'gdpr':
        data.details = await this.collectGdprData(request.period);
        data.compliance.gdpr = await this.assessGdprCompliance(data.details);
        break;
        
      case 'sox':
        data.details = await this.collectSoxData(request.period);
        data.compliance.sox = await this.assessSoxCompliance(data.details);
        break;
        
      case 'security_audit':
        data.details = await this.collectSecurityData(request.period);
        data.compliance.security = await this.assessSecurityCompliance(data.details);
        break;
        
      case 'data_access':
        data.details = await this.collectDataAccessData(request.period);
        break;
        
      default:
        throw new Error(`Unsupported report type: ${request.type}`);
    }
    
    // 공통 요약 정보
    data.summary = {
      totalLogs: data.details.totalLogs || 0,
      uniqueUsers: data.details.uniqueUsers || 0,
      criticalEvents: data.details.criticalEvents || 0,
      anomalies: data.details.anomalies || 0
    };
    
    return data;
  }
  
  private async collectGdprData(period: ReportPeriod): Promise<GdprReportData> {
    const startDate = new Date(period.start);
    const endDate = new Date(period.end);
    
    // 개인정보 접근 로그
    const dataAccess = await this.searchEngine.search({
      query: {
        bool: {
          must: [
            { range: { timestamp: { gte: startDate, lte: endDate } } },
            { terms: { action: ['data.read', 'data.export', 'data.download'] } }
          ]
        }
      },
      aggs: {
        by_user: { terms: { field: 'user.id', size: 1000 } },
        by_table: { terms: { field: 'metadata.table_name', size: 100 } }
      },
      size: 0
    });
    
    // 개인정보 수정/삭제 로그
    const dataModification = await this.searchEngine.search({
      query: {
        bool: {
          must: [
            { range: { timestamp: { gte: startDate, lte: endDate } } },
            { terms: { action: ['data.update', 'data.delete'] } },
            { terms: { 'metadata.table_name': ['users', 'user_profiles'] } }
          ]
        }
      },
      size: 10000
    });
    
    // 데이터 주체 권리 행사 요청
    const rightRequests = await this.searchEngine.search({
      query: {
        bool: {
          must: [
            { range: { timestamp: { gte: startDate, lte: endDate } } },
            { terms: { action: ['gdpr.request', 'gdpr.portability', 'gdpr.erasure'] } }
          ]
        }
      },
      size: 1000
    });
    
    return {
      totalLogs: dataAccess.total + dataModification.total,
      dataAccessCount: dataAccess.total,
      dataModificationCount: dataModification.total,
      rightRequestsCount: rightRequests.total,
      accessByUser: dataAccess.aggregations.by_user.buckets,
      accessByTable: dataAccess.aggregations.by_table.buckets,
      modifications: dataModification.hits,
      rightRequests: rightRequests.hits
    };
  }
  
  private async assessGdprCompliance(data: GdprReportData): Promise<ComplianceAssessment> {
    const issues: ComplianceIssue[] = [];
    let score = 100;
    
    // 1. 과도한 개인정보 접근 확인
    const excessiveAccessUsers = data.accessByUser.filter(user => user.doc_count > 1000);
    if (excessiveAccessUsers.length > 0) {
      issues.push({
        severity: 'medium',
        category: 'data_access',
        description: `${excessiveAccessUsers.length} users with excessive personal data access`,
        recommendation: 'Review access patterns and implement additional controls'
      });
      score -= 10;
    }
    
    // 2. 데이터 주체 요청 처리 시간 확인
    const delayedRequests = data.rightRequests.filter(request => {
      const requestDate = new Date(request._source.timestamp);
      const responseDate = request._source.metadata.responseDate;
      if (responseDate) {
        const daysDiff = (new Date(responseDate) - requestDate) / (1000 * 60 * 60 * 24);
        return daysDiff > 30; // GDPR 1개월 기준
      }
      return false;
    });
    
    if (delayedRequests.length > 0) {
      issues.push({
        severity: 'high',
        category: 'response_time',
        description: `${delayedRequests.length} GDPR requests exceeded 30-day response time`,
        recommendation: 'Improve request processing workflow and set up alerts'
      });
      score -= 20;
    }
    
    // 3. 무단 개인정보 수정 확인
    const unauthorizedModifications = data.modifications.filter(mod => 
      !mod._source.metadata.authorized || mod._source.metadata.bypassAuth
    );
    
    if (unauthorizedModifications.length > 0) {
      issues.push({
        severity: 'critical',
        category: 'unauthorized_access',
        description: `${unauthorizedModifications.length} unauthorized personal data modifications`,
        recommendation: 'Immediate investigation required - review access controls'
      });
      score -= 30;
    }
    
    return {
      score: Math.max(0, score),
      level: score >= 80 ? 'compliant' : score >= 60 ? 'partially_compliant' : 'non_compliant',
      issues,
      recommendations: issues.map(issue => issue.recommendation)
    };
  }
}

### 5. 로그 아카이빙 서비스

```typescript
export class ArchiveService {
  private readonly s3Service: S3Service;
  private readonly compressionService: CompressionService;
  private readonly indexService: ArchiveIndexService;
  
  async archiveLogs(policy: ArchivePolicy): Promise<ArchiveResult> {
    try {
      // 1. 아카이브 대상 로그 조회
      const logsToArchive = await this.getLogsForArchive(policy);
      
      if (logsToArchive.length === 0) {
        return { archived: 0, message: 'No logs to archive' };
      }
      
      // 2. 로그 데이터 압축
      const compressedData = await this.compressionService.compress(logsToArchive);
      
      // 3. S3에 업로드
      const archiveKey = this.generateArchiveKey(policy.period);
      const s3Location = await this.s3Service.upload(archiveKey, compressedData);
      
      // 4. 아카이브 인덱스 생성
      await this.indexService.createIndex({
        archiveId: this.generateArchiveId(),
        s3Location,
        period: policy.period,
        logCount: logsToArchive.length,
        compressedSize: compressedData.length,
        checksum: await this.calculateChecksum(compressedData),
        createdAt: new Date()
      });
      
      // 5. 원본 로그 삭제 (정책에 따라)
      if (policy.deleteAfterArchive) {
        await this.deleteArchivedLogs(logsToArchive);
      }
      
      return {
        archived: logsToArchive.length,
        archiveLocation: s3Location,
        compressedSize: compressedData.length
      };
      
    } catch (error) {
      this.logger.error(`Log archiving failed: ${error.message}`);
      throw error;
    }
  }
  
  async searchArchivedLogs(searchRequest: ArchiveSearchRequest): Promise<ArchiveSearchResult> {
    try {
      // 1. 검색 기간에 해당하는 아카이브 찾기
      const relevantArchives = await this.indexService.findArchives(searchRequest.timeRange);
      
      const results: LogEntry[] = [];
      
      // 2. 각 아카이브에서 검색
      for (const archive of relevantArchives) {
        try {
          // 아카이브 다운로드 및 압축 해제
          const archiveData = await this.s3Service.download(archive.s3Location);
          const decompressedLogs = await this.compressionService.decompress(archiveData);
          
          // 검색 조건에 맞는 로그 필터링
          const matchingLogs = this.filterLogs(decompressedLogs, searchRequest);
          results.push(...matchingLogs);
          
        } catch (error) {
          this.logger.error(`Failed to search archive ${archive.archiveId}: ${error.message}`);
        }
      }
      
      return {
        hits: results,
        total: results.length,
        searchedArchives: relevantArchives.length
      };
      
    } catch (error) {
      this.logger.error(`Archive search failed: ${error.message}`);
      throw error;
    }
  }
  
  private async getLogsForArchive(policy: ArchivePolicy): Promise<LogEntry[]> {
    const cutoffDate = new Date();
    cutoffDate.setDate(cutoffDate.getDate() - policy.retentionDays);
    
    const query = {
      query: {
        range: {
          timestamp: {
            lt: cutoffDate.toISOString()
          }
        }
      },
      sort: [{ timestamp: { order: 'asc' } }],
      size: policy.batchSize || 10000
    };
    
    const result = await this.searchEngine.search(query);
    return result.hits.map(hit => hit._source);
  }
  
  private filterLogs(logs: LogEntry[], searchRequest: ArchiveSearchRequest): LogEntry[] {
    return logs.filter(log => {
      // 시간 범위 확인
      if (searchRequest.timeRange) {
        const logTime = new Date(log.timestamp);
        if (logTime < new Date(searchRequest.timeRange.start) || 
            logTime > new Date(searchRequest.timeRange.end)) {
          return false;
        }
      }
      
      // 텍스트 검색
      if (searchRequest.searchText) {
        const searchLower = searchRequest.searchText.toLowerCase();
        const searchableText = [
          log.action,
          log.description,
          log.user?.username,
          JSON.stringify(log.metadata)
        ].join(' ').toLowerCase();
        
        if (!searchableText.includes(searchLower)) {
          return false;
        }
      }
      
      // 사용자 필터
      if (searchRequest.userIds && searchRequest.userIds.length > 0) {
        if (!searchRequest.userIds.includes(log.user?.id)) {
          return false;
        }
      }
      
      return true;
    });
  }
}
```
