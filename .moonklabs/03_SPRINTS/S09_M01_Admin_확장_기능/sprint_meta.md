# Sprint Meta: S09 - Admin 확장 기능 (Phase 2)

## Sprint Information
- **Sprint ID**: S09
- **Sprint Name**: Admin 확장 기능 구현
- **Duration**: 3주
- **Status**: planned
- **Milestone**: M01 - MVP 안정화 및 핵심 기능 강화

## Sprint Goals
1. 조직/팀 관리 체계 구축
2. 공유 관리 기능 고도화
3. 알림/공지사항 시스템 구현

## Tasks

### T01_S09: 조직/팀 엔티티 설계
- Organization, Department, Team 엔티티
- 계층 구조 관계 설정
- 팀-사용자 매핑
- 팀 권한 상속 구조

### T02_S09: 조직/팀 관리 UI
- 조직 구조 트리 뷰
- 팀 CRUD 기능
- 드래그앤드롭 조직 구조 변경
- 팀별 멤버 관리

### T03_S09: 팀 기반 권한 및 격리
- 팀별 대시보드 격리
- 팀 리더 권한 위임
- 팀 간 리소스 공유 정책
- 팀별 사용량 통계

### T04_S09: 공유 관리 중앙화
- 전체 공유 링크 관리 대시보드
- 공유 링크 활성화/비활성화
- 공유 만료 기간 관리
- 공유 통계 (조회수, 접속자)

### T05_S09: 공유 권한 고도화
- 공유 레벨 설정 (Public/Internal/Specific)
- 공유 대상 그룹 관리
- 패스워드 보호 공유
- 공유 정책 템플릿

### T06_S09: 공지사항 시스템 구현
- Notice 엔티티 및 API
- 공지 작성 에디터 (리치 텍스트)
- 공지 유형 및 우선순위
- 예약 발송 기능

### T07_S09: 알림 시스템 구현
- 인앱 알림 (실시간)
- 이메일 알림 통합
- 알림 설정 (사용자별)
- 알림 히스토리

### T08_S09: 공지사항 UI
- 공지사항 목록 및 상세
- 팝업/배너 표시 로직
- 읽음 확인 추적
- 중요 공지 고정

## Dependencies
- S08의 RBAC 시스템
- 기존 공유 기능
- 이메일/알림 인프라

## Success Criteria
- [ ] 조직 구조에 따른 권한 관리 가능
- [ ] 팀별 리소스 격리 정상 작동
- [ ] 공유 링크 중앙 관리 가능
- [ ] 공지사항이 대상자에게 정확히 전달
- [ ] 알림이 실시간으로 동작

## Risks & Mitigations
- **Risk**: 복잡한 조직 구조로 인한 성능 저하
  - **Mitigation**: 조직 구조 캐싱, 최대 깊이 제한
- **Risk**: 실시간 알림 서버 부하
  - **Mitigation**: WebSocket 연결 풀 관리, 배치 처리

## Notes
- 조직 구조는 최대 4단계까지 지원
- 팀 이동 시 권한 자동 조정
- 공지사항은 마크다운 지원
