# Studio dashboards

## Sub-features
Create from a file or sample, add and resize numeric/chart/pivot blocks, save, publish, remix.

## How to get to it (user POV)
/dashboard/<id>/studio, or the add menu on /dashboard.

## Driving it with Playwright
Needs an organization and a ready file source. Upload a CSV through the file artifact or source upload, create a dashboard, add a block, save, reload, and compare block titles and values.

## Gotchas
Without an organization or file source the journey cannot start. Report it as unreachable with the missing prerequisite.
