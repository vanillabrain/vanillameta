# Vision

## Product

VanillaMeta — Simple Analysis

## Problem

커머스 운영팀은 SQL 없이 신뢰할 수 있는 지표와 추세를 보고 싶다. 미리보기와 저장 화면의 차이, 동시에 펼쳐진 설정은 판단을 어렵게 한다.

## Outcome

같은 데이터·기간·필터의 숫자와 시계열을 미리보기부터 저장·재조회까지 유지한다. 보조 설정은 필요할 때 펼친다. 이번 AIWF 문서는 기존 전체 제품의 역설계가 아니라 UC-001의 제한된 범위다.

## Users

운영 담당자: 데이터를 연결하고 질문·검토·저장한다. 개발 담당자: 내부 정의와 실행 경계를 유지한다.

## Non-Goals

Rill 전체 리소스 엔진 복제, YAML 파일 트리 노출, 새 DB 스키마, 지표 계층 전면 교체, BigQuery/Athena, 알림/API 신규 구현, 운영 배포.
