### 질문 A — 제목과 정의 정리

```text
대시보드 제목을 매출·환불 운영 현황으로 바꾸고, 세금·배송 포함 차감 수취액과 주문일 코호트 환불률의 차이를 설명해 줘. 금액과 계산식은 변경하지 마.
```

실제 응답: 차감 수취액은 선택한 UTC 기간의 결제액에서 기록된 환불액을 빼고, 환불률은 주문일 코호트의 성공 결제 주문 중 확보한 데이터 범위 내 환불 이력이 있는 고유 주문 비율이라고 설명했다. 차트 제목은 `일별 결제액·환불액·차감 수취액 (USD)`였다.

### 질문 B — 모순처럼 보이는 지표 해결

```text
현재 조회 범위는 2025-06-24 하루야. 환불액이 0달러인데 환불 주문 비율은 100%인 이유를 운영 담당자가 이해하도록 두 문장으로 설명해 줘. 환불 처리일과 주문일 코호트의 차이, 확보한 데이터 범위 내 환불 이력임을 포함해. 제목은 매출·환불 운영 현황으로 유지하고 금액과 계산식은 변경하지 마.
```

실제 화면 응답:

> 2025-06-24에는 결제 1건(200.23달러), 환불 처리액 0달러였지만 주문일 코호트의 결제 주문 1건 모두에 확보한 데이터 범위 내 환불 이력이 있어 환불 주문 비율은 100%입니다. 금액은 환불 처리일 기준으로 집계하고 환불 주문 비율은 주문일 코호트 기준으로 계산하므로, 환불 처리액이 0달러여도 비율은 100%일 수 있습니다.

문장은 실행마다 달라질 수 있다. 날짜 기준·0달러·1/1=100%·데이터 범위라는 의미를 검증한다. 이 화면의 AI 기능은 제목·설명 편집이며, 자유로운 다중 테이블 질의나 환불 계산식 변경을 시연한 것은 아니다.
