# VanillaMeta 사용자 가이드

데이터를 연결하고 질문으로 분석을 만든 뒤, 저장·게시·공유하는 방법을 안내합니다. SQL을 몰라도 지원되는 파일 소스로 Studio 분석을 시작할 수 있습니다.

- 처음 사용한다면 [빠른 시작 가이드](빠른_시작_가이드.md)를 따라 해 보세요.
- 내 데이터 연결, 수정, 게시 갱신, 조직 공유와 오류 복구는 [사용자 매뉴얼](VanillaMeta_사용자_매뉴얼.md)을 참고하세요.
- 기존 데이터셋·위젯 편집기의 차트 설정은 [차트 유형별 사용 가이드](차트_유형별_사용_가이드.md)를 참고하세요. 이 문서는 기존 위젯용 참고 자료이며, 모든 차트가 AI Studio에서 생성된다는 의미는 아닙니다.
- [스크린샷 가이드](스크린샷_가이드.md)는 기존 화면의 촬영 계획입니다. 최신 화면 캡처나 실행 검증 결과를 대신하지 않습니다.
