## 스크린샷 제작 가이드라인

### 기본 원칙
1. 해상도: 1920x1080 기준
2. 브라우저: Chrome 최신 버전
3. 확대/축소: 100%
4. 언어: 한국어
5. 테마: 기본 라이트 테마

### 주의사항
1. 개인정보나 민감한 데이터 제거
2. 샘플 데이터 사용
3. 깔끔한 화면 상태 유지
4. 중요 부분 강조 (빨간 박스 등)

### 파일 명명 규칙
- 소문자 사용
- 하이픈으로 단어 구분
- 섹션-기능-순서.png
- 예: `dashboard-create-01.png`
