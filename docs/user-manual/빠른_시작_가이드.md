# VanillaMeta 빠른 시작 가이드

5분 안에 첫 대시보드를 만들어보세요!

## 🚀 3단계로 시작하기

### 1단계: 데이터 연결 (2분)

1. 좌측 메뉴에서 **"데이터" → "데이터소스"** 클릭
2. **"데이터소스 추가"** 버튼 클릭
3. 데이터베이스 정보 입력:
   ```
   연결 이름: 내 첫 데이터베이스
   호스트: your-database.com
   포트: 3306
   데이터베이스: sample_db
   사용자명: your_username
   비밀번호: your_password
   ```
4. **"연결 테스트"** → **"저장"**

### 2단계: 데이터셋 생성 (2분)

1. **"데이터" → "데이터셋"** 이동
2. **"데이터셋 추가"** 클릭
3. 방금 만든 데이터소스 선택
4. 간단한 SQL 쿼리 입력:
   ```sql
   SELECT 
       DATE(created_at) as 날짜,
       COUNT(*) as 주문수,
       SUM(amount) as 매출액
   FROM orders
   WHERE created_at >= DATE_SUB(CURRENT_DATE, INTERVAL 30 DAY)
   GROUP BY DATE(created_at)
   ORDER BY 날짜 DESC
   ```
5. **"실행"** → 결과 확인 → **"저장"**

### 3단계: 차트 만들기 (1분)

1. **"위젯" → "위젯 생성"** 클릭
2. 방금 만든 데이터셋 선택
3. **"라인 차트"** 선택
4. 데이터 매핑:
   - X축: 날짜
   - Y축: 매출액
5. **"저장"** → 대시보드에 추가

## 💡 유용한 팁

### 샘플 SQL 쿼리

**일별 매출 추이**
```sql
SELECT 
    DATE(order_date) as date,
    SUM(amount) as daily_sales
FROM orders
GROUP BY DATE(order_date)
ORDER BY date DESC
LIMIT 30
```

**카테고리별 매출 비중**
```sql
SELECT 
    category,
    SUM(amount) as sales
FROM products p
JOIN order_items oi ON p.id = oi.product_id
GROUP BY category
```

**시간대별 트래픽**
```sql
SELECT 
    HOUR(created_at) as hour,
    COUNT(*) as visits
FROM page_views
WHERE DATE(created_at) = CURRENT_DATE
GROUP BY HOUR(created_at)
```

### 자주 사용하는 차트 조합

**영업 대시보드**
- 라인 차트: 일별 매출 추이
- 파이 차트: 제품 카테고리 비중
- 바 차트: 영업사원별 실적
- 게이지: 목표 달성률

**마케팅 대시보드**
- 라인 차트: 방문자 수 추이
- 깔때기 차트: 전환율 퍼널
- 히트맵: 시간대별 활동
- 지도: 지역별 분포
