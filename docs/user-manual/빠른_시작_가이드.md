# 첫 아티팩트 만들기

**완성할 것:** 총매출 숫자와 날짜별 매출 차트가 있는 내 대시보드. 처음에는 준비된 샘플로 만들고 비공개로 저장합니다.

운영자가 안내한 VanillaMeta 주소에 접속해 개인 계정으로 로그인하세요. AI 기능은 서버에 AI 실행 환경이 준비되어 있어야 합니다. 준비되지 않았다는 안내가 나오면 운영자에게 확인하세요.

## 1. 샘플 데이터 준비

1. 대시보드 목록(`/dashboard`)에서 **질문으로 대시보드 만들기**를 누릅니다.
2. **내 데이터로 시작하기** 화면에서 **비용·마진 샘플**을 선택합니다.
3. 준비가 끝나면 **저장된 데이터**에 해당 소스가 선택되어 있는지 확인합니다.

이 샘플은 공개 합성 데이터입니다. 선택하면 본인 분석용 소스를 준비하며, 이 단계에서 대시보드를 게시하지 않습니다.

![데이터 준비와 질문 입력](images/01-source-question.png)

## 2. 질문하고 결과 확인

**만들 대시보드 요청**에 다음을 입력하고 **지표와 차트 제안**을 누릅니다.

> 총매출 SUM(revenue)을 숫자 지표로, 날짜별 매출 추세를 시계열 차트로 만들어줘. 제목은 매출 분석으로 해줘.

**계산 미리보기**에서 다음을 확인합니다.

- 숫자 지표와 날짜별 시계열이 모두 생성되었는지
- **계산 기준 확인**에 `revenue`의 합계가 표시되는지
- 조회 기간·필터·통화와 차트 날짜 범위가 맞는지
- **데이터 표 보기**의 결과가 의도와 맞는지

원본 그대로의 비용·마진 샘플 18행 전체를 합산하면 매출은 **14,937.49 USD**입니다. 샘플 버전이나 필터가 달라지면 이 값과 달라질 수 있습니다. AI가 다른 구성을 제안하면 미리보기에서 확인하고 수정하세요.

![총매출 숫자와 날짜별 매출 시계열 미리보기](images/02-ai-preview.png)

## 3. 저장하고 다시 열기

1. **Studio에 저장하고 열기**를 누릅니다.
2. Studio에서 **저장됨**을 확인합니다.
3. 브라우저를 새로고침해 제목·숫자·시계열이 유지되는지 확인합니다.

저장은 내 대시보드를 만드는 작업입니다. 아직 익명 공개 링크는 없습니다.
