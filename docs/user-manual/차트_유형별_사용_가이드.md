# VanillaMeta 차트 유형별 상세 사용 가이드

## 📊 기본 차트

### 라인 차트 (Line Chart)

#### 언제 사용하나요?
- 시간에 따른 변화를 보여줄 때
- 연속적인 데이터의 추세를 표현할 때
- 여러 시리즈를 비교할 때

#### 데이터 요구사항
- X축: 시간 또는 순서가 있는 데이터
- Y축: 수치 데이터
- 시리즈: 선택사항 (여러 라인 표시)

#### 설정 옵션
```javascript
{
  smooth: true,          // 곡선으로 표시
  showSymbol: true,      // 데이터 포인트 표시
  areaStyle: {},         // 영역 채우기
  step: 'start',         // 계단형 라인
  connectNulls: true     // NULL 값 연결
}
```

#### 사용 예시
```sql
-- 월별 매출 추이
SELECT 
    DATE_FORMAT(order_date, '%Y-%m') as month,
    product_category,
    SUM(amount) as revenue
FROM orders
GROUP BY month, product_category
ORDER BY month
```

### 바 차트 / 컬럼 차트 (Bar/Column Chart)

#### 언제 사용하나요?
- 카테고리 간 크기 비교
- 순위 표시
- 긍정/부정 값 표현

#### 데이터 요구사항
- 카테고리: 비교할 항목
- 값: 수치 데이터
- 그룹: 선택사항 (그룹 비교)

#### 설정 옵션
```javascript
{
  barWidth: '60%',       // 막대 너비
  barGap: '30%',         // 막대 간격
  stack: 'total',        // 누적 막대
  showBackground: true,   // 배경 표시
  label: {
    show: true,
    position: 'top'      // 라벨 위치
  }
}
```

#### 사용 예시
```sql
-- 지역별 매출 비교
SELECT 
    region,
    SUM(amount) as total_sales,
    COUNT(DISTINCT customer_id) as customers
FROM sales
GROUP BY region
ORDER BY total_sales DESC
LIMIT 10
```

### 파이 차트 / 도넛 차트 (Pie/Donut Chart)

#### 언제 사용하나요?
- 전체 대비 비율 표현
- 구성 요소 비중 표시
- 5-7개 이하의 카테고리

#### 데이터 요구사항
- 카테고리: 구분할 항목
- 값: 양수 값만 가능

#### 설정 옵션
```javascript
{
  radius: ['40%', '70%'], // 도넛: [내부반경, 외부반경]
  center: ['50%', '50%'], // 중심 위치
  roseType: 'radius',     // 장미 차트
  selectedMode: 'single', // 선택 모드
  label: {
    formatter: '{b}: {d}%' // 라벨 포맷
  }
}
```

#### 사용 예시
```sql
-- 제품 카테고리별 매출 비중
SELECT 
    category,
    SUM(amount) as sales
FROM products
GROUP BY category
HAVING sales > 0
```

## 📈 고급 차트

### 산점도 (Scatter Chart)

#### 언제 사용하나요?
- 두 변수 간 상관관계 분석
- 이상치 발견
- 클러스터 패턴 식별

#### 데이터 요구사항
- X축: 수치 데이터
- Y축: 수치 데이터
- 크기: 선택사항 (버블 차트)
- 카테고리: 선택사항 (색상 구분)

#### 설정 옵션
```javascript
{
  symbolSize: 20,         // 점 크기
  large: true,           // 대용량 데이터 최적화
  largeThreshold: 2000,  // 최적화 임계값
  emphasis: {
    focus: 'self'        // 강조 효과
  }
}
```

### 히트맵 (Heatmap)

#### 언제 사용하나요?
- 2차원 데이터의 밀도 표현
- 시간대별 패턴 분석
- 상관관계 매트릭스

#### 데이터 요구사항
- X축 카테고리
- Y축 카테고리
- 값: 강도를 나타내는 수치

#### 설정 옵션
```javascript
{
  label: {
    show: true           // 셀 내 값 표시
  },
  itemStyle: {
    borderWidth: 1,      // 셀 테두리
    borderColor: '#fff'
  }
}
```

#### 사용 예시
```sql
-- 요일별 시간대별 주문 수
SELECT 
    DAYNAME(order_date) as day_of_week,
    HOUR(order_time) as hour,
    COUNT(*) as order_count
FROM orders
GROUP BY day_of_week, hour
```

### 트리맵 (Treemap)

#### 언제 사용하나요?
- 계층적 데이터 표현
- 비율과 계층을 동시에 표시
- 디스크 사용량, 예산 배분 등

#### 데이터 요구사항
- 계층 구조 데이터
- 각 노드의 값

#### 설정 옵션
```javascript
{
  leafDepth: 2,          // 표시할 깊이
  roam: false,           // 줌/팬 가능 여부
  nodeClick: 'zoomToNode', // 클릭 동작
  breadcrumb: {
    show: true           // 경로 표시
  }
}
```

## 🎯 특수 차트

### 게이지 차트 (Gauge Chart)

#### 언제 사용하나요?
- KPI 달성률 표시
- 단일 값의 상태 표현
- 목표 대비 현재 상황

#### 데이터 요구사항
- 단일 수치 값
- 최소값, 최대값 범위

#### 설정 옵션
```javascript
{
  min: 0,
  max: 100,
  splitNumber: 10,       // 눈금 개수
  axisLine: {
    lineStyle: {
      color: [            // 구간별 색상
        [0.3, '#67e0e3'],
        [0.7, '#37a2da'],
        [1, '#fd666d']
      ]
    }
  }
}
```

### 워드클라우드 (Word Cloud)

#### 언제 사용하나요?
- 키워드 빈도 시각화
- 텍스트 데이터 요약
- 트렌드 키워드 표시

#### 데이터 요구사항
- 단어/구문
- 빈도 또는 가중치

#### 설정 옵션
```javascript
{
  shape: 'circle',       // 모양
  rotationRange: [-90, 90], // 회전 범위
  sizeRange: [12, 60],   // 크기 범위
  gridSize: 8            // 단어 간격
}
```

### 캔들스틱 차트 (Candlestick Chart)

#### 언제 사용하나요?
- 주가 변동 표시
- OHLC 데이터 시각화
- 가격 변동성 분석

#### 데이터 요구사항
- 날짜/시간
- 시가(Open)
- 고가(High)
- 저가(Low)
- 종가(Close)

#### 사용 예시
```sql
-- OHLC 데이터 준비
SELECT 
    DATE(timestamp) as date,
    MIN(price) as low,
    MAX(price) as high,
    FIRST_VALUE(price) as open,
    LAST_VALUE(price) as close
FROM price_data
GROUP BY DATE(timestamp)
```

## 📐 복합 차트

### 믹스드 차트 (Mixed Chart)

#### 언제 사용하나요?
- 서로 다른 단위의 데이터 표시
- 추세와 값을 동시에 표현
- 복합적인 분석 필요 시

#### 구성 예시
1. **라인 + 바**
   - 바: 월별 매출액
   - 라인: 성장률

2. **영역 + 라인**
   - 영역: 누적 매출
   - 라인: 일별 매출

3. **바 + 파이**
   - 바: 카테고리별 매출
   - 파이: 전체 비중

#### 설정 방법
```javascript
{
  series: [
    {
      type: 'bar',
      yAxisIndex: 0,     // 첫 번째 Y축
      data: salesData
    },
    {
      type: 'line',
      yAxisIndex: 1,     // 두 번째 Y축
      data: growthData
    }
  ]
}
```

## 🎨 차트 선택 의사결정 트리

```
데이터 유형은?
├─ 시계열 데이터
│  ├─ 단일 시리즈 → 라인 차트
│  ├─ 다중 시리즈 → 멀티 라인 차트
│  └─ 누적 표현 → 영역 차트
├─ 카테고리 비교
│  ├─ 순위/크기 → 바/컬럼 차트
│  ├─ 비율/구성 → 파이/도넛 차트
│  └─ 계층 구조 → 트리맵
├─ 상관관계
│  ├─ 2개 변수 → 산점도
│  └─ 다차원 → 평행좌표
└─ 분포/밀도
   ├─ 2D 분포 → 히트맵
   └─ 통계 분포 → 박스플롯
```

## 💡 차트 디자인 베스트 프랙티스

### 색상 사용
1. **일관성**: 같은 카테고리는 같은 색상
2. **대비**: 중요 데이터는 강조색
3. **접근성**: 색맹 친화적 팔레트
4. **제한**: 5-7개 이하 색상 사용

### 레이블과 범례
1. **명확성**: 축 제목 필수
2. **간결성**: 짧고 명확한 라벨
3. **위치**: 데이터를 가리지 않게
4. **크기**: 읽기 쉬운 폰트 크기

### 데이터 표현
1. **정직성**: Y축은 0부터 시작
2. **맥락**: 비교 기준 제공
3. **단순성**: 불필요한 요소 제거
4. **일관성**: 같은 단위 사용
