# MCP와 외부 에이전트 연결

::: warning 현재 지원 상태
현재 VanillaMeta 배포본에는 외부 코딩 에이전트가 등록해 사용할 **VanillaMeta MCP 서버가 제공되지 않습니다**. 이 페이지는 작동하는 설정이 누락된 상태를 뜻하지 않습니다. 서버 패키지·실행 명령·MCP 접속 URL·인증 설정이 아직 제품으로 제공되지 않았습니다.
:::

## MCP는 어떤 역할인가요?

MCP는 AI 클라이언트가 서버의 도구와 문맥을 찾아 사용하도록 연결하는 프로토콜입니다. 일반적인 구성은 다음과 같습니다. [MCP 공식 아키텍처 안내](https://modelcontextprotocol.io/docs/learn/architecture)를 참고할 수 있습니다.

```text
코딩 에이전트의 질문
  → MCP 클라이언트
  → 해당 서비스의 MCP 서버와 인증
  → 허용된 도구 실행
  → 결과·미리보기·Artifact 주소
```

에이전트에 MCP 설정 칸이 있다는 것과 VanillaMeta가 그 서버를 제공한다는 것은 별개입니다.

## 현재 가능한 경로부터 시작하세요

1. 운영자는 [Codex 실행 엔진 연결](./agent-connection.md)을 준비합니다.
2. 사용자는 [프롬프트로 Artifact 만들기](./agent-artifacts.md)를 따라 앱에서 생성·미리보기·저장합니다.
3. 외부 에이전트에서는 요청문을 정리하고 앱에 전달할 수 있습니다. 현재 전용 MCP를 통한 직접 생성·저장으로 안내하지 않습니다.

현재 앱 내부 HTTP API는 있지만 MCP 프로토콜을 제공하는 서버와 같지 않습니다. `docs.vanillameta.net`은 사용 설명서 주소이며 MCP 서버 URL이 아닙니다. 앱 주소 뒤에 임의로 `/mcp`를 붙이거나 존재하지 않는 npm 패키지를 등록해도 연결되지 않습니다.

## MCP 직접 제작에서 목표로 하는 경험

아래는 **구현 후 검증할 목표**이며 지금 실행할 수 있는 기능 목록이 아닙니다.

1. 에이전트에서 내 계정으로 연결하고 접근 가능한 소스·지표를 찾습니다.
2. “총매출 숫자와 날짜별 추세를 만들어줘”라고 질문합니다.
3. 권한과 계산 기준이 확인된 전체 미리보기를 받습니다.
4. 사용자가 결과를 확인하고 저장을 요청합니다.
5. 새 대시보드 번호와 Studio 링크를 받아 브라우저에서 다시 엽니다.
6. 게시가 필요할 때 별도로 공개 범위를 확인합니다.

직접 연결이 제공되더라도 원본 소스 접근권·저장 충돌·복제 허용 같은 제품 규칙을 지켜야 합니다. 질문 하나로 만들더라도 저장과 공개 범위를 확인할 수 있어야 합니다.

## 정식 설정 가이드에 포함되어야 할 것

| 안내 항목         | 완료를 확인하는 방법                                                 |
| ----------------- | -------------------------------------------------------------------- |
| 설치와 버전       | 실제 배포된 서버 패키지 또는 실행 파일과 지원 버전 확인              |
| 연결 방식         | 제공된 실행 명령 또는 실제 MCP URL과 transport 확인                  |
| 로그인과 권한     | 내 사용자·조직으로 인증, 만료·회수·다른 계정 접근 차단 확인          |
| 클라이언트별 설정 | Codex·Claude Code 등 지원 클라이언트에서 실제 도구 목록 확인         |
| 질문에서 저장까지 | 질문 → 전체 미리보기 → 명시 저장 → Studio 링크 → 새로고침 실행       |
| 장애 복구         | 인증 실패·409·응답 유실에서 초안/요청을 보존하고 중복 생성 없이 복구 |

MCP 제공 전에는 복사해서 실행할 수 있는 설정 JSON이나 설치 명령을 이 문서에 싣지 않습니다. 지원 클라이언트와 실제 실행 증거가 확보되면 이 페이지를 정식 연결 절차로 갱신합니다. 별도 MK AI 프로젝트의 연동 계약은 이 문서의 범위가 아닙니다.
