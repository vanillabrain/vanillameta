# 화면과 이동

접속 주소와 로그인 계정은 운영자가 안내한 정보를 사용합니다. 아래 경로는 설치한 VanillaMeta 주소 뒤에 붙는 화면 경로입니다.

## 목적에 맞는 화면 고르기

| 목적                     | 화면·진입점                    | 경로                     |
| ------------------------ | ------------------------------ | ------------------------ |
| 내 대시보드 찾기         | 대시보드 목록·내 시각화 산출물 | `/dashboard`             |
| 질문으로 새 분석 만들기  | 질문으로 대시보드 만들기       | `/studio/new`            |
| 저장 분석 편집           | 해당 대시보드의 Studio         | `/dashboard/번호/studio` |
| 파일 연결                | 일반 CSV·JSON·Parquet 분석     | `/data/file`             |
| 연결 관리                | 데이터 연결 관리               | `/data`                  |
| 소스 탐색·Pivot          | 소스 Explore                   | `/explore/source`        |
| 직원·자원 권한 관리      | 계정 메뉴 → 조직·직원          | `/organization`          |
| 별도 조직 분석 접근 관리 | Studio → 조직 접근             | `/organizations`         |

표의 ‘번호’는 실제 대시보드 번호로 바꿉니다. 주소를 직접 입력해도 권한이 생기지는 않습니다.

## 처음 보이는 시작 항목

**질문으로 대시보드 만들기**는 새 분석을 만드는 시작점입니다. **샘플 대시보드 보기**는 이미 준비된 보고서를 엽니다. 샘플을 열었다고 내가 질문한 분석이 저장되는 것은 아닙니다.

**SQL 없이 차트 만들기**와 기존 데이터셋·위젯 편집기는 Studio와 별도 흐름입니다. 예전 위젯에서 가능한 모든 차트가 AI 생성에서 지원된다는 뜻은 아닙니다.

## Studio 화면 읽기

- 중앙: 숫자·차트·표 등 블록과 현재 배치
- 상단: 저장 상태, 되돌리기·다시 실행, 저장, 게시·공유
- 블록 설정: 선택한 블록의 설정과 AI 탭
- 분석 기준: 소스·기간·필터·계산 기준 확인

작은 화면에서는 보조 패널이 별도 창으로 열리거나 컨트롤이 다음 줄로 이동합니다. 편집창을 연 상태라면 해당 창의 AI 탭을 사용하세요.

## 메뉴가 보이지 않을 때

먼저 본인 계정과 조직, 자원 소유·접근권을 확인하세요. 일반 직원에게 관리자 기능이 보이지 않는 것은 권한에 따른 차이일 수 있습니다. [조직 공유와 권한](./organization.md)에서 확인 순서를 안내합니다.
