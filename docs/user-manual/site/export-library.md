# CSV 출력과 보관

## 현재 화면의 CSV와 파일 작업

지원되는 탐색 화면에서 현재 결과 내보내기와 **파일 작업**을 구별합니다. 파일 작업은 접수 당시 소스·지표 버전·조건으로 집계 CSV를 만들며, 이후 화면의 필터를 바꿔도 기존 작업의 기준은 바뀌지 않습니다.

## 고정 조건으로 CSV 만들기

**준비:** 현재 조직에 소속된 활성 계정과 해당 소스의 내보내기 권한이 필요합니다. 소스를 소유하거나 화면에서 조회할 수 있다는 것만으로 영속 파일 작업을 접수할 수 있는 것은 아닙니다. 조직 소속이 없다면 관리자에게 먼저 요청하세요. 현재 화면 CSV와 영속 파일 작업은 별도 경로입니다.

1. 유효한 집계 결과와 지표 버전을 확인합니다.
2. **파일 작업 펼치기**를 누릅니다.
3. **현재 조건으로 작업 접수**를 누릅니다.
4. 선택 작업의 **고정 조건·지표 버전 확인**을 읽습니다.
5. **CSV 만들기**를 실행합니다.
6. **선택 작업 다시 읽기**로 완료 상태를 확인합니다.
7. 준비 상태에서 **고정 파일 받기**를 누릅니다.

현재 화면 안내 기준은 최대 10,000행·2MiB, 접수 후 24시간입니다. 운영 설정과 표시된 제한을 확인하세요. 집계 CSV이지 임의 SQL이나 모든 원본을 무제한 추출하는 기능이 아닙니다.

## 작업 상태와 재시도

| 상태·상황         | 다음 동작                                  |
| ----------------- | ------------------------------------------ |
| 접수·대기         | 기준 확인 후 CSV 만들기                    |
| 실행 중           | 선택 작업 다시 읽기로 확인                 |
| 준비 완료         | 다시 실행하지 않고 고정 파일 받기          |
| 중단              | 고정 기준 확인 후 CSV 만들기로 명시 재실행 |
| 접수 응답 유실    | 같은 접수 재확인                           |
| 읽기 실패         | 작업 상태부터 다시 읽기                    |
| 더 이상 필요 없음 | 지원 상태에서 작업 취소                    |

**이전 작업 읽기**로 과거 접수를 확인합니다. 성공 알림은 과거 사건이며 다운로드 시점의 현재 권한을 대신하지 않습니다. 취소는 이미 내려받은 파일을 삭제하지 않습니다.

## 내 보관함

대시보드 목록의 **내 시각화 산출물**에서 검색·유형·정렬을 사용합니다. **기본 목록 / 보관함**을 구분해 본인 목록을 정리하고 복원합니다.

개인 보관은 원본 삭제나 다른 직원 공유 회수가 아닙니다. 자원 비활성·영구 삭제·조직 탈퇴는 별도 관리 절차입니다. 자료를 숨기려는 목적과 접근을 끊으려는 목적을 구분하세요.

## 관리자에게 요청할 때

자료 인계·조직 이동·탈퇴가 필요하면 현재 소유 자료와 남은 권한을 먼저 검토합니다. 단순히 내 목록에서 지워졌다는 사실을 인계 완료나 권한 회수로 간주하지 않습니다. 운영자의 별도 검토·동의 절차를 따르세요.
