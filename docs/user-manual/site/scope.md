# 지원 범위와 문서 기준

## 실제 화면으로 확인한 대표 여정

공개 합성 비용·마진 데이터로 다음을 실행한 캡처를 재사용합니다.

- 샘플·CSV 연결, 실제 AI로 숫자와 시계열 생성
- 미리보기 → 저장 → 새로고침
- 저장 분석의 시계열 제목 AI 수정 → 저장 → 새로고침
- 비공개 게시 → 링크 공개 재게시 → 익명 열람 → 게시 중지
- 소스 읽기 권한 → 직원 조회 공유 → 수신자 읽기 전용 열람
- 390·768·1440px 대표 화면의 크기·정렬 확인

이는 앞선 제품 검증 결과입니다. 이번 문서 사이트의 빌드·검색·탐색 검증과 구분합니다. 모바일 캡처는 Ego의 화면 크기 모사이며 실휴대폰 터치 검증이 아닙니다.

## 코드와 기존 기록을 대조한 안내

Explore·고급 Pivot·저장 지표 조합·CSV 작업·초안/충돌 복구·복제의 절차는 현재 UI 코드와 관련 기존 기록을 대조해 작성했습니다. 문서가 존재한다고 해당 기능의 모든 조합을 이번에 다시 실행한 것은 아닙니다. 외부 DB의 모든 드라이버, 운영 이전, 전 역할·전 기기, 전체 기업 요건 수용 완료도 뜻하지 않습니다.

## 현재 주의할 제한

| 항목        | 안내                                                 |
| ----------- | ---------------------------------------------------- |
| Studio 생성 | 지원되는 서버 저장 소스 하나, 최대 6개 블록          |
| 외부 연결   | 연결 성공과 Studio 지원 여부는 별도                  |
| 게시        | 저장본 스냅샷, 자동 실시간·예약 갱신을 전제하지 않음 |
| 재사용      | 복제 허용과 구성 지원 필요, 일부 Pivot 등 제한       |
| 초안 복구   | 계정·조직·화면·탭과 보관 조건에 따름                 |
| 직원 공유   | 대시보드 공유와 소스 읽기 별도                       |
| 기존 위젯   | AI Studio와 차트·공유 방식이 다를 수 있음            |

MK AI는 별도 프로젝트이며 이 문서는 별도 연동 계약·API·MCP를 제공한다고 설명하지 않습니다.

## Rill에서 참고한 점

[Rill Explore 안내](https://docs.rilldata.com/guide/dashboards/explore)의 화면 읽기 → 시간 범위 → 지표·차원 → 필터 → 비교 탐색과, 기능별 문서를 나누는 구성을 참고했습니다. 문장은 VanillaMeta 화면에 맞춰 새로 작성했고 제품 캡처는 자체 실행 화면입니다.

Rill의 전체 기능·백엔드·알림·커넥터 지원을 VanillaMeta가 동일하게 제공한다는 뜻은 아닙니다. 용어가 같아도 지원 범위와 권한·저장 방식은 해당 VanillaMeta 절차를 따르세요.
