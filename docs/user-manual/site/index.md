## 프롬프트로 Artifact 만들기

[에이전트 기반 제작 가이드](./agent-artifacts.md)에서 질문 → 숫자·시계열 → 수정·저장 → 게시·재사용을 한 흐름으로 따라 하세요. 운영자는 [Codex 실행 엔진 연결](./agent-connection.md)부터 확인합니다. 외부 에이전트에서 직접 연결하려면 [MCP 연결·직접 제작 실습](./mcp.md)을 따라 하세요.

## 기능별로 따라 하기

[50개 기능별 시나리오](./feature-scenarios.md)에서 목표·준비·조작·기대 결과·문제 해결을 한 항목씩 확인하세요. 샘플 연결부터 분석·게시·복제까지 결과를 직접 대조할 수 있습니다.

## 화면을 보며 실습하기

[화면으로 따라 하는 매출 분석 샘플](./sample-walkthrough.md)에서 실제 스크린샷과 입력값·예상 결과를 함께 확인하세요. 질문으로 대시보드 만들기, 고객 매출 비교, 주간 Pivot 저장을 순서대로 실습할 수 있습니다.

[조직 공유·재사용 샘플](./team-reuse-walkthrough.md): 소스 읽기 → 조회 공유·복제 허용 → 받은 자료 → 내 소스로 재계산·저장 → 회수 후 사본 보존을 실제 화면으로 따라 합니다.

::: tip 문서 보는 방법
왼쪽 메뉴에서 작업을 고르고, 오른쪽 목차에서 단계를 찾으세요. 작은 화면에서는 **메뉴**를 사용합니다. 상단 **문서 검색**으로 ‘재게시’, ‘소스 읽기’, ‘변화율’처럼 필요한 단어를 찾을 수 있습니다.
:::

이 가이드는 `develop`의 사용자 화면과 기능을 기준으로 작성했습니다. 화면 캡처는 공개 합성 데이터로 실행한 예시이며 설치 환경·권한에 따라 메뉴가 다릅니다. [문서 기준과 검증 범위](./scope.md)를 확인하세요.
