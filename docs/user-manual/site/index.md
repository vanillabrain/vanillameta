## 처음에는 이것 하나만 만들어 보세요

**총매출 숫자 + 날짜별 매출 차트.** 준비된 비용·마진 샘플로 시작하면 업무 파일 없이 질문·미리보기·저장을 경험할 수 있습니다.

[첫 아티팩트 만들기 →](./quickstart.md)

아티팩트는 **데이터와 계산 기준이 연결된 대시보드**입니다. 제품 화면에서는 ‘대시보드’로 표시되며, **Studio**에서 편집합니다. 코드를 작성하지 않아도 시작할 수 있습니다.
