# 아티팩트 이해하기

VanillaMeta에서는 **내 데이터로 숫자와 차트를 만들고, 수정·공유·재사용할 수 있는 결과물**을 아티팩트라고 부릅니다. 제품 화면의 이름은 **대시보드**, 이를 편집하는 곳은 **Studio**입니다.

예를 들어 “총매출과 날짜별 추세를 보여줘”라고 질문하면, 합계 숫자와 시계열 차트를 가진 분석을 만들 수 있습니다. 결과를 미리보고 저장한 뒤 제목과 배치를 다듬고 다른 사람에게 공유합니다.

![총매출과 날짜별 추세가 있는 아티팩트 미리보기](../images/02-ai-preview.png)

## 다섯 단계로 익히기

1. **이해하기:** 지금 읽는 페이지입니다.
2. **[만들기](./quickstart.md):** 샘플 선택 → 질문 → 숫자 확인 → 비공개 저장.
3. **[다듬기](./ai-edit.md):** 바꿀 블록 선택 → 질문하거나 직접 편집 → 저장.
4. **[공유하기](./publish.md):** 공개 범위 확인 → 게시 → 링크 확인.
5. **[재사용하기](./reuse.md):** 저장본을 복제하거나 내 소스를 연결 → 재계산 → 새 사본 저장.

## 처음에 알아둘 세 가지

| 화면의 말 | 이렇게 이해하세요 |
| --- | --- |
| 데이터 소스 | 분석할 파일이나 연결된 자료 |
| 블록 | 총매출 숫자, 매출 차트처럼 결과를 구성하는 한 조각 |
| Studio | 블록과 분석 기준을 편집하고 저장하는 화면 |

‘지표’는 **매출 합계처럼 계산할 숫자**, ‘차원’은 **회사별처럼 나눠 볼 기준**입니다. 처음부터 지표를 따로 정의할 필요 없이 샘플과 질문으로 시작할 수 있습니다. 필요한 용어는 [용어 찾아보기](./concepts.md)에 있습니다.

## 저장과 공유는 별개예요

AI의 제안은 아직 저장된 결과가 아닙니다. **미리보기에서 숫자 확인 → 저장**하면 다시 열 수 있는 내 대시보드가 생깁니다. 다른 사람에게 보여주려면 별도로 게시하거나 조직에 공유합니다.

아티팩트의 숫자는 선택한 데이터·기간·필터·계산법에 따라 달라집니다. AI의 설명과 함께 실제 계산 결과를 확인하세요.
