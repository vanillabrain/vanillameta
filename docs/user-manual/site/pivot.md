# Pivot으로 교차 분석하기

**목적:** 지표를 행·열의 조합으로 나누고 계층·부분합·시간별 변화를 비교합니다. 소스 Explore의 **Pivot**과 **고급 Pivot**은 서로 다른 구성 도구입니다.

## 기본 Pivot과 고급 Pivot

- **Pivot**: 제공되는 행·두 번째 행·열 차원을 선택해 교차표를 확인합니다.
- **고급 Pivot**: 여러 축의 구성, 계층, 시간 축, 셀 기준 정렬 등을 다룹니다.

먼저 기간·필터·지표를 정하고 전환하세요. 지표를 바꾸거나 파일을 갱신하면 결과를 다시 확인해야 합니다.

## 행·열 구성하기

1. **고급 Pivot**을 선택합니다.
2. **Pivot 필드 검색**으로 차원을 찾습니다.
3. 해당 차원을 **행에 추가** 또는 **열에 추가**합니다.
4. 행·열 차원 선택에서 순서를 확인합니다.
5. 교차표의 열 머리글과 각 행을 읽어 의도한 분류인지 확인합니다.

예를 들어 행을 회사, 열을 환경으로 구성하면 회사·환경 조합별 매출을 비교합니다. 소스에 실제 존재하는 차원을 사용하세요.

## 계층·부분합·총합

행 차원을 둘 이상 구성하고 **행 계층**을 켜면 상위 분류를 펼치거나 접어 하위 항목을 볼 수 있습니다. **모두 펼치기 / 모두 접기**를 사용할 수 있습니다.

합계는 지표 정의로 다시 집계한 값입니다. 비율·평균처럼 단순히 더할 수 없는 지표는 셀의 합과 총합이 다를 수 있습니다. 데이터에 조합이 없다는 표시와 실제 값 0도 구별하세요.

## Pivot 테이블과 Flat

**Pivot 테이블**은 행과 열을 나누어 교차값을 보여줍니다. **Flat**은 행·열 차원의 조합을 한 레코드 축으로 표시합니다. Flat에서는 열 셀을 지정하는 정렬 범위가 없으며 기존 셀 정렬이 행 기준으로 바뀔 수 있습니다.

## 시간 축 사용하기

1. 날짜 열을 행 또는 열 축에 포함합니다.
2. **시간 축**을 켜고 **시간 축 열**을 선택합니다.
3. **시간 집계**에서 일·주·월을 고릅니다.
4. 날짜 범위·표시 시간대와 시간 묶음을 확인합니다.

하나의 시간 축을 지정하는 방식입니다. 날짜가 문자열로 잘못 인식되었거나 선택한 축에 날짜 열이 없으면 사용할 수 없습니다.

## 현재값·변화량·변화율 정렬

1. **행 정렬 기준**에서 차원 이름 또는 지표를 고릅니다.
2. 지표 정렬이면 **정렬 범위**에서 **행 합계** 또는 특정 열 셀을 고릅니다.
3. **현재값 / 변화량 / 변화율** 중 계산 기준을 고릅니다.
4. **오름차순 / 내림차순**을 정합니다.

변화량·변화율 정렬에는 **이전 기간 비교**가 필요합니다. 비교를 끄면 현재값 기준으로 전환될 수 있습니다. 필터·시간 단위를 바꿔 정렬하던 셀이 사라지면 행 합계 기준으로 돌아갈 수 있으므로 정렬 표시를 다시 확인하세요.

## 저장과 재사용

유효한 결과에서 **탐색 보기 → 현재 조건 저장**으로 구성을 보관합니다. Studio의 **저장 Pivot 추가**는 지원되는 저장 정의를 블록으로 연결합니다. 모든 Pivot을 게시본에서 재사용할 수 있다고 가정하지 마세요.

::: info 안내 범위
