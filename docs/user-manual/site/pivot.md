# Pivot으로 교차 분석하기

**목적:** 지표를 행·열로 나누고 계층·부분합·시간별 변화를 비교합니다. [Explore](./explore.md)에서 소스와 저장 지표를 준비한 다음 진행합니다. **Pivot**과 **고급 Pivot**은 서로 다른 구성 도구입니다.

## 먼저 분석 기준 맞추기

이 예제는 공개 합성 **비용·마진 샘플**, 저장 지표 **매출(합계 revenue, USD, 소수 2자리)**을 사용합니다. 기간은 UTC `2025-01-13`~`2025-01-19`, 필터는 모두 해제합니다. 이 조건의 총합은 **9,636.75 USD**입니다.

고급 Pivot에서 이전값·변화량·변화율을 보려면 **이전 기간 비교**를 켜세요. 기본 Pivot은 현재 기간 교차표이며 이전 기간 비교를 제공하지 않습니다.

## 기본 Pivot: 행·열을 빠르게 고르기

1. 탐색 방식에서 **Pivot**을 누릅니다.
2. **Pivot 행 차원**은 `company`, **Pivot 두 번째 행 차원**은 `plan`을 선택합니다.
3. **Pivot 열 차원**은 `environment`를 선택합니다. 열을 나누지 않으려면 **지표만 표시**를 고릅니다.
4. 결과의 **전체 합계**와 **행 전체 합계**를 확인합니다.
5. **행·열 바꾸기**로 축을 바꾸거나 행·열 이름 버튼으로 해당 값을 필터링합니다. **Pivot CSV 내보내기**로 현재 결과를 받을 수 있습니다.

기본 Pivot은 첫 지표 값의 내림차순이며 최대 50행 × 12열 그룹을 표시합니다. **조합 없음**과 실제 `0.00`은 다릅니다. 표시 범위 제한이 있으면 안내와 CSV의 범위를 확인하세요.

## 고급 Pivot: 행·열 구성하기

1. **고급 Pivot**을 누릅니다. 기본 Pivot의 축 구성이 그대로 복사된다고 가정하지 말고 선택값을 확인합니다.
2. **Pivot 필드 검색**으로 필요한 필드를 찾습니다. 검색어를 지워야 다른 필드가 다시 보입니다.
3. `company`의 **+ 행**, `plan`의 **+ 행**, `environment`의 **+ 열**을 누릅니다. 이미 축에 포함된 필드는 중복 추가할 수 없습니다.
4. **행 차원 1 / 2**, **열 차원 1 / 2**에서 순서를 확인하거나 다른 필드로 바꿉니다. 각 축은 최대 두 차원입니다.
5. **구성 초기화**는 축 구성을 다시 시작할 때 사용합니다. 위쪽 기간·필터도 초기화됐다고 가정하지 말고 분석 기준을 확인하세요.

## 계층·부분합·총합

행 차원이 두 개일 때 **행 계층 꺼짐**을 눌러 **행 계층 켜짐**으로 바꿉니다. **모두 펼치기 / 모두 접기** 또는 상위 행의 화살표를 사용합니다. 회사 아래 요금제가 나타나며 상위 행에는 **부분합**, 맨 위에는 **총합**이 표시됩니다.

회사 이름 버튼은 필터이고 펼침 화살표와 다릅니다. 잘못 필터링했다면 상단 **적용된 필터 → 삭제**로 해제하세요.

합계는 지표 정의로 원본에서 다시 집계합니다. 비율·평균은 셀을 더한 값과 총합이 다를 수 있습니다. 고급 Pivot의 **값 없음**도 실제 0과 구별하세요.

## Pivot 테이블과 Flat

**Pivot 테이블**은 행과 열을 교차해 보여줍니다. **Flat**은 모든 차원의 조합을 레코드 형태로 보여줍니다. Flat에서는 행 계층을 사용할 수 없고 특정 열 셀의 정렬 범위도 없어집니다. **Pivot 테이블**로 돌아와도 계층·정렬 범위는 다시 확인하세요.

## 시간 축 사용하기

1. **열 차원 1**을 `day`로 바꾸고 **열 차원 2**는 **추가하지 않음**으로 둡니다. 날짜 필드는 행 축에 놓을 수도 있습니다.
2. **시간 축 꺼짐**을 눌러 켭니다. 날짜 필드가 축에 없으면 버튼을 사용할 수 없습니다.
3. **시간 축 열** `day`, **시간 집계** **주**를 선택합니다. 일반 날짜 문자열을 그대로 나누는 것과 날짜를 일·주·월로 묶는 것은 다릅니다.
4. 결과 머리글의 `2025-01-13`과 시간 축 안내 `day(week, UTC)`를 확인합니다. 예제 기간은 한 주이므로 주별 열이 한 개입니다.
5. 날짜 필드를 축에서 제거했다가 다시 추가하면 시간 축을 다시 켜야 할 수 있습니다.

위쪽 **집계 단위**와 Pivot의 **시간 집계**는 별도 설정입니다. 실제 교차표 시간 묶음은 **시간 집계**와 결과의 시간 축 안내를 확인하세요.

## 현재값·변화량·변화율 정렬

1. **행 정렬 기준**에서 **매출**을 고릅니다. **차원 이름**은 이름순입니다.
2. **정렬 범위**에서 **행 합계** 또는 특정 열을 고릅니다. 표의 지표 머리글을 눌러 그 열 셀 기준으로 정렬할 수도 있습니다.
3. **현재값 / 변화량 / 변화율**을 고릅니다.
4. **오름차순 ↑ / 내림차순 ↓** 버튼으로 방향을 전환합니다.

환경별 표라면 `production`의 매출 머리글을 누른 뒤 **변화량**을 선택해 해당 환경의 증감을 비교할 수 있습니다. 계층이 켜져 있으면 같은 계층 안에서 정렬합니다.

변화량·변화율에는 **이전 기간 비교**가 필요합니다. 비교를 끄면 현재값으로 전환됩니다. 시간 축·필터·열을 바꿔 정렬하던 셀이 사라지거나 Flat으로 바꾸면 **행 합계** 기준으로 돌아갈 수 있습니다. 이전값이 없는 행의 변화율을 0%로 읽지 마세요.

## 저장과 새로고침 복원

### 고급 Pivot

1. 결과 조회가 끝나면 **탐색 보기**를 엽니다.
2. **새 보기 이름**에 `주간 매출 Pivot`을 입력하고 **현재 조건 저장**을 누릅니다.
3. 새로고침 후 같은 소스의 **탐색 보기 → 저장한 탐색 보기 → 보기 열기**로 복원합니다.
4. 고급 Pivot 전환, 행·열, 시간 축·주, 비교, 정렬과 총합을 확인합니다. 목록에서 선택만 해서는 적용되지 않습니다.

### 기본 Pivot과 대시보드 재사용

기본 Pivot에서는 **저장 보기**를 사용합니다. **탐색 보기**와 별도 목록이며 두 화면의 저장 도구를 혼동하지 마세요. 지원되는 저장 Pivot은 대시보드에 추가할 수 있지만, 고급 Pivot의 모든 구성을 Studio 블록으로 자동 변환하는 것은 아닙니다.

## 모바일에서 확인하기

입력과 버튼은 다음 줄로 이동하며 표는 별도 영역에서 가로 스크롤됩니다. 왼쪽의 행 이름과 합계만 보이면 **표 안을 좌우로 스크롤**해 날짜·환경 열을 확인하세요. 페이지 전체를 옆으로 밀 필요는 없습니다.
