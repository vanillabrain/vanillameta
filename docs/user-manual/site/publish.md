# 게시하고 공유하기

**목적:** 검토한 저장본을 읽기 전용 스냅샷으로 전달하고, 공개 범위·갱신·중지를 관리합니다.

## 저장과 게시의 차이

저장은 내 편집 가능한 대시보드를 갱신합니다. 게시는 저장본을 바탕으로 읽기 전용 게시본을 만듭니다. 이후 초안이나 저장본을 바꾸어도 게시본은 별도 재게시 전까지 그대로입니다.

## 공개 범위 선택

| 선택                                     | 누가 열 수 있나요?    | 용도                           |
| ---------------------------------------- | --------------------- | ------------------------------ |
| 비공개 · 로그인한 소유자만 조회          | 로그인한 소유자       | 게시 결과 본인 확인            |
| 링크 공개 · 링크가 있는 모든 사람이 조회 | 링크를 가진 사람      | 익명 열람을 허용할 자료        |
| 조직 조회 공유                           | 현재 권한을 가진 직원 | 사내 계정 기반 전달, 별도 기능 |

::: warning 사내 전용 자료
‘링크 공개’는 사내 전용 권한이 아닙니다. 직원에게만 전달하려면 [조직 공유](./organization.md)를 사용하세요. 비공개 게시 링크를 전달하는 것만으로 직원 권한이 생기지도 않습니다.
:::

## 처음 게시하기

1. 분석을 미리보고 **저장됨** 상태를 확인합니다.
2. **게시·공유**를 엽니다.
3. **게시할 저장본 기준**과 분석 기준을 확인합니다.
4. 공개 범위를 선택합니다.
5. 필요하면 **링크 만료 시각 (내 시간대)**을 지정합니다. 링크 공개에서 비워 두면 게시 시점부터 서버의 기본 기간(최대 30일) 뒤에 만료됩니다. 직접 지정할 때도 최대 30일이며 재게시하면 만료 시각을 다시 정합니다. 게시 결과에 표시된 실제 만료 시각을 확인하세요.
6. **내 데이터로 복제 허용** 여부를 검토합니다. 구성에 따라 제한될 수 있습니다.
7. **게시하기**를 누르고 버전·범위·만료를 확인합니다.
8. **게시본 열기**로 확인하고 **링크 복사**로 전달합니다.

## 수정한 내용 재게시

**수정 → 미리보기 → 저장 → 게시·공유 → 재게시** 순서로 진행합니다. 새로 열린 게시본의 제목·숫자·차트가 저장본과 맞는지 확인합니다. 링크 복사만 다시 하는 것은 재게시가 아닙니다.

자동 실시간·예약 갱신을 전제로 사용하지 마세요. 자료나 지표가 바뀌었다면 새 기준으로 계산하고 저장한 뒤 게시본에 반영합니다.

## 중지·만료·권한 변경

**게시 중지 → 중지 확인**을 누른 뒤 기존 링크를 확인합니다. 만료나 현재 게시자·소스 권한 변경으로도 열람이 제한될 수 있습니다. 이미 열람·다운로드한 내용이나 만들어진 독립 사본을 원격으로 지우는 것은 아닙니다.

## 기존 위젯 공유와 구별

이 가이드는 Studio의 `/published/…` 스냅샷 기준입니다. 기존 위젯의 `/share/…`, `/embed/…`는 별도 기능입니다. 동작과 권한을 같은 것으로 가정하지 마세요.
