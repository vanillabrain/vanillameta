# 지표와 차원

**목적:** 같은 데이터를 보고도 합계·평균·비율을 혼동하지 않고, 분석에 적용된 계산 기준을 확인합니다.

## 지표를 고를 때

비용·마진 샘플에서 `revenue` 합계는 총매출, `cost` 합계는 총비용입니다. `company`로 나누면 회사별 매출이 됩니다. `day`를 일 단위로 나누면 일별 추세입니다.

| 질문           | 계산 관점                       | 주의할 점                     |
| -------------- | ------------------------------- | ----------------------------- |
| 총매출은?      | 매출 합계                       | 통화·기간·취소 처리           |
| 평균 매출은?   | 행 기준 평균                    | 행이 주문인지 날짜 집계인지   |
| 마진율은?      | 집계 이익 ÷ 집계 매출 × 100     | 행별 비율의 단순 평균과 다름  |
| 회사별 비중은? | 회사 매출 ÷ 비교 대상 전체 매출 | 분모에 같은 필터를 적용했는지 |

숫자 표시를 바꾸는 것과 계산식을 바꾸는 것은 별개입니다. `1.5`를 `150%`로 표시하려면 원래 계산의 배율부터 확인합니다.

## 저장 지표 확인하기

Studio의 저장 지표 선택에서 이름·ID·버전으로 찾고 제공되는 계산 기준을 읽습니다. 생성안의 **계산 기준 확인**과 저장 분석의 기준 표시를 함께 확인하세요. 설명을 읽는 것만으로 현재 계산식이 변경되지는 않습니다.

저장 분석이 참조한 버전과 최신 지표 정의는 다를 수 있습니다. 여러 분석이 같은 지표를 써도 자동으로 최신 계산식을 채택했다고 판단하지 마세요.

## 저장 지표로 계산 만들기

지원되는 소스 화면의 **저장 지표로 계산 만들기**를 사용합니다.

1. **계산 지표 이름**을 입력합니다.
2. **계산 방식**에서 차이, 백분율 또는 차이의 백분율을 선택합니다.
3. **지표 A**, **지표 B**, 필요하면 **분모 지표 C**를 고릅니다.
4. 소수 자릿수를 선택하고 **계산 미리보기**를 실행합니다.
5. 계산과 단위를 확인한 후 **계산 지표 저장**을 누릅니다.

| 방식          | 의미              |
| ------------- | ----------------- |
| 차이          | A − B             |
| 백분율        | A ÷ B × 100       |
| 차이의 백분율 | (A − B) ÷ C × 100 |

같은 단위끼리 지원하며 다른 계산 지표를 다시 참조하는 것은 현재 제한됩니다. 분모가 0이면 값 없음으로 표시합니다. 전체와 그룹에서 각각 다시 계산하므로 그룹별 비율을 더해 전체 비율로 쓰지 마세요.

새 비율을 만들 때 분자와 분모가 같은 계산이면 거절됩니다. 다른 이름으로 저장한 지표라도 실제 계산이 같으면 같은 제한이 적용됩니다. `매출 ÷ 매출`은 카테고리별 매출의 **전체 대비 비중**을 뜻하지 않습니다. 거절되면 실제로 비교하려는 분자·분모를 다시 선택하세요. 기존 저장 지표와 게시본은 이 검사 때문에 자동 변경되지 않습니다.

차원과 지표가 같은 원본 열을 사용한다고 항상 잘못된 것은 아닙니다. 예를 들어 시각을 날짜로 묶은 뒤 그날의 서로 다른 시각 수를 세는 계산은 가능합니다. 반면 같은 분류 값으로 묶고 그 분류 값의 고유 개수만 세는 새 차트는 그룹을 의미 있게 비교하기 어려워 거절됩니다.

## 계산식 변경을 분석에 반영하기

변경 영향과 적용 대상 분석을 확인하고 **미리보기 → 저장 → 새로고침**으로 결과를 대조합니다. 새 지표 버전을 명시적으로 채택하는 흐름인지 확인하세요. 게시본에도 반영하려면 재게시가 필요합니다. 모든 과거 분석·게시 이력이 한 번에 바뀌는 것으로 간주하지 않습니다.

**완료 확인:** 대상 열·집계·단위·분모와 적용된 지표 버전을 설명할 수 있습니다.
