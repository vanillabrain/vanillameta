# 복제와 재사용

[스크린샷으로 따라 하는 조직 공유·재사용 샘플](./team-reuse-walkthrough.md)에서 두 계정의 입력과 결과를 함께 확인하세요.

**목적:** 검증된 대시보드 구성을 내 자료에 적용하고 원본을 보존합니다.

## 어떤 분석을 복제할 수 있나요?

| 시작점      | 조건                               | 결과                            |
| ----------- | ---------------------------------- | ------------------------------- |
| 내 대시보드 | 저장된 대시보드                    | 마지막 저장본의 사본            |
| 받은 자료   | 현재 조회 가능·소유자 복제 허용    | 내 소스로 만든 비공개 독립 사본 |
| 게시본      | 현재 열람 가능·복제 허용·지원 구성 | 내 소스로 만든 비공개 독립 사본 |

미저장 초안은 **저장본 복제**에 포함되지 않습니다. 복제 허용 여부가 보이지 않거나 비활성이라면 원본 권한과 구성 제한을 확인합니다.

## 내 저장본 복제

Studio에서 필요한 내용을 먼저 저장하고 **저장본 복제**를 사용합니다. 복사본 제목과 소스를 확인하고 미리본 뒤 저장합니다. 원본의 ID·공유 상태를 바꿔 쓰는 작업이 아닙니다.

## 받은 분석·게시본에 내 소스 연결

1. 현재 열 수 있는 원본에서 복제 동작을 엽니다.
2. 본인 소스를 선택합니다.
3. 원본에서 필요한 열과 본인 소스의 열을 연결합니다.
4. 숫자·날짜·차원 형식과 단위를 확인합니다.
5. 전체 미리보기에서 모든 블록과 조건을 확인합니다.
6. 저장해 새 비공개 사본을 만듭니다.
7. 새로고침해 소스와 결과를 확인합니다.

필수 열이 없거나 형식이 다르면 매핑과 소스를 수정합니다. 매출과 비용 열을 바꿔 연결하는 것처럼 이름만 맞춘 잘못된 연결은 오류가 없어도 의미가 달라질 수 있습니다.

## 질문으로 수정하고 다시 게시

사본을 Studio에서 열어 [AI 수정](./ai-edit.md)을 진행합니다. **미리보기 → 저장 → 새로고침 → 게시**를 확인하세요. 새 사본은 별도 공개 범위를 선택해야 합니다. 원본이 공개됐다는 이유로 사본도 자동 공개되지는 않습니다.

## 보존과 제한

원본 공유를 회수해도 이미 저장한 독립 사본은 남습니다. 복제 허용은 정의·조건·배치의 재사용을 포함하므로 허용 전에 확인하세요. 원본 소스의 자격 증명을 복사하는 기능으로 해석하지 않습니다.

Pivot을 포함한 일부 게시 구성의 재사용은 제한될 수 있습니다. 화면에 표시된 지원 여부를 따르고 모든 블록이 자동 교체된다고 가정하지 마세요. 요청 결과가 유실되었다면 새 복제 전에 완료 사본부터 확인합니다.
