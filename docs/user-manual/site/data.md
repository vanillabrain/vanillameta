# 데이터 연결

**준비물:** 분석 가능한 파일 또는 지원되는 연결 정보, 현재 로그인 계정. AI 분석은 서버의 AI 실행 환경도 준비되어 있어야 합니다.

## 샘플로 시작하기

1. **질문으로 대시보드 만들기**를 엽니다.
2. 목적에 맞는 샘플을 선택합니다.
3. 준비가 끝나면 **저장된 데이터**에서 해당 소스를 확인합니다.
4. 열 이름을 확인하고 [AI 분석 생성](./ai-create.md)으로 이동합니다.

| 샘플      | 용도                | 데이터 성격    |
| --------- | ------------------- | -------------- |
| 매출·환불 | 주문·환불 분석 연습 | 합성 샘플      |
| 비용·마진 | 매출·비용·이익 분석 | 공개 합성 샘플 |
| 앱 전환   | 전환 흐름 연습      | 합성 집계 샘플 |

샘플 선택은 소스 준비이며 AI 호출·대시보드 저장·게시와 별개입니다. 가이드에서 검산한 수치는 비용·마진 샘플을 기준으로 합니다.

## CSV·JSON·Parquet 연결하기

1. Studio에서 **파일 선택**을 누르고 지원되는 파일을 선택합니다. 또는 **일반 CSV·JSON·Parquet 분석**(`/data/file`)으로 이동합니다.
2. 표시된 행 수와 열 이름·형식을 확인합니다.
3. 재사용할 파일은 서버 저장을 완료합니다. 브라우저 안의 일회성 분석은 서버 저장과 다릅니다.
4. Studio에서 **저장된 데이터**를 고릅니다. 목록이 오래되었다면 **소스 새로 확인**을 사용합니다.
5. **데이터 검색**으로 소스를 찾고 필요하면 **데이터 업무 설명 확인**으로 설명을 읽습니다.
6. 간단한 합계와 날짜별 추세를 미리보고 원본과 대조합니다.

### 업로드 전 점검

| 확인      | 예시·이유                                     |
| --------- | --------------------------------------------- |
| 열 이름   | 질문에 실제 이름을 사용. 공백·중복 여부 확인  |
| 숫자 형식 | 통화 기호·쉼표가 섞인 문자열과 실제 숫자 구별 |
| 날짜 형식 | 유효한 날짜인지, 시간대가 무엇인지 확인       |
| 누락 값   | 0과 값 없음은 서로 다름                       |
| 통화·단위 | 원화·달러를 한 합계에 섞지 않기               |
| 집계 수준 | 주문 1행인지 이미 날짜별 합계인지 확인        |

필수 열 누락·날짜 오류가 나오면 안내된 항목을 고쳐 다시 준비합니다. 임의로 값을 채워 오류만 없애면 결과가 왜곡될 수 있습니다.

## 일별 분석을 위한 날짜 설정

1. 소스의 실제 열 이름과 형식을 확인합니다. `20260101`은 숫자, 날짜와 잘못된 값이 섞인 열은 문자열로 인식될 수 있습니다.
2. 숫자로 읽힌 날짜는 원본을 유효한 날짜 또는 날짜 문자열로 고쳐 다시 연결합니다. 숫자 열에 날짜 업무 유형만 지정해 변환할 수는 없습니다.
3. 데이터의 업무 설명 편집에서 날짜·시각 또는 날짜 문자열 열의 **업무 유형**을 날짜로 지정하고 실제 값과 맞는 **날짜 형식**을 선택합니다. 수정 권한이 없으면 소스 소유자에게 요청하세요.
4. 저장한 기준을 확인하고 Studio에서 소스를 새로 확인하거나 새 생성 요청을 시작합니다. 이미 만든 생성안이 새 기준을 자동으로 채택했다고 가정하지 않습니다.
5. 일별 데이터 표에서 같은 날의 여러 행이 한 날짜로 합산됐는지 확인합니다.

날짜만 저장된 열은 날짜별로 묶을 수 있습니다. 시각이 포함된 열을 그대로 사용하면 시각별 값이 나올 수 있어 업무 날짜 기준을 확인해야 합니다. 잘못된 날짜·공백은 먼저 원본에서 바로잡고, 변환 오류를 피하려고 임의의 날짜를 채우지 마세요.

## 외부 DB 연결하기

**데이터 연결 관리**에서 데이터 소스 생성 화면을 열고 지원되는 연결 유형을 선택합니다. 운영자가 준 접속 정보로 **연결 테스트 → 연결 저장**을 진행하세요. 서버에서도 해당 DB로 접속할 수 있어야 합니다.

연결 유형별 드라이버·인증 설정은 운영자가 준비합니다. 접속 비밀번호를 AI 질문에 넣지 마세요. 연결 테스트 성공이 모든 Studio 기능의 지원을 뜻하지는 않습니다. Studio에서 미지원 안내가 나오면 기존 데이터셋·위젯 흐름 또는 지원 파일 소스를 사용합니다.

## 파일을 교체하거나 다시 불러올 때

새 파일은 열·형식·데이터 버전을 바꿀 수 있습니다. 기존 미리보기를 그대로 저장하지 말고 새 기준을 확인해 다시 계산하세요. 기존 분석·게시본이 모두 자동으로 바뀐다고 가정하지 마세요. 오류가 나면 초안을 남긴 채 [문제 해결](./troubleshooting.md)을 따릅니다.

**완료 확인:** 소스 이름·열·형식과 간단한 합계가 의도대로 보입니다.
