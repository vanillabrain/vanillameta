# AI로 분석 만들기

**준비물:** 지원되는 서버 저장 소스 하나, AI 실행 환경. 현재 생성 흐름은 최대 6개 블록을 구성합니다.

처음 AI를 연결하는 운영자는 [Codex 실행 엔진 연결](./agent-connection.md)을, 질문에서 공유까지 한 번에 익히려는 사용자는 [Artifact 제작 실습](./agent-artifacts.md)을 먼저 확인하세요.

## 좋은 질문의 구성

‘매출 보여줘’보다 **보고 싶은 값 + 나눌 기준 + 기간 + 차트 형태 + 유지할 조건**을 적으면 결과를 확인하기 쉽습니다. 실제 소스의 열·저장 지표 이름을 사용하세요.

> 총매출 SUM(revenue)을 숫자 지표로, 날짜별 매출 추세를 시계열 차트로 만들어줘. 제목은 매출 분석으로 해줘.

질문에 없는 내용을 AI가 추측할 수 있으므로 계산 기준은 반드시 확인합니다. 접속 비밀번호·인증키를 질문에 넣지 않습니다.

## 일별 추이를 요청하기 전에

날짜 열이 날짜로 인식되는지 먼저 확인하세요. 날짜만 있는 열과 시각까지 있는 열은 집계 기준이 다릅니다. 문자열 날짜나 시각 열을 하루 단위로 묶으려면 [날짜 업무 유형과 형식](./data.md)을 확인합니다.

`order_date`가 날짜 열이고 `amount`가 집계할 금액 열이라면 다음처럼 실제 이름을 적습니다.

> `order_date` 날짜별 `amount` 합계를 선 차트로 보여줘.

열이 있는데도 필요한 데이터가 없다는 질문이 나오면, 그 열이 뜻하는 업무 값과 날짜 형식을 확인해 명시하세요. 열 이름이 매출처럼 보인다는 것만으로 결제액·상품금액·환불액을 같은 값으로 취급하지 않습니다.

## 현재 생성 요청의 지원 범위

AI 신규 생성과 **후속 질문 · 저장 전 편집**에서는 상위 N개 제한, 전체 대비 비중, 월·주·분기·연도 단위 생성 요청에 미지원 안내가 나올 수 있습니다. 이 경우 새 계산 결과가 만들어진 것이 아니며, 이전 미리보기가 남아 있어도 수정이 적용됐다고 판단하지 마세요. 저장된 분석의 기간·집계 컨트롤 지원 범위와 AI 생성 범위는 다릅니다.

제목만 바꿀 때는 이름을 따옴표로 구분하세요. 제목에 ‘월별’을 넣어도 계산이 월별로 바뀌지 않습니다. 실제 집계 기준과 맞는 제목을 사용합니다.

> 선택한 블록의 제목만 "날짜별 매출"로 바꿔줘. 지표와 날짜 기준은 유지해줘.

## 질문 → 미리보기

1. **질문으로 대시보드 만들기**를 열고 소스를 선택합니다.
2. **만들 대시보드 요청**에 질문을 입력합니다.
3. **지표와 차트 제안**을 누릅니다.
4. **계산 미리보기**에서 모든 블록을 확인합니다.
5. **계산 기준 확인**에서 대상 열·집계·지표 버전을 읽습니다.
6. **데이터 표 보기**로 숫자와 시계열의 기초 결과를 대조합니다.

![총매출 숫자와 날짜별 매출 시계열 미리보기](../images/02-ai-preview.png)

### 미리보기 체크리스트

- 숫자와 요청한 시계열이 모두 있는가?
- 합계·평균·비율이 요청과 일치하는가?
- 날짜 열·기간·시간대·필터가 맞는가?
- 통화와 소수점 표시가 적절한가?
- 비어 있는 결과·분모 0·누락 값을 0으로 오해하지 않았는가?

## 저장 전에 다시 질문하기

**후속 질문 · 저장 전 편집**에서 **수정할 블록**을 고른 뒤 **생성안 수정 요청**을 입력하고 **수정안 미리보기**를 실행합니다. 대화형 구성에서는 **수정안 전체 미리보기**로 표시될 수 있습니다.

> 숫자 지표는 유지하고 시계열 제목만 날짜별 매출로 바꿔줘.

변경 없는 응답은 수정 완료가 아닙니다. 남아 있는 초안을 확인한 뒤 대상을 명확히 해서 다시 질문합니다.

## 저장 → 새로고침

모든 결과가 맞으면 **Studio에 저장하고 열기**를 누릅니다. **저장됨** 상태를 확인한 뒤 새로고침하고 숫자·차트가 남는지 확인합니다. 저장과 게시는 별도이며 이 단계에서 공개 링크가 만들어졌다고 가정하지 않습니다.
