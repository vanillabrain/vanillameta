# Explore로 데이터 탐색하기

**목적:** 질문을 다시 쓰지 않고 기간·차원·필터를 바꿔 숫자와 추세의 원인을 확인합니다. 아래 절차는 소스 Explore(`/explore/source`) 기준입니다. 기존 보고서 Explore는 구성과 메뉴가 다를 수 있습니다.

## 1. 소스와 표시 항목 선택

소스 Explore를 열고 **데이터 소스**를 선택합니다. 제공되는 지표와 차원을 확인하고 **표시 설정**에서 볼 항목을 고릅니다. 지원되는 소스·저장 지표가 준비되어 있어야 합니다.

지표는 계산할 값, 차원은 나눠 볼 열입니다. 차원 목록의 순위는 선택한 **차원 순위 기준**과 **차원 순위 방향**을 따릅니다. 순위 변경과 필터 적용은 다릅니다.

## 2. 기간·시간대·집계 단위

1. **전체 기간**으로 전체 범위를 확인하거나 **사용자 지정**을 고릅니다.
2. **시작일 / 종료일**을 입력합니다.
3. 제공되는 **표시 시간대**와 **집계 단위**를 확인합니다.
4. 결과의 날짜 범위와 숫자를 확인합니다.

시간대와 집계 단위가 다르면 같은 원본도 날짜별 값이 달라질 수 있습니다. 시계열이 없는 소스나 지원되지 않는 구성에서는 시간 관련 선택이 제한됩니다.

## 3. 차원·숫자 필터

1. **필터 추가**를 누릅니다.
2. **필터 열**을 선택합니다.
3. 차원은 **값 검색** 후 원하는 값을 고릅니다. 숫자 열은 **값 선택** 또는 **숫자 범위**를 사용합니다.
4. 범위는 **최솟값 (포함) / 최댓값 (포함)**을 확인합니다.
5. 화면의 적용 동작을 실행하고 **적용된 필터**와 결과를 확인합니다.
6. 해제할 때는 해당 필터의 삭제 버튼을 사용합니다.

차원 순위에서 값을 선택해 필터로 적용하는 동작도 제공됩니다. 필터를 지웠다고 이미 저장된 게시본의 조건이 바뀌지는 않습니다.

## 4. 이전 기간 비교

지원되는 사용자 지정 기간에서 **이전 기간 비교**를 켭니다. 현재값·이전값·변화량·변화율을 함께 확인합니다. 변화율은 이전값을 분모로 하므로 이전값이 0이거나 없는 경우 일반 숫자로 비교할 수 없습니다.

전체 기간으로 돌아가면 비교와 정렬이 초기화될 수 있습니다. 비교 기간이 실제로 적용되어 있는지 먼저 확인하고 순위를 판단하세요.

## 5. 차원 추세와 조건 탐색

**차원 추세 비교**는 차원별 시간 흐름을, **집계 조건**은 조건별 집계 분석을 확인할 때 사용합니다. 조건에 사용할 열·분포·표본은 현재 선택과 접근권에 따라 제한됩니다. 상위 값이나 일부 표본을 전체 원본이라고 해석하지 마세요.

## 6. 탐색 보기를 저장하기

1. 원하는 결과가 나온 뒤 **탐색 보기**를 엽니다.
2. **새 보기 이름**을 입력합니다.
3. **현재 조건 저장**을 누릅니다.
4. 다음에는 **저장한 탐색 보기 → 보기 열기**로 복원합니다.

소스별 개인 보기는 최대 20개이며 이름은 80자 이내입니다. **보기 삭제**는 저장된 탐색 조건을 지우는 작업입니다. 소스 데이터 삭제와 다릅니다. 파일·지표 버전이 바뀌어 적용할 수 없으면 카탈로그를 다시 읽고 조건을 확인해 새 보기로 저장합니다. 원본 표 페이지는 첫 페이지로 돌아갈 수 있습니다.

**다음:** 행·열로 교차 분석하려면 [Pivot](./pivot.md), 결과를 파일로 받으려면 [CSV 출력](./export-library.md).
