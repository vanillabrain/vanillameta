# Explore로 데이터 탐색하기

**목적:** 질문을 다시 쓰지 않고 기간·차원·필터를 바꿔 숫자와 추세의 원인을 확인합니다. 이 절차는 **지표 탐색**(`/explore/source`) 화면 기준입니다.

## 1. 화면 열기와 지표 준비

1. 로그인한 뒤 **SQL 없이 차트 만들기** 화면 상단의 **지표 탐색**을 누릅니다. 설치 주소 뒤에 `/explore/source`를 붙여 직접 열어도 됩니다.
2. **데이터 소스**에서 서버에 저장한 파일 소스를 선택합니다. 파일이 없다면 [데이터 연결](./data.md)부터 진행하세요.
3. 저장 지표가 없으면 **지표 빌더**를 누릅니다. **지표 이름 → 집계 방법 → 집계할 열 → 단위·소수 자릿수 → 지표 저장** 순서로 준비하고 **지표 탐색**으로 돌아옵니다. 파일만 연결한 상태에서는 지표가 자동으로 만들어지지 않습니다.
4. 지표·차원 개수가 표시된 **표시 설정**을 펼쳐 볼 지표와 차원을 선택합니다. 하나 이상의 지표가 필요합니다.
5. 상단 **분석 기준**과 아래 숫자·추세·차원별 순위가 같은 소스와 기간을 가리키는지 확인합니다.

지표는 계산할 값, 차원은 나눠 볼 열입니다. **차원 순위 기준 / 차원 순위 방향**은 순서를 바꾸며 데이터를 제외하는 필터와 다릅니다.

::: tip 따라 할 예제
**내 데이터로 시작하기**(`/studio/new`)의 **비용·마진 샘플**을 준비한 뒤 이 화면에서 선택할 수 있습니다. 이 가이드 캡처는 공개 합성 데이터 18행을 사용합니다. 지표 빌더에서 `매출`, `합계`, `revenue`, 단위 `USD`, 소수 `2자리`로 저장했습니다. 전체 매출은 **14,937.49 USD**입니다. 소스 번호·지표 번호는 설치마다 달라집니다.
:::

## 2. 기간·시간대·집계 단위

1. **전체 기간**으로 전체 범위를 보거나 **사용자 지정**을 누릅니다.
2. **시작일 / 종료일**을 모두 입력하고 날짜 입력을 확정합니다. 입력 도중에는 결과가 일시 중지됩니다. 별도 기간 적용 버튼 없이 완성된 기간으로 다시 조회합니다.
3. **표시 시간대**와 **집계 단위**의 **일 / 주 / 월**을 고릅니다.
4. **분석 기준**의 기간과 결과 아래 **적용됨** 안내를 확인합니다.

예제에서 UTC 기준 `2025-01-13`~`2025-01-19`를 입력하면 두 날짜를 포함한 매출은 **9,636.75 USD**입니다. 날짜 범위는 데이터의 날짜이며 현재 달력 날짜와 다를 수 있습니다. 시간대가 바뀌면 날짜 경계와 묶음이 달라질 수 있습니다.

날짜 열이 없거나 지원되지 않는 구성에서는 시간 선택이 제한됩니다. **차원 추세 비교**의 추세는 화면 안내대로 UTC 기준입니다.

## 3. 차원·숫자 필터

### 차원 값을 골라 적용하기

1. **필터 추가 → 필터 열**에서 `company`를 고릅니다.
2. **값 검색**에 `Hanul`을 입력하고 `Hanul Foods`를 체크합니다. 검색만으로는 필터가 적용되지 않습니다.
3. **필터 적용**을 누릅니다.
4. **적용된 필터**에 `company: Hanul Foods`가 생기고, 위 예제 기간의 매출이 **2,260.00 USD**로 바뀌는지 확인합니다.
5. 해제할 때는 해당 칩의 **삭제**를 누릅니다. 차원 순위의 값 버튼을 눌러 바로 필터링할 수도 있습니다.

![고객 필터와 이전 기간 비교를 적용한 결과](../images/13-explore-filter-1440.png)

### 숫자 범위로 좁히기

1. 앞의 고객 필터를 삭제합니다.
2. **필터 추가 → 필터 열**에서 `revenue`를 고릅니다.
3. **숫자 범위**를 누르고 **최솟값 (포함)** `1000`, **최댓값 (포함)** `2000`을 입력합니다.
4. **필터 적용** 후 같은 기간의 매출 **4,810.40 USD**를 확인합니다.

이 범위는 **집계된 매출 합계가 아니라 원본 각 행의 revenue**에 적용됩니다. 양 끝값은 포함하고 NULL은 제외하며, 한쪽을 비우면 그쪽 제한이 없습니다. 공통 필터는 최대 5개 열까지 적용합니다. 다른 조건이 남아 있으면 예제 숫자와 달라질 수 있습니다.

## 4. 이전 기간 비교

사용자 지정 기간을 완성한 다음 **이전 기간 비교**를 켭니다. 예제의 1월 13~19일은 바로 앞 같은 길이인 1월 6~12일과 비교합니다.

| 확인 항목    | 예제 결과     |
| ------------ | ------------- |
| 현재 매출    | 9,636.75 USD  |
| 이전 기간 값 | 5,300.74 USD  |
| 증감         | +4,336.01 USD |
| 증감률       | 약 +81.8%     |

이 표는 **필터 없음** 기준입니다. 고객 필터를 적용하면 두 기간 모두 같은 고객으로 다시 계산합니다. 이전값이 0이거나 없으면 일반 변화율로 해석하지 마세요. **전체 기간**으로 돌아가면 비교가 꺼지고 순위 기준이 초기화됩니다.

## 5. 차원 추세와 조건 탐색

**차원 추세 비교**에서는 **비교 차원 → 비교할 값(최대 4개) → 추세 비교** 순서로 진행합니다. **차원 값 검색**은 후보를 찾는 기능이며 비교할 값 선택과 별도입니다.

**집계 조건**은 조건별 집계 분석을 확인할 때 사용합니다. 조건 열·분포·표본은 현재 선택과 접근권에 따라 제한됩니다. 상위 값이나 일부 표본을 전체 원본이라고 해석하지 마세요. 적용한 분석 조건을 지원하지 않는 탐색 방식에서는 제한 안내를 먼저 확인하세요.

## 6. 탐색 보기 저장과 새로고침 복원

1. 결과 조회가 끝나면 **탐색 보기**를 엽니다.
2. **새 보기 이름**에 `고객 매출 비교`처럼 이름을 입력하고 **현재 조건 저장**을 누릅니다.
3. 브라우저를 새로고침합니다. 소스가 선택되지 않았다면 같은 **데이터 소스**를 다시 선택합니다.
4. **탐색 보기 → 저장한 탐색 보기**에서 이름을 선택하고 **보기 열기**를 누릅니다.
5. 기간·비교·필터·지표와 숫자가 저장 전과 같은지 확인합니다. 새로고침만으로 마지막 미저장 조건이 복구되지는 않습니다.

소스별 개인 보기는 최대 20개, 이름은 80자 이내입니다. **보기 삭제**는 탐색 조건만 지우며 소스 데이터나 게시본을 삭제하지 않습니다. 파일·지표 버전 변경으로 열 수 없으면 카탈로그를 다시 읽고 조건을 확인해 새 보기로 저장하세요. 원본 표 페이지는 첫 페이지로 복원됩니다.

**저장 보기**와 **탐색 보기**는 별도 목록입니다. 이 절차에서는 **탐색 보기**를 사용합니다. Explore 조건을 저장해도 Studio와 이미 게시한 대시보드가 자동으로 바뀌지 않습니다.
