# 문제 해결

## AI 실행 엔진이나 MCP 연결을 찾고 있습니다

앱의 AI 실행은 [서버 Codex 연결 가이드](./agent-connection.md)를 따릅니다. 외부 에이전트에는 [로컬 stdio MCP 서버](./mcp.md)를 연결합니다. 문서 주소를 HTTP MCP 주소로 입력하지 말고 Node·개인 연결 파일·서버 진입 파일의 절대 경로와 현재 계정의 인증·권한을 확인하세요.

## AI 편집이 안 보이거나 제목·설명만 보입니다

기존 설명·제목 편집과 Studio AI 분석 편집은 다릅니다. 저장한 분석의 Studio를 열고 **블록 설정 → AI** 탭을 확인하세요. 일반 질문은 **AI 열기**를 사용합니다. 구버전 화면이나 지원되지 않는 분석이면 운영자에게 현재 환경과 분석 유형을 알려주세요.

## 숫자만 나오고 시계열이 없습니다

생성 미리보기에서 요청한 시계열 블록이 있는지 먼저 확인합니다. 날짜 열 인식, 기간 내 행 존재, 선택한 시간 단위를 확인하세요. 제안에 없다면 실제 날짜 열을 명시해 다시 질문합니다. 저장 전에는 있었는데 저장 후 사라지면 대시보드 번호와 단계·오류를 기록해 문의합니다. 숫자 하나를 시계열 대신으로 해석하지 않습니다.

## 버튼이 비활성이거나 저장이 안 됩니다

미리보기 필요 안내, 진행 중 작업, 현재 편집권과 소스 접근권을 확인합니다. 지표·파일 버전이 바뀌었다면 다시 읽고 재미리보기하세요. 차트 구성 요소가 준비되지 않았다는 안내는 운영자가 서버 설정을 완료해야 해결됩니다. 같은 요청을 반복하지 말고 설정 완료 후 생성안의 유효 상태를 확인하세요.

## 날짜 형식 오류·필수 컬럼 누락

오류에 나온 열과 파일 형식을 확인합니다. 원본의 유효한 날짜·열 이름을 수정해 다시 연결합니다. 다른 소스로 교체했다면 필요한 열 매핑도 다시 확인합니다. 잘못된 값을 임의의 날짜나 0으로 채우지 않습니다.

## 일별 요청이 거절되거나 날짜마다 여러 점이 나옵니다

날짜 열의 실제 타입과 [업무 날짜 설정](./data.md)을 확인합니다. 질문에는 날짜·집계 열을 실제 이름으로 명시하세요. 시각 열을 그대로 묶은 결과를 일별 합계로 읽지 않습니다. 반복 실패하면 질문과 열 타입을 함께 기록하고, 아직 만든 결과가 없는 상태를 성공으로 처리하지 마세요.

## 비율 계산에서 분자와 분모가 같다는 안내가 나옵니다

이름이 달라도 실제 계산이 같을 수 있습니다. [저장 지표의 계산 기준](./metrics.md)을 확인하고 서로 다른 분자·분모를 선택하세요. 각 그룹의 금액을 자기 자신으로 나눈 값은 전체 대비 비중이 아닙니다.

## 직원이 공유한 대시보드를 못 엽니다

수신자 계정·조직·활성 상태, 대시보드 공유와 **소스 읽기 권한**을 각각 확인합니다. 관리자가 소스 권한부터 저장한 뒤 공유를 확인해야 합니다. 알림이 있다는 사실만으로 현재 접근 가능하다고 판단하지 마세요. [조직 공유 절차](./organization.md)를 참고합니다.

## 게시 링크를 전달했는데 열 수 없습니다

비공개는 로그인한 소유자만 조회합니다. 만료·게시 중지·게시자 또는 소스 권한 변경도 확인하세요. 다른 사람에게 열어 줄 목적이면 링크 공개와 조직 공유 중 알맞은 방법을 선택합니다.

## 저장했는데 게시본이 옛날 내용입니다

저장은 편집본, 게시는 스냅샷입니다. **저장 → 게시·공유 → 재게시**를 진행한 뒤 게시본을 다시 확인합니다.

## 충돌·끊김·새로고침 후 초안이 보입니다

질문과 초안을 확인한 뒤 [초안·충돌 복구](./recovery.md)를 따르세요. 최신 조회가 실패하면 조회부터 재시도합니다. 저장 성공 여부가 불확실하면 결과 확인 전에 새 저장을 반복하지 않습니다.

연결이 끊기거나 중지를 눌렀다는 사실만으로 서버의 저장까지 취소됐다고 단정하지 마세요. 실행 기록과 저장 결과를 확인한 뒤 다음 작업을 진행합니다.

## Pivot·CSV의 합계가 눈으로 더한 값과 다릅니다

기간·필터·지표 버전·정렬 범위와 상위 값만 표시되는지 확인합니다. 비율·평균은 그룹별 값을 더한 총합과 다릅니다. CSV 파일 작업은 접수 당시 고정 기준이며 현재 화면 조건과 다를 수 있습니다.

## 모바일에서 컨트롤이 잘립니다

설정창 내부 스크롤, 메뉴 접힘, 화면 확대 상태를 확인합니다. 긴 표는 표 안의 가로 스크롤을 사용합니다. 버튼이 겹치거나 페이지 전체가 옆으로 밀리면 사용 화면·폭·브라우저·캡처를 함께 전달하세요.

## 문의할 때 남길 정보

발생한 단계, 대시보드 번호, 소스 표시 이름, 예상 결과와 실제 결과, 발생 시각, 오류 문구, 브라우저·화면 크기를 기록합니다. 비밀번호·토큰·공개 링크 전체·고객 원본은 문의 캡처나 공개 이슈에서 숨기세요.
