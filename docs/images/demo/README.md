## 스크린샷 생성 가이드

1. VanillaMeta를 Docker로 실행
2. 각 시나리오를 따라가며 스크린샷 촬영
3. 이미지 크기: 1200x800px 권장
4. 파일 형식: PNG
5. 민감한 정보는 모자이크 처리
