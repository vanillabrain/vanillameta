# UC035 — 같은 대화의 생성안 수정·추가

2026-10-16. P3/FR008·009·011. [UC](../use_cases/UC-035-inline-proposal-refinement.md) · [설계](../architecture/inline-proposal-refinement.md) · [계획](../plans/UC-035.md) · [TC](../test_cases/TC-035-inline-proposal-refinement.md).

## 변경

저장 전 생성 미리보기의 `이 생성안 수정`을 펼쳐 대상 블록/새 블록 추가와 질문을 입력한다. 수정안 전체 미리보기 뒤 최신 생성안을 명시 비공개 저장한다. 기존 별도 생성 화면의 생성기를 재사용하고 현재 편집기에 AI operations를 적용하지 않는다. 기본 접힘으로 설정을 감추며 펼침 화살표·키보드 기본 동작을 유지한다.

creation/clarify의 수정 입력은 질문+대상이며 분모/소스 답변과 혼합하지 못한다. 소유 실행·완성 부모·소스 revision을 검증하고 기존 parentProposalId/targetBlockIndex 생성기로 전체 결과를 다시 계산한다. 미완성 결과/변경 없음은 이전 바인딩을 유지한다. 수정 중 단일화·마지막 완료 요청 hash·CAS는 UC033/034와 공유한다. 응답 불명확 시 질문·대상과 이전 미리보기를 보존하고 변경/저장을 잠근 뒤 동일 요청만 재확인한다. 실행 JSON에 수정 질문/계산식/미리보기를 추가 저장하지 않는다.

후속 질문이 분모를 명시하면 기존 판별기가 그 기준을 우선하고, 없으면 부모의 확정 기준을 캐시에서 이어받는다. 제목만 요청의 계산식/차트 변경 방지는 기존 생성기를 그대로 사용한다. 모든 자연어를 정확히 해석한다는 보장은 아니다.
