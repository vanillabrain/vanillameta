# Claude Code로 만든 차트의 조직 공유 리허설

2026-11-22에 운영 도움말의 두 프롬프트를 사용했다. 앱은 로컬 발표용 Compose 프로젝트 `vm-demo1123`, 메타데이터는 PostgreSQL 17, 호스트는 Claude Code 2.1.330, 브라우저는 Ego Lite였다. 운영 제품 배포는 별도다.

| 단계 | 실제 관측 |
| --- | --- |
| 운영 목차에서 튜토리얼 열기 | 페이지에서 두 프롬프트를 읽었다. |
| OAuth | VanillaMeta Demo에서 아티팩트 읽기·쓰기 범위를 확인하고 승인했다. Claude 콜백 화면에 Authentication successful이 표시됐다. |
| 생성 | Claude가 지역별 매출 차트 링크를 반환했다. 리비전 1의 표에서 서울 120·부산 80과 만 원 단위·합성 데이터 범례를 확인했다. |
| 수정 | 동일 Claude 대화에서 부산을 100만 원으로 수정했다. 같은 ID의 리비전 2를 새로고침해 서울 120·부산 100을 확인했다. |
| 재열기 | 상세 탭을 닫고 허브에서 제목·AI 유형으로 검색해 같은 차트를 열었다. |
| 공유 전 | 같은 조직의 시연 수신자에게 직접 GET은 404, 받은 목록에는 해당 ID가 없었다. |
| 공유 | 소유자가 수신자 로그인 ID를 입력해 읽기 권한을 부여했다. |
| 수신 | 별도 계정으로 로그인하고 공유받음에서 검색했다. 같은 ID의 리비전 2, 읽기 전용 상태와 두 금액을 확인했다. 수신자의 재공유 요청은 404였다. |

기록한 차트 ID는 `b23d4029-3382-4dc9-b0a9-caf57403d7b3`이다. 이번 시연 공유는 유지했다. 회수·중복 부여·계정 버전 변경·수신자의 수정 거절은 별도 서비스 회귀 테스트에서 확인했다.

최초 자동 실행기는 터미널 하이퍼링크의 주소와 표시 문자열을 붙여 읽어 OAuth 요청이 거절됐다. 실제 링크만 분리한 뒤 Ego에서 새 승인 요청을 실행했다. Docker 전체 백엔드 이미지 빌드는 발표 VM의 디스크 용량 한도에 걸렸다. 기존 발표 이미지에 이 체크아웃에서 컴파일한 변경 파일을 적용해 앱을 실행했고 DB 볼륨을 보존했다.

로컬 증빙은 `phase2-evidence/demo-20261122/claude-live-sharing-1795310655356/ego/`에 보관했다. `index.html`에 단계별 PNG 16장과 약 56초 분량의 영상을 연결했다. 영상은 Ego 화면 프레임 및 결과 캡처를 시간순으로 편집했다. CLI 화면은 실제 입출력을 읽기 좋게 표시한 화면이다. 계정 비밀번호 입력과 작업 대기는 생략했다.
