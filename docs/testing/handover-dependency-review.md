# UC051 인계 전 연결·보관 조건 검토 증빙

Status: Draft

[설계](../plans/UC-051-handover-review.md)·UC051 A5/BR-051-06·TC050 E02/E03의 선택 단위다. 수락된 고정 의향의 현재 소유자가 명시 연결의 선택 누락과 파일/외부 연결 보관 검토 필요를 조회한다. 실제 인계·퇴사·전체16개/TC050 수용은 Open이다.

## 구현 범위

`GET /enterprise/handover/:id/dependencies`와 조직 화면의 접힌 추가 검토를 추가했다. 기존 create/accept/cancel 계약과 schema를 유지한다. 수신자·일반 admin에게 새 의존성 정보를 공개하지 않는다. 모든 응답은 executionAvailable=false이며 covered는 선택한 명시 연결만 뜻한다. 원본 bytes/파일 경로/전역 역방향 사용처·임의 SQL 의존성·외부 계정 이전을 검증하지 않는다.

analysis/structured/Pivot/Studio/legacy widget→dataset/table의 저장 연결을 중복 제거하고 누락 본인 소스·타인/소유 미확인·누락/손상 참조를 구별한다. 소스 카드는 비활성 포함 지표 건수와 파일/외부 연결의 별도 보관 검토만 표시한다. 소스에 대시보드용 ‘필요 소스0개’ 목록을 반복하지 않도록 실제 화면 확인 후 간소화했다. 미선택 ID/제목·SQL·경로·설정·hash·링크는 응답하지 않는다.

## Ego104 실제 화면과 HTTP

전용 격리 SQLite 서버·합성 계정/조직/metadata만 사용했다. 원본 파일을 만들거나 외부 DB에 연결하지 않았다. 두 수락 요청은 배경 API로 준비했으며 요청 생성/수락 UI를 이번 새 검토 UI 실행으로 합산하지 않는다.

소유자 로그인→요청 번호 조회→접힌 연결 검토 열기→명시 조회로 필요한 소스3/선택1/본인 누락1/타인1과 비활성 포함 지표1·파일 보관 별도 검토를 확인했다. 미선택 자료의 제목은 표시하지 않았다. 네트워크 offline 실패(status0) 후 이전 결과 제거·같은 요청 번호 보존→명시 재조회200을 확인했다. 가상 소스 제목을 배경 DB에서 바꾼 뒤 실제 조회409/이전 결과 비노출/요청 보존을 확인하고 fixture 원복 후 명시 재조회200으로 복구했다. 배경 변경을 실제 두 탭 UI 편집으로 해석하지 않는다.

새로고침 후 패널은 접힌 상태이며 결과를 복구/자동 실행하지 않는다. 요청 번호를 다시 입력해 다른 수락 요청을 명시 조회하면 선택 연결 포함과 실행 불가 안내가 함께 나온다. 실제 HTTP는 소유자200/수신자403/admin403/다른 조직403/익명401이며, 선택 연결이 포함된 요청도 executionAvailable=false다. Ego에서 정상 로그아웃/수신자 로그인→같은 요청 조회 시 고정 제목만 표시되고 연결 검토 패널은 숨겨짐도 확인했다. 순수 GET 검증 전후66개 표의 행/hash가 모두 같았다. UI 로그인/reload에 따른 기존 인증·로그인 이력 쓰기는 이 순수 GET 불변 검사와 구별한다.

최종390/768/1440 대표 화면을 메인이 열람했다. 조회 버튼36px·접기 도구32px·입력36px/글자16·16·14px, 가로 넘침0, 상세 한계 접힘을 실측했다.390/768은 카드 세로8px 간격,1440은 두 카드 top 차이0px다. viewport768의 콘텐츠 폭은 scrollbar 포함753px로 카드가 한 열인 실제 상태를 기록했다. 실제 휴대폰 검증은 아니다. 개발 화면 HMR로 접힌 패널과 stale 요소 참조는 같은 공간에서 재조회했으며 전체 브라우저 차단으로 해석하지 않았다.

## 문서와 미완료

UC051 A5/BR-051-06·TC050 E02/E03·완료 계획·entity의 비영속 읽기 투영을 동기화했다. 초기 설계 lint의 A5 Trigger/Flow 누락은 보완했다. 선택 문서 lint와 pin 검증, 전역 lint의 기존 오류는 별도로 기록한다. 비공개 증빙/계정·경로는 Git 제외 디렉터리에만 보관한다. 승인 packet은 awaiting_review/acceptance not_recorded를 유지한다.
