# UC050 생성 미리보기의 계산 기준 일치

## 범위와 구현

2026-10-18·비교 기준 `0a5bac51`. FR015·BR050-02·[계획](../plans/UC-050.md)의 계산 의미 확인이다. 선택기/생성 미리보기의 필드 표현을 `StudioMetricBasis`로 공유한다. 기존 선택기에서 추가된 읽기 전용 상세를 재사용하며 BE/API/DB/의존성·SQL/LLM·제안/저장 payload와 숫자/차트 계산은 변경하지 않는다. 새 Entity/요구사항 상태·전체 UC/TC 수용 상태도 바꾸지 않는다.

선택기는 기존 목록/선택/검색·2열→599px이하1열/264px 내부스크롤을 유지한다. 생성 미리보기는 저장 지표ID/정의버전과 집계/열 요약·차원을 유지하고, 접힌 계산 기준에서 aggregation/column/denominatorColumn/weightColumn/scale/unit만 읽는다. 기존 분모 행의 scale??1 추측은 제거했다. 비율의 분모·배율, 가중평균의 가중치, 집계의 대상 열이 없거나 올바른 표시 타입이 아니면 미확인이다. 단위 없음은 미지정, 집계 없음은 기준 미확인 안내다. 문자열은 React 텍스트로 표시하고 scale은 유한 숫자만 표시한다. SQL/연결정보·기타 정의 필드는 렌더하지 않는다.

현재 지표 목록을 재조회하거나 선택기의 최신 정의로 생성안을 보충하지 않는다. 생성안이 담고 있는 기준과 서버 계산 결과만 나란히 보여준다. 단위 필드는 업무 기준의 참고값이고 실제 숫자/차트의 prefix/suffix·자리수는 기존 preview 응답을 그대로 사용한다. 누락 안내는 임의 보완/정의 유효성 승인·수치 재검증을 의미하지 않는다. 현재 스키마·저장 버전·수치 정답 확인은 기존 서버의 제안/미리보기/저장 경계가 유지한다.

## 디자인과 미확인

기존 미리보기 grid/카드·숫자·차트 컨테이너 크기와 선택기 스크롤 경계를 유지하고 common text-xs·줄바꿈/min-width·focus outline/native summary를 재사용한다. 펼친 기준은 같은 카드 안에만 추가되며 기본은 접힘이다. 실제 부모 정렬/긴 열명/모바일 넘침·포커스/터치·3폭 치수는 확인하지 않아 디자인 PASS가 아니다. Ego 제어권을 재탈취하거나 새 공간을 만들어 우회하지 않았다. 전체 UC050/TC050·조직 승인·운영MySQL/실기기/고객 수용은 미완료다.
