# Claude Code에서 만든 아티팩트의 발표 리허설

2026년 11월 22일, 제품 커밋 `435cce0f`에서 공개 도움말 목차를 열고 실제 Claude Code 2.1.330과 VanillaMeta를 연결했다. 새 대화의 첫 요청부터 지정 수신자의 공유 회수 확인까지 포함한 전체 진행 시간은 67.531초였다. 발표 서버는 로컬 Docker Compose와 PostgreSQL 17이고, 실험 자료는 모두 합성 데이터다. [화면 녹화](./media/artifact-customer-rehearsal-20261122.mp4) · [실행 결과 JSON](./media/artifact-customer-rehearsal-20261122.json)

## 증빙 읽는 법

녹화의 대화 장면은 Claude Code 프로세스의 실제 입력과 출력을 브라우저에 표시한 것이다. OAuth·차트·허브·공유 장면은 실행 중인 서비스 화면이다. 영상은 Ego 화면 캡처를 촬영 시각대로 재생하며 음성은 포함하지 않는다. [버전·검색·재사용 검증 영상](./media/artifact-version-workflows-20261122.mp4)은 기능별로 나눠 기록했다. 일회용 조직 연결 코드를 전달하는 구간은 영상에서 생략했다. 단계별 PNG와 PostgreSQL 비교 결과는 로컬 `phase2-evidence/demo-20261122/artifact-release-1795318100504/index.html`에서 볼 수 있다. [고객 튜토리얼](../user-manual/site/codex-first-chart.md)

관련 프런트엔드 4개 스위트의 79개 검사와 백엔드 조회·공유 서비스 2개 스위트의 7개 검사를 확인했다. 서버·클라이언트 TypeScript 검사와 이미지 빌드가 통과했다. 과거 DB 업그레이드에서는 migration 1개가 적용되고 재실행에서는 0개였다. 기록이 없는 과거 버전은 생성하지 않는다.

이 리허설의 외부 호스트 모델은 `claude-sonnet-5-5`다. 제품 내부의 `gpt-6-luna` 설정은 별도다. 운영 사이트에서 확인한 범위는 기존 도움말의 진입 경로다. 새 도움말과 조직 연결 안내는 발표 브랜치의 로컬 빌드에서 확인했다. 실제 고객 수용과 VoiceOver 발화는 미검증이며 공유 범위는 같은 조직의 지정 수신자다.

## 발표 직전 연결 해제 재검증

인계서의 로컬 별칭 `vm-customer-demo`로 승인한 새 Claude 연결을 사용했다. CLI에서 `Connected`를 확인한 뒤 소유자가 **외부 AI 연결 → 연결 해제 → 연결 해제 확정**을 선택했다. 목록을 다시 읽었을 때 활성 연결은 0개였다. PostgreSQL에는 이 환경에서 만든 승인 7개 모두 해제 상태로 남았고, 같은 Claude Code 클라이언트는 즉시 `Needs authentication`을 반환했다. 아티팩트 공유 회수와 AI 연결 해제는 서로 독립된 조작이다. [실제 연결 해제 영상](./media/artifact-connection-revocation-20261122.mp4)

검증 환경 정리 중 한 차례 Ego 소유자 탭의 페이지 이동이 지연되어 연결 해제 결과를 확인할 수 없다는 안내를 보았다. 당시 로컬 웹·API는 HTTP 200이었다. 이후 동일 원본에 다시 접속해 저장된 차트와 권한을 확인하고, 위 새 승인으로 해제 단계를 검증했다. 일시적인 지연의 원인은 확정하지 못했다.
