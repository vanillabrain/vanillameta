# UC034 — 필수 열 누락의 같은 대화 복구

2026-10-16. P3 / FR008·009·011. [UC](../use_cases/UC-034-inline-source-recovery.md) · [설계](../architecture/inline-source-recovery.md) · [계획](../plans/UC-034.md) · [TC](../test_cases/TC-034-inline-source-recovery.md).

## 변경과 경계

필수 열 누락 카드는 기존 권한별 소스 목록에서 다른 DuckDB 소스를 선택하고 `이 소스로 미리보기`로 원 질문을 다시 실행한다. 소스 선택만으로 모델/저장을 실행하지 않는다. 원 질문·이전 분모 답변은 서버 캐시에서 가져오며 클라이언트가 질문/계산식을 바꾸지 않는다. 소스 접근과 snapshot/계산 검증은 기존 생성기를 사용하고 완료 직전 원 실행 바인딩을 재확인한다. UC033과 같은 진행 Map/마지막 완료 영수증/취소 경계로 소스 답변과 분모 답변·저장의 경합을 처리한다.

대화 카드에는 실제 분석 소스 ID/이름을 표시한다. 시작한 편집기의 소스·정의·모든 폭 배치는 유지한다. 새 소스에도 열이 없으면 부족한 열을 다시 안내하고 저장을 막는다. 목록 조회 실패는 읽기 재시도, 계산 응답 불명확은 선택 잠금·동일 답변 재시도다. 다른 소스가 없을 때는 기존 파일·원본 열 확인 화면으로 이어지는 링크를 남겼다. 임의 열 매핑/카드 내 업로드/영속 캐시 복원은 추가하지 않았다.

## Ego76 실제 실행

기존 실행 환경3698/4899→4898, SQLite/DuckDB, Codex gpt-6-luna. 원본35/source30과 source31은 기존 공개 Rill 복사 소스다. source32는 공개 합성 커머스37주문이며 고객 자료가 아니다. 새 게시/공유 링크는 만들지 않았다.

1. 원본35에서 `필드 refund_amount, revenue를 사용한 환불률 숫자와 날짜별 추세를 보여주는 새 대시보드`를 요청했다(실제 문장에는 열 이름을 backtick으로 감쌌다). 두 열이 없는 Rill 소스는 미리보기/저장 없이 누락을 안내했다. `다시 분석할 데이터` 목록은 접근 가능한 소스만 읽었다. 목록에는 SQLite가 있어도 선택 후보에서 제외한다.
2. source31 선택만으로 clarify POST가 발생하지 않았다. 명시 미리보기 후에도 두 열 누락 안내/저장 차단이 유지됐다. 다음 source32 선택→명시 미리보기→같은 카드의 환불률 분모 amount 답변→실LLM 숫자21.23%+날짜별 선 차트37행을 확인했다. 해당 여정은 URL35/탭1개를 유지했다.
3. 명시 비공개 저장→새 대시보드43/source32. dashboard/state/생성 영수증 각1개 증가, metric 증가0(기존26 재사용), publication 증가0이다. 원본35의 document/definitions/sourceRevision/DB 해시가 유지됐다. 완료 링크를 누른 뒤에만 선택적으로 p2 새 탭을 열었다.
4. 최종 BE 빌드로 재시작한 뒤43과 대화를 새로고침했다. 저장43의 숫자·두 블록·ID/정의/모든 폭 배치/revision과 완료 링크가 유지됐고 새로고침은 GET만 발생했다.
5. 마지막 서버에서 새 질문 `환불률 숫자와 날짜별 추세…`→분모 amount 답변→Rill 소스의 필수 열 누락→source32 선택→분모를 다시 묻지 않고 같은 숫자+시계열 미리보기로 회복됐다. 이 둘째 제안은 저장하지 않았다. requestAnswers는 캐시에만 있고 영속 실행에는 바인딩과 마지막 요청 hash만 추가된다.

독립 CSV 검증은 manifest SHA256 확인 후 Decimal로4457.60/20994.61×100=21.23211624316908%를 계산했다. 두 preview의21.232116243169088과 오차1e-12 이내다. Rill 광고 열을 매출/환불로 대체하지 않는 소스 경계를 확인했다. Rill 자체에 동일 AI 대화 UX가 있다는 비교 결과로 해석하지 않는다. 이번에 Rill 탐색/Pivot UI는 변경하지 않았다.
