# UC053 개인 권한 알림 검증

2026-10-18 · FR022/NFR005/007/008 첫 단위. [설계](../plans/UC-053-notifications.md)·[UC053](../use_cases/UC-053-distribute-artifacts.md)를 따른다. 직원/그룹 전달과 독립 사본 전체 구현은 아니다.

## 구현 결과

- 확정 권한 감사 이벤트(source/dashboard.permissions)를 본인·현재 조직으로 투영한다. 기존 이벤트도 포함한다. 별도 알림 생성/발송 worker가 없어 감사 이벤트 저장 실패 시 권한 transaction도 기존대로 실패하고, 성공한 권한은 알림 표시 상태 저장 실패와 독립이다.
- 본인 recipientId+eventId 표시 상태의 읽음/목록 제거는 단방향·동일 요청 멱등이다. 감사/자원/grant는 변경하지 않는다. 제거 후 read 요청이 와도 removed를 되돌리지 않는다.
- GET는 쓰기0/20행 cursor이며 active 계정/현재 소속을 재검사한다. 응답은 자원 번호/유형/권한 버전/시각/읽음만 포함한다. 알림은 현재 권한 증명이 아니다.
- 조직 화면의 admin/member 공용 접힌 알림함·32px 도구/14px 본문·wrap/min-w-0을 적용했다. 조회 실패는 목록을 숨기고 재조회, 쓰기 실패는 항목 보존/동일 재시도, 닫기·조직/계정 변경·unmount 이후 늦은 응답은 무시한다.
- SQLite additive migration과 감사 수신자/조직/이벤트 인덱스를 추가했다. 기존 원장/표시 상태를 두 번째 실행에도 보존한다. MySQL 실실행은 별도다.

## 별도 Main 검토

실행/구현 뒤 Main이 인증/현재 조직·응답 필드·read/remove 단방향·기존 grant 불변·커서·오래된 UI 응답을 별도 읽었다. SQLite raw timestamp의 UTC 보존과 같은 조직 내 계정 변경 시 알림 컴포넌트 key도 확인했다. 독립 에이전트 리뷰는 NOT_RUN이다. 기존 코어 회귀 결과는 아래 최종 증거를 따른다.
