# Explore·Pivot 가이드 실제 검증

2026-10-21 · develop/448c1a4c에서 시작했다. [계획](../plans/user-guide-explore-pivot.md), [Explore](../user-manual/site/explore.md), [Pivot](../user-manual/site/pivot.md). 문서와 해당 UI의 선택 범위 검증이며 전체 제품 수용은 아니다.

## 환경과 준비

- Ego TaskSpace126, 전용 Docker MySQL8.4.11, 전체 Nest/native DuckDB/Vite. 기존 사용자 서버·DB는 변경하지 않았다.
- 서버 API로 전용 계정과 공개 합성 비용·마진 소스를 준비했다. 매출 지표의 이름/합계/revenue/USD/소수2자리 저장은 실제 UI로 수행했다. 지표 준비를 AI 생성 실행으로 세지 않는다.
- 최신 develop의 TS7 의존성 누락으로 최초 빌드가 실패했다. 기존 CI의 legacy-peer-deps 설치 후 native 검사/Nest 빌드를 통과하고 감독기 restart200/새 API PID로 재시작했다. 초기 샘플 실패는 빌드/worker 준비 중의 결과로 구분했다.
- 검증 전제조건 등록의 과도하게 긴 ID는 로그인 UI 길이 제한에 맞춰 새 전용 계정으로 교체했다. 자동화의 날짜 fill만으로 React 상태가 반영되지 않아 브라우저 표준 날짜 입력을 실제 키로 확정했다. 대기 조건의 잘못된 예상값·셀렉터 실패를 제품 실패로 집계하지 않는다.
- 원시 치수·전용 자격증명은 Git 제외 증빙에만 보관한다. 캡처6개에는 합성 자료만 포함하며 토큰·게시 링크·기업 원문을 포함하지 않는다.

## 디자인·문서 보완

- 날짜 입력과 시간대 버튼, 고급 Pivot의 라벨 있는 select와 정렬/시간 축 버튼이 중앙 정렬되어 하단이14px 어긋났다. 해당 flex 그룹만 하단 정렬로 보완했다. API·계산·저장 동작 변경은 없다.
- 수정 후1440/768px의 정렬 select·방향 버튼 높이36px/하단 차이0px. 날짜 두 입력/UTC 버튼 하단 차이0px. 390px은 다음 줄로 배치된다.
- Explore·고급 Pivot 모두390/768/1440px 페이지 가로 넘침0. 입력/select 높이36px, 글자 desktop14px·768/390px16px. 작은 선택 버튼32px와 일반 버튼36px는 공용 UI Kit 구분을 유지했다.
- 390px Pivot의 표540px/내부 스크롤 영역356px/overflow-x:auto를 확인했다. 표 열이 화면 밖에 있어도 페이지 전체 넘침으로 계산하지 않는다. 문서에 표 내부 좌우 스크롤을 설명했다.
- 가이드 진입·지표 선행 준비·기간 확정/필터 적용 차이·숫자 범위 의미·비교 예제·기본/고급의 저장 목록 차이·복원 후 확인·시간 집계 차이를 추가했다. 캡처6개를 실화면에서 다시 촬영하고 확인했다.
- 가이드 자체도 Explore/Pivot×390/768/1440px에서 본문16px·전체 넘침0·새 이미지6개 로드/반응형 축소를 확인했다.

## 자동 검사와 전달

- FE SourceExplore/PivotTable:2 files/83 tests PASS. 변경 파일 ESLint PASS, Vite build PASS(기존 dynamic-import 경고 유지).
- BE 최신 의존성 native 타입 검사/Nest build PASS. 제품 BE 변경은 없다.
- 문서 root·/guide/ 하위 경로 모두21 HTML/859 로컬 참조 오류0. 초기 캡처 모음 include의 상대 링크2개 오류는 링크 경로 보완 후 해소했다. 검사 완화는 하지 않았다.
- Git diff 공백 검사와 새 공개 문서의 금지 출처/로컬 경로 검사를 수행한다. 실제 commit/push SHA와 자동 배포 판정은 Git/Actions 기록을 따른다.
- 감독기 stop200·ownedContainerRemoved=true·temporaryCredentialsRemoved=true·persistentVolumesCreated=0을 확인했다. 별도 전용 계정 인증정보 파일도 제거했다.

## 남는 범위

모든 지표/시간대/데이터 조합, 비율 합계의 전체 oracle, 조건 탐색·분포/표본 전 여정, 기본 Pivot 저장과 Studio 추가/게시, 실제 CSV 다운로드, 실휴대폰 터치, 운영 부하·운영 migration/기업 수용은 이번 검증 범위 밖이다. 기본 Pivot의 저장 도구는 코드와 실제 노출을 대조한 안내이며 이번에 대시보드 재사용까지 실행했다고 주장하지 않는다.
