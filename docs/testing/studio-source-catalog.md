# UC050 Studio에서 저장 업무 설명 확인

## 범위와 기준

비교 기준 `2352f716`·2026-10-18. FR014/015·BR050-02·[계획](../plans/UC-050.md)의 제한된 읽기 단위다. 신규 API/DB/의존성은 없다. `StudioSourceCatalog`를 생성/재사용 공용 `StudioSourcePicker`에 연결한다. 선택 profile과 sourceId가 일치할 때만 진입한다. 기존 `/bi/source-catalog/read`의 매 요청 소유권 검사/현재 프로파일 계약을 사용한다. BE 소스는 변경하지 않았다.

기본은 접힘/요청0이며 펼침/다시 조회만 읽는다. 저장 버전·소스 표시명/설명·열별 표시명/설명/단위를 원본 열/형식과 함께 보여준다. version0은 미등록 안내만 표시한다. 설명을 질문/LLM·계산식·차원·차트에 자동 반영하지 않는다. 조직 공식 승인 여부를 표시하거나 카탈로그 전체 구현으로 주장하지 않는다.

현재 sourceId/dataVersion·열 이름/형식·열 수/중복과 응답을 대조한다. 불일치/schemaChanged는 설명을 숨기고 소스 새로 확인을 안내한다. 잘못된 응답·403/503은 기존 표시를 지우고 재조회한다. profile의 소스/버전/열 변경은 접힌 새 snapshot으로 바뀌며 이전 응답은 무시한다. 접기 후 재열기는 새 조회다. 동등한 profile의 부모 렌더는 추가 조회하지 않는다.

## 디자인 기준과 남은 검증
