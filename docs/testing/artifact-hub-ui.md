# 아티팩트 허브 UI 첫 구현

2026-10-29 · develop · 기준 42710147. Figma 허브의 목록·그리드를 기존 산출물 목록에 적용하는 첫 단위다.

## 구현

- 기존 `/dashboard/library`의 허용된 자료, 검색·유형·정렬·보관·수정·삭제·Studio 링크를 유지한다.
- 목록·그리드를 전환한다. 검색 조건과 표시 방식은 `artifactQuery`, `artifactKind`, `artifactSort`, `artifactDisplay` URL 값으로 복원한다. 기존 `aiSourceId`는 보존한다.
- 그리드는 3열 데스크톱 카드와 40px 제어를 사용한다. 긴 제목의 두 줄 영역과 날짜·열기·관리 버튼의 위치를 맞춘다.
- 목록에 집계나 썸네일 API가 없으므로 차트 숫자를 만들지 않는다. 카드의 미리보기 영역에는 저장된 시각화를 열라는 안내를 표시한다.
- 대시보드 시작 페이지의 제목을 아티팩트로 바꾸고, 기존 자료가 있으면 온보딩을 접힌 영역으로 옮긴다.

Figma 전체 포팅은 아니다. 공통 사이드바·전체/공유받음의 통합 데이터 모델, Google/MS 문서, 원문 사본·요약, 원격 OAuth는 후속이다. 기존 색상 토큰·shadcn 버튼·Pretendard·아이콘을 재사용했다. 모바일 신규 설계는 하지 않았다.

## 브라우저 근거와 제한

기존 3100 Vite는 현재 파일을 resolve하지 못했다. 기존 프로세스는 유지하고 이 작업만의 Node24 서버3235를 실행했다. API4100은 CORS3100만 허용해 임시 검증 서버에 같은 호스트의 API 프록시를 사용했다. 이는 운영 CORS 검증이 아니다.

저장소 기본 e2etester 계정은401이었다. 합성 계정의 정상 로그인201 뒤 `/v1/dashboard/library?view=active`는400을 반환했다. 현재 소스와 dist에는 별도 PersonalLibraryController가 있다. 실행 중인 PID88029는 10월11일 시작했고 목록 기능은 10월18일 추가됐으며 dist는 10월25일 갱신됐다. 오래된 실행본이 원인일 가능성이 높다. 다른 검증 중인 서버를 교체하지 않았으므로 최신 실행본의 HTTP 결과는 별도로 확인해야 한다. 새 목록 컴포넌트의 UI는 별도 임시 페이지에서 합성3건으로 검증했다. 이 페이지의 목적지 화면은 경로 확인용이며 실제 보고서 API 결과가 아니다.

증빙 폴더는 `/Users/moonklabs/workspace-vanilla/phase2-evidence/artifact-hub-code-20261029`다. `component-grid-final.png`는 최종 컴포넌트 렌더, `component-list-1800.png`는 목록, `component-error.png`는 오류 상태다. `api-contract.json`은 로그인201·목록400만 기록하며 토큰을 포함하지 않는다.
