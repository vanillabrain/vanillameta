# UC050 소스 활성 상태 검증

2026-10-18 · develop-v2 · 기준8da042c3 이후 [설계](../plans/UC-050-source-availability.md)의 변경. FR014·NFR005/007·TC050 E01/E02/E03/E12의 선택 검증이며 전체 추가 요건은 active다.

## 구현 범위

Database의 catalogActive/버전과 활성 소유 admin 전용 관리 API를 추가했다. 상태 변경은 소유자/버전 CAS와 실제 actor/source/version 감사가 한 transaction이며 SQLite 조직/권한 쓰기 큐를 공유한다. 비활성 상태에서도 관리 경로/소유 admin 자원 목록은 유지한다. 일반 연결 목록/이름 수정·삭제·파일 교체는 재활성 후 사용하며 조직 자원 관리가 재활성 진입점이다. 일반 소스 목록은 비활성을 제외하고 중앙 SourceAccess의 owner/read/edit/export·연결 대시보드/위젯 및 직접 source 정책 assert에서403으로 차단한다. 권한·원본 파일/정의·게시 snapshot은 보존한다.

기존 게시의 현재 게시자/원 소스 검사도 비활성 상태를 따른다. 재활성은 기존 권한·중지/만료 여부를 그대로 검사하며 공개 링크를 새로 만들지 않는다. 상태 변경은 source.updatedAt을 갱신하므로 기존 데이터 버전의 요청은 재조회/미리보기가 필요할 수 있다. 소스 분류/이용 범위·공식 승인·전체 사용처 영향 확인은 후속이다.

## 미실행·제한

실제 Ego 제어권 미반환으로390/768/1440·모바일 크기/정렬은 BLOCKED이며 자동 검사로 디자인 PASS를 대신하지 않는다. MySQL/실휴대폰/사람 수용·전체 TC050은 미검증이다. 진행 중 SQL/저장/파일 교체의 일괄 취소·이미 보인 화면/다운로드 원격 회수는 보장하지 않는다. 동일 SQLite 큐에 참여하지 않는 모든 모듈의 동시 transaction이나 운영 부하는 이번 선택 검증의 범위 밖이다.
