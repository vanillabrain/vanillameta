# 다른 탭 변경 후 Studio 보관 초안 병합

Status: Draft · P1/P3 · UC046/TC046 · PASS_SELECTED.

## 계약과 변경

[계획](../plans/UC-046.md)·[Use Case](../use_cases/UC-046-concurrent-studio-draft.md)·[테스트 정의](../test_cases/TC-046-concurrent-studio-draft.md)를 따른다. 보관 v2는 SQL 없는 저장 기준 문서와 초안·기준 버전을 함께24h/256KiB에 제한한다. v1은 같은 버전 복구를 유지하며 다른 버전의 기준을 추측하지 않는다. 기존 로그인/탭 분리·권한 확인·질문 별도 보관을 재사용한다.

다른 버전이면 **명시 최신본 조회 → 세 방향 비교 → 같은 항목 충돌의 내 초안 사용 동의 → 전체 미리보기 → 명시 저장**이다. 비대상 최신 변경을 보존하고 제목/설명/표시 항목·전체 필터/기간·폭별 블록 좌표의 실제 로컬 변경만 반영한다. 같은 항목의 서로 다른 변경은 두 값을 보여주고 기본 동의 없이 막는다. 새 복제 블록의 모든 폭 좌표도 그대로 복구한다. 기존 편집기409 재적용 함수는 바꾸지 않는다.

삭제된 수정 대상·정의 교체·소스 버전 변경·6블록 초과·겹치는/경계 밖 배치는 보존형 차단이다. 조용한 블록 생략이나 자동 재배치는 없다. GET/미리보기 실패·재409·대기 중 새 편집/이탈은 기록과 현재 편집을 유지한다.409는 비교와 동의를 초기화한다. 성공 시 최신본을 저장 기준, 병합본을 미저장 문서로 연다. 자동 저장/게시/AI 실행은 없다.

정리 저장을 끝내고 후속 조회가 아직 끝나지 않은 순간에 reload하면 이미 저장한 보관 기록이 남는 문제를 발견했다. 기록 정리의 조건을 미확정 저장 요청으로 한정해 **확인된 저장 성공 후 후속 조회 대기 중에도 정리**하도록 고쳤다. 관련 컴포넌트 회귀와 실제 UI 제목 수정→저장 직후reload→안내/키0→정상 원복 저장/reload를 확인했다.

**기능 PASS_SELECTED:** 위 실제 두 탭 여정과 보존 범위다. GET실패/미리보기409/재비교·대기 중 새 편집·구조/배치 변형·인증/TTL/용량은 회귀 증빙이다. 실제 장애 주입·소스 교체·모든 자연어/경합을 이번 브라우저에서 실행했다고 주장하지 않는다. 게시/LLM 요청은 새로 실행하지 않았다.

**디자인 PASS_SELECTED:** 같은 UI Kit·Studio 배너/32px 작은 버튼·체크박스를 재사용하고390/768/1440 캡처를 직접 확인했다. 같은 항목의 원문과 선택을 인접하게 보여준다. 기존 헤더/도구/질문 안내와의 여백·정렬을 확인했으며 전역 크기 예외/새 의존성은 없다. 계산/차트 변경이 없어 새 live Rill 비교는 NOT_RUN이다.

## 검사와 증빙

- FE6파일101개·타입·변경 lint(경고0)·FE build PASS. 초기 legacy v1 테스트는 바뀐 안내 이름에 맞췄고 낮은 JS target의 Set 순회는 Array.from으로 호환했다.
- 직접 증빙 대조31개 PASS. 미리보기 직후의 첫 이벤트/보관 조회는 응답 종료 전에 읽혀 비어 있거나 이전 기록이었다. 이 초기 파일을 보존하고 완료된 XHR의 응답·저장 요청/응답 및 reload 자료로 판정했다. 보관 기준 갱신 자체는 컴포넌트 회귀로 별도 확인했다.
- AIWF strict 기존12 errors/33 warnings/4 infos를 유지한다. pin/check는 일치 확인이며 승인/전체 수용이 아니다. 스토리지 위임 시도는 제공자400으로 실행되지 않아 주 에이전트가 구현·수동 별도 검토했다. 독립 리뷰 승인으로 보고하지 않는다.
- BE 코드 변경 없음. BE 단위/core E2E·실휴대폰/운영/전체 접근성/고객 수용은 NOT_RUN이며 다른 버전의 정의 교체 자동 병합·저장 불명확 요청 reload 확인은 후속이다.
- 증빙 `/tmp/vm-uc046/`: `baseline{45,46}.json`, `stored-local.json`, `remote-save-events.json`, `remote46.json`, `reload-conflict.json`, `compare-events.json`, `conflict-controls.json`, `merge-preview-events.json`(초기 빈 관측), `merged-local.json`(초기 이전 기록), `merged-save-events.json`(완료된 preview/save 응답), `question-restored.json`, `saved46.json`, `reload-saved.json`, `save-cleanup-reload.json`, `final{45,46}.json`, `final-state.json`, `final-code-reload.json`, `final-code46.json`, `conflict/saved-{390,768,1440}.png/json`, `assertions.py/json`, `unit/type/lint/build/strict.log`. 토큰·비밀번호를 출력하지 않는다.
