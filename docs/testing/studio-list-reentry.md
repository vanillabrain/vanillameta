# 저장 분석 목록에서 Studio 다시 열기

Status: Draft · P3 · TC-005 저장 후 재편집 진입 지원 · PASS_SELECTED.

## 변경 계약

Dashboard 목록에서 `analysisDefinition`이 있는 항목에 별도 ‘Studio 열기’를 제공한다. 제목 조회 링크·이름 수정·삭제 동작은 유지하며 일반 위젯 목록은 Studio 링크를 요청하지 않는다. 목록의 분석 정의 존재는 지원 가능성 안내일 뿐 권한·DuckDB 지원을 보장하지 않는다. 실제 Studio 서버가 기존 권한·소스·정의 검사를 수행하고 미지원/오류는 기존 화면을 따른다. 새 권한이나 우회 API는 없다.

공통 BoardItem은 선택적 Studio URL/열 표시만 받아 렌더링한다. 링크 안에 중첩됐던 수정·삭제 버튼을 독립시켜 링크 선택과 구분하고 항목 제목을 포함한 접근 가능한 이름을 붙였다. 분석이 없는 행도 Studio 열 공간을 확보해 수정일을 정렬한다. 목록 헤더와 도구 열은 같은 간격/너비 토큰을 사용한다. Studio 링크96×32px, 행 최소64px(마지막 행을 제외한 하단 테두리 포함65px), 긴 제목은 말줄임한다.

**기능 PASS_SELECTED:** 실제 재진입·읽기·새로고침만 새 검증이다. 새 AI·저장·게시 요청은 실행하지 않았다. 기존 생성·편집·저장·게시 증빙을 이번 결과로 재집계하지 않는다.

**디자인 PASS_SELECTED:** 최종 목록과 저장45 Studio의 세 폭을 캡처/실측했다. 시각 검사에서 링크 유무에 따라 수정일 열이 달라지는 문제를 발견해 빈 열과 헤더 정렬을 보완했다.390px 긴 제목·날짜·링크가 겹치지 않고 모바일에서도 Studio 링크를 유지한다. 실제 휴대폰·전체 접근성은 NOT_RUN이다. 차트 엔진은 미변경이므로 새 live Rill 비교는 수행하지 않았다.
