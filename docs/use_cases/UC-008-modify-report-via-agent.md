# 유스케이스: 에이전트를 통한 리포트 수정

## 개요

**유스케이스 ID:** UC-008
**유스케이스명:** Modify Report via Agent
**주 액터:** AI 에이전트
**목표:** 도구 표면을 통해 공유 리포트를 리믹스하거나 수정해 에이전트가 만든 분석 결과를 영속적인 아티팩트로 남긴다
**시작 이벤트:** AI 에이전트가 공유 리포트의 도구 표면에 변경 요청을 보낸다
**상태:** Draft

**Requirements:** [FR-010, FR-013, NFR-006, NFR-007, NFR-008, C-004, C-006](../requirements.md)

## 사전 조건

- 변경(리믹스 또는 편집)을 허용하는 권한의 공유 링크가 존재한다
- AI 에이전트가 그 링크에 바인딩된 유효한 스코프 접근 권한을 보유한다

## 주 성공 시나리오

1. AI 에이전트가 도구 표면을 통해 공유 리포트의 구조를 살핀다.
2. AI 에이전트가 변경을 요청하고, 시스템이 권한으로 변경 경로를 정한다 — 인증된 라이브 에디터 링크는 원본 제자리 편집(3단계의 임시 사본을 만들지 않음), 리믹스가 허용된 링크(뷰어·스냅샷 링크 포함)는 독립 리믹스.
3. 리믹스 경로에서만 시스템이 수신자 작업공간에 임시 사본을 만들고 출처를 기록한다.
4. AI 에이전트가 대상 — 임시 사본 또는 라이브 원본 — 에 대한 수정(위젯, 레이아웃, 제목 변경)을 제출한다.
5. 시스템이 저장 직전에 링크와 권한을 재확인하고 검증 후 새 상태를 새 리비전으로 저장한다 — 리믹스 경로에서는 임시 사본을 확정한다.
6. AI 에이전트가 링크를 받아 사용자에게 전달한다 — 제자리 편집이면 기존 공유 링크, 리믹스면 새 리포트의 링크.

## 대안 흐름

### A1: 읽기 전용 권한

**트리거:** 링크의 권한이 변경을 허용하지 않는다 (2단계 또는 4단계)
**흐름:**

1. 시스템이 요청을 거부하고 권한의 경계를 밝힌다.
2. 시스템이 시도를 기록한다.
3. 유스케이스 종료.

### A2: 수정 검증 실패

**트리거:** 저장 시 검증에서 제출된 변경이 형식에 맞지 않거나 사용 불가한 필드를 참조한다 (5단계)
**흐름:**

1. 시스템이 변경을 거부하고 문제를 설명한다.
2. 에이전트가 수정해 재제출하면 4단계에서 계속 — 에이전트가 포기하면 리믹스 경로의 임시 사본을 폐기하고 유스케이스 종료.

### A3: 스냅샷 에디션에 대한 직접 수정 시도

**트리거:** 에이전트가 동결 에디션 자체에 변경을 요청한다 (2단계)
**흐름:**

1. 시스템이 저장 에디션은 불변이며 제자리 수정은 불가함을 밝힌다 — 스냅샷은 에디터 역할을 가질 수 없다.
2. 에이전트나 사용자가 명시적으로 리믹스를 요청하고 링크가 리믹스를 허용하면 리믹스 경로로 3단계에서 계속 — 요청이 없거나 허용되지 않으면 거부를 기록하고 유스케이스 종료(임시 사본은 만들어지지 않는다).

### A4: 저장 시점에 권한 소실

**트리거:** 5단계의 재확인에서 링크가 만료·철회됐거나 권한이 더 이상 변경을 허용하지 않는다 (5단계)
**흐름:**

1. 시스템이 저장을 거부하고 시도를 기록한다 — 리믹스 경로의 임시 사본은 폐기돼 잔여물이 남지 않는다.
2. 유스케이스 종료.

## 사후 조건

### 성공 사후 조건

- 출처가 기록된 영속적인 리포트 아티팩트 — 새 사본 또는 새 리비전 — 가 존재한다
- 권한이 원본 편집을 허용하지 않는 한 원본 공유 리포트는 변하지 않는다
- 모든 변경 호출이 감사용으로 기록됐다

### 실패 사후 조건

- 부분적인 수정이 저장되지 않는다 — 폐기된 임시 사본을 포함해 잔여물이 남지 않는다
- 기존 리포트, 리비전, 스냅샷, 권한은 변하지 않는다

## 비즈니스 규칙

### BR-001: 스냅샷은 변경 불가

에이전트는 저장 에디션을 제자리에서 수정할 수 없다 — 수정 경로는 항상
리믹스 또는 리포트의 라이브 상태를 거친다.

### BR-002: 에이전트 변경은 귀속된다

에이전트가 일으킨 모든 변경은 사용된 권한과 그 대리인이 된 사용자에게
기록된다 — 익명의 에이전트 편집은 존재하지 않는다.
