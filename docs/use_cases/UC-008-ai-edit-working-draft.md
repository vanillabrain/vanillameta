# UC-008 — 미저장 초안의 선택 블록 AI 수정

상태: Implemented (단위·실LLM/API PASS, 실제 UI BLOCKED). P1 / FR-009. 사용자는 소유 분석을 차트·배치 편집 화면에서 열었다.

1. 직접 제목·순서·크기를 편집하거나 블록을 추가/복제한다.
2. 같은 화면에서 블록을 선택하고 변경을 질문한다.
3. 서버가 현재 revision과 전체 초안을 검증하고 선택 블록만 AI로 변경한다.
4. 사용자가 전체 미리보기를 확인한다. 다른 블록과 미저장 제목·배치는 유지된다.
5. AI 변경을 되돌리거나 다시 실행할 수 있다. 복원 후 미리보기를 다시 요청한다.
6. 명시 저장 후 재조회에서 계산과 논리 ID·배치를 확인한다.

오류 규칙: 잘못된 source/SQL/key와 stale revision은 거절한다. 취소/오류 후 초안은 유지하고 늦게 도착한 결과를 적용하지 않는다. 초안 종류는 내부 계약이며 사용자에게 모드 선택을 요구하지 않는다. 이 흐름의 계산식 변경은 해당 분석의 snapshot이며 중앙 저장 지표의 수정·일괄 반영은 UC-003/004로 분리한다.
