# UC-010 — 손잡이로 블록 배치 변경

사용자는 서버 미리보기 후 편집 화면 폭을 선택하고 블록 손잡이를 끌거나 오른쪽 아래 모서리를 조절한다. 선택 폭의 x/y/w/h만 변경되고 다른 폭과 SQL·지표는 유지된다. 방향키는 이동, Shift+방향키는 크기 조절이며 겹침과 열 범위 초과는 거절한다.

이동 종료 한 번이 undo 단계 하나다. 배치 변경 중 결과는 직전 계산 값으로 유지되며 안내를 표시한다. 저장 버튼은 비활성화되고 사용자가 변경 결과 미리보기를 성공시킨 후 저장할 수 있다. 저장·재조회는 UC-009 서버 계약을 그대로 사용한다. AI·미리보기·저장 요청 중 손잡이는 비활성화된다.

내용/제목/블록 개수 변경은 이전 결과를 숨긴다. 배치만 undo/redo하면 결과를 유지하지만 미리보기 재확인은 필요하다. 자동 저장이나 쿼리 자동 실행은 없다.
