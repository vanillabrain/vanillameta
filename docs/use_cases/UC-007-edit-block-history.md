# UC-007 — 블록 복제와 편집 되돌리기

상태: Implemented (단위/API PASS, 실제 UI BLOCKED). 요구사항 FR-009, P1. 사용자: 소유 분석의 운영 담당자.

1. 차트·배치 편집에서 기존 블록을 복제한다.
2. 복제본이 새 ID로 표시된다. 원본 계산·표시·ID는 유지된다.
3. 모바일에서도 위/아래 이동과 크기 선택으로 편집한다.
4. 삭제/순서/크기/설정/제목 변경을 되돌리거나 다시 실행한다.
5. 변경 결과를 다시 미리보기한 뒤 저장하고 재조회한다.

규칙: 1~6개 블록, 최대50단계 로컬 편집 이력. undo는 서버 저장을 취소하지 않는다. 복원 후 이전 미리보기로 저장하지 않는다. 충돌 시 초안과 이력은 유지하되 저장은 최신 버전을 요구한다. 명시 재조회/분석 전환은 이력을 버린다. 기존 SQL 복제의 copyOf는 현재 소유 분석의 저장 블록만 참조하며 신규 key와 달라야 한다.

검증: [실행 계획](../plans/UC-007.md), [실행 기록](../testing/block-editor-history.md). 순서·크기 편집과 breakpoint별 자유 위치 저장을 구별한다.
