# UC-009 — 화면 폭별 블록 배치

상태: Implemented (좌표 편집 단위/API/실LLM PASS, UI BLOCKED). FR-009·010 / P1.

1. 소유 분석의 차트·배치 편집에서 모바일4/태블릿8/데스크톱12열 중 편집 대상을 선택한다.
2. 블록 설정에서 위치·너비·높이를 지정한다. 다른 화면 폭의 좌표는 유지된다.
3. 공통 undo/redo로 배치를 복원하고 다시 미리보기한다.
4. 서버가 정수·범위·겹침을 검증하고 명시 저장한다.
5. 재조회 및 분석 읽기 화면에서 해당 폭의 좌표를 사용한다.
6. AI 내용 수정·블록 복제 후에도 비대상 세 배치가 보존된다.

규칙: 좌표는0부터, y≤1000/h≤50이며 x+w는 해당 열 수 이하이다. 분석 JSON에 서버 blockId로 기록한다. 신규 블록은 기존 점유 영역 아래에 기본 배치한다. 조회만으로 저장하지 않는다. 오류/버전 경합은 전체 저장을 거절한다. AI 일반 저장의 클라이언트 배치 필드는 쓰기 권한이 아니다. 기존 소유권/SQL/ID 경계를 유지한다.

이번 범위는 좌표 컨트롤과 소유 분석의 반응형 읽기다. 포인터 드래그, AI 배치 이동, 게시/공유 수신 화면의 독립 배치 계약은 남는다. [계획](../plans/UC-009.md), [증빙](../testing/responsive-block-layout.md).
