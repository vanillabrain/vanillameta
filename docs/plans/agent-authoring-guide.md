## MCP 후속 구현의 완료 조건(미구현)

- 실제 제공 패키지/버전·실행 명령 또는 URL·transport·지원 클라이언트/OS를 확정한다. 가상 `npx` 패키지나 `/mcp` 경로를 안내하지 않는다.
- 인증은 사용자/조직에 묶고 만료·회수·다른 사용자의 자원 조회를 검증한다. 관리자 공용 token으로 우회하지 않는다.
- 조회와 생성 제안/전체 미리보기/저장/게시를 분리한다. 임의 SQL·파일·shell을 도구에 그대로 노출하지 않는다.
- 저장은 같은 requestId/정확 입력·현재 버전·응답 유실 확인을 따르고, 게시는 별도 범위 확인을 요구한다.
- 실제 코딩 에이전트에서 도구 발견→질문→미리보기→동의→저장→Studio URL→reload까지 실행한다. 도구 목록 화면만으로 완료하지 않는다.
- Claude Code/기타 클라이언트는 각 실제 연결 검증 뒤 지원 목록에 추가한다. MK AI 계약은 별도 작업이다.

## 검증과 공개 경계

공개 문서는 실제 경로·합성 예시만 사용한다. 서버 계정·로컬 사용자 경로·토큰은 제외한다. 기존 CLI help/login 상태·제품 호출기의 합성 스키마 실호출과 선택 회귀를 구분하고, 새 안내를 기존 UI 캡처·현재 코드와 대조한다. 새 MCP/Claude 실행이나 전체 앱 여정을 실행한 것으로 표시하지 않는다. 문서 root/subpath·검색/모바일·배포는 별도 검증한다.
