# 조직 공유·받은 자료·독립 재사용 샘플 가이드

2026-10-21 · 기존 사용자 문서의 조직 조회 공유와 독립 복제 흐름을 실제 화면으로 확인해 샘플 가이드로 연결한다.

- 전용 Docker MySQL/Nest/DuckDB/Vite와 합성 두 계정·동일 조직을 준비한다. 사용자 기존 자료와 서버는 변경하지 않는다.
- 소유자의 소스 read 부여→대시보드 조회 공유/별도 복제 허용→수신자 받은 자료 열람/reload→본인 소스 매핑/미리보기→독립 사본 저장/reload를 Ego에서 수행한다.
- 원본600/수신자1200으로 소스 재계산을 구별하고 원본 보존과 새 비공개 사본을 확인한다. 가능하면 회수 후 기존 사본 보존도 확인한다.
- 390/768/1440px에서 컨트롤·가로 넘침·이미지 표시를 구분해 검증한다. 실기기·모든 권한/엔진 조합 수용으로 확대하지 않는다.
- 새 캡처는 합성 자료만 포함한다. 코드/토큰·기업 정보는 공개 문서·커밋에서 제외한다.
- 문서 빌드/링크·모바일 확인 후 develop commit/push와 해당 SHA의 자동 배포/온라인 내용·이미지를 확인한다.
