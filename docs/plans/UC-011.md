# UC-011 — AI 선택 블록 배치 변경

FR-009·010 / P1. 선택 블록 하나와 선택 화면 폭의 배치를 자연어로 변경한다. 기존 내용 AI 경로와 구분하는 작은 목적 선택(차트 내용/배치)을 AI 요청 옆에 제공한다. 자동 의도 분류·다중 블록 재배치는 후속이다.

AI에는 블록 키·제목·선택 폭의 현재 좌표만 제공하며 SQL/원본 행은 제공하지 않는다. JSON x/y/w/h만 수신하고 범위·겹침은 기존 compiler로 검증한다. AI는 좌표 제안자이고 권한·버전·계산·저장의 주체가 아니다. 내용 변경·모호한 요청은 unsupported로 거절한다. 실패 시 초안과 저장 상태를 유지한다.

editor/ai에 editMode=layout, layoutMode를 추가하고 생략 시 기존 내용 편집을 유지한다. 선택 item의 layouts만 교체하여 공통 이력에 적용한다. 다른 블록·SQL·다른 폭은 유지한다. 성공한 서버 미리보기를 확인한 다음 명시 저장한다. abort와 버전 재검증은 기존 경로를 재사용한다.

검증: AI JSON 제한·SQL 비노출·취소, compiler 겹침/버전/권한·원본 보존, FE 요청/결과/undo/저장 gate, 실제 Luna 요청→미리보기→저장→새로고침, 대표 모바일/데스크톱 컨트롤. 포인터·터치 미검증은 이번 범위에서도 별도로 남긴다. 관련 단위·타입·lint·build와 Git commit/push까지 진행한다.
