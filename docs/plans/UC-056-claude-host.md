# UC056 Claude Code 실제 호스트 검증

2026-10-23 · develop · 기존 UC056/TC056의 후속 검증.

## 목표와 경계

Claude Code의 기존 로그인·기본 모델을 사용한다. 실행별 stdio MCP 설정만 추가하고 전역 설정, 모델, 로그인은 변경하지 않는다. 합성 매출 CSV(100/200/300)와 전용 Docker MySQL 앱만 사용한다. 게시·공유·원격 MCP는 포함하지 않는다.

## 검증 순서

1. 실제 CLI 인증과 지원 옵션을 확인한다. 샌드박스 키체인 제한과 실제 미로그인을 구분한다.
2. 전용 앱에서 소스 준비 후 CLI에 이 MCP만 노출한다. 기본 파일/명령 도구는 비활성화한다.
3. 첫 질문은 소스·스키마·제안·미리보기만 허용한다. 도구 호출과 실제 결과, 저장 행 수 불변을 확인한다.
4. 숫자600/날짜별100·200·300/두 블록을 검증한 뒤 별도 승인 입력에서 저장·재조회만 허용한다. 새 행1개와 정확한 저장 기준을 검사한다.
5. Ego에서 반환된 Studio 링크를 열고 새로고침한다. 390/768/1440px의 넘침·컨트롤·차트를 확인하고 합성 화면만 가이드에 추가한다.
6. 단위 테스트·문서 빌드와 링크 검사를 수행하고 commit/push·자동 문서 배포를 확인한다.

## 실패와 증빙

CLI 오류·권한 거절·실제 tool_result를 구분한다. 모델 완료 문장만으로 성공 처리하지 않는다. 원시 호스트 로그와 인증 파일은 Git 제외 증빙 경로에 보관하고 인증 파일은 종료 시 제거한다. 결과 불명 시 새 UUID로 자동 재저장하지 않는다. 하네스의 별도 저장 승인은 사용자에게 허용받은 합성 검증이며 고객 업무 수용 승인이 아니다.
