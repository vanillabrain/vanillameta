# UC053 조회 공유의 실제 대시보드 소비자 복구

2026-10-21 · 사용자 가이드 실제 Ego 검증에서 받은 자료 목록은 열리지만 본문의 숫자·시계열 조회가 실패했다.

## 원인과 설계

기존 DashboardAnalysis가 편집용 `/ai/dashboard-preview`로 브라우저 초안을 전송한다. 이 경로의 edit 검사는 유지한다. 조회 공유에 편집권을 추가하지 않는다.

읽기 전용 `/ai/dashboard-view`를 추가한다. 요청은 대시보드 ID·읽은 revision·기간/필터·집계 표시 옵션만 허용한다. SQL·소스·블록 정의를 받지 않고 서버의 현재 저장 정의로 계산한다. 현재 대시보드 read와 모든 소스 read를 검사하며 저장 revision을 계산 전후 대조한다. 위조 필드와 오래된 기준은 쓰기 없이 거절한다. 기존 편집·저장·원본 상세 경계는 변경하지 않는다.

## 검증 기준

- 단위: SQL/초안 주입 거절, 현재 읽기 거절·계산 전후 변경 거절, auth epoch 전달.
- 실제 MySQL/Ego: source read 없는 전달 거절 → source read 부여 → 동일 전달 재시도 → 수신자 받은 자료 열기 → 숫자·시계열 → 새로고침. 수신자의 edit/임의 SQL 미허용을 함께 확인한다.
- 모바일 390px 수신자 화면·대표 768/1440px과 가이드 캡처를 확인한다.

실행 결과는 [사용자 가이드 검증 기록](../testing/user-guide-ego.md)에 따르며 이 계획만으로 완료·운영 수용으로 표시하지 않는다.
