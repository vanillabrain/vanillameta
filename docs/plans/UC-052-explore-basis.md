# UC052 명시 조건 적용과 조회·출력 기준 일치

2026-10-18 · 기준 ec965220 · FR018/019/025·NFR005/006/008·TC050 E05/E08/E14. 전체 FR014~025/NFR005~008 완료 목표의 다음 단위다. AIWF workflow로 설계 후 구현하며 전체 수용을 이 단위 통과로 대체하지 않는다.

## 확인한 공백과 최소 변경

서버의 중첩 포함/제외·이전 기간 비교·시간대·Pivot·CSV 계산은 이미 있다. SourceConditions의 검증 미리보기는 Explore 조회/값 검색/Pivot/출력으로 명시 전달되지 않는다. 또한 즉시 CSV는 지표를 다시 읽어 화면 조회 후 정의 변경을 놓칠 수 있다. 새 보고서 엔진을 만들지 않고 기존 공통 계산 경로를 연결한다.

## 계약

- 검증한 조건 미리보기에서만 사용자가 '이 분석에 조건 적용'을 누른다. 읽기 사용자도 자신의 분석 범위에 적용할 수 있으며 소스 metadata 저장과 분리한다. 조건 편집/검증 실패/늦은 응답은 이전 검증 snapshot을 적용하지 못한다. Source 미리보기의 전체 기간/UTC 분모와 분석의 현재 기간·필터 분모를 구분한다.
- 적용 snapshot은 서버 미리보기의 실행용 StudioConditions(sourceRevision/definition)다. 소스 편집 draft.sourceRevision은 metadata+파일 합성 revision이므로 실행 파일 hash로 사용하지 않는다. 서버는 캡처한 실제 파일 기준을 별도로 제공하고 FE는 검증 draft와 동일한 definition인지 검사한 후 적용한다. 조회·값 검색·기본/고급 Pivot·즉시/영속 CSV와 저장 보기/reload에 같은 조건을 전달한다. 소스 조건 metadata 변경은 자동 동기화하지 않는다. 파일 hash 불일치는 차단하고 명시 재검토를 요구한다. 제거는 명시 동작이며 원본/SQL/다른 분석을 변경하지 않는다.
- 조회 응답은 실제 사용한 지표 버전 기준을 제공한다. 화면에서 확인한 기준을 출력에 전달하고 계산 전후 지표 변경은409로 거절한다. sourceRevision만 같다고 성공 처리하지 않는다. 영속 작업의 기존 고정 basis/과거 완료 파일 보존 계약은 유지한다. 신규 필드는 기존 호출과 호환하면서 화면의 새 출력은 엄격하게 검사한다.
- 저장 보기의 조건은 구조/크기/실제 schema·파일 기준을 검사한다. 과거 조건 없는 보기와 호환하며 복구 실패 시 현재 입력을 보존하고 자동 조건 재바인딩/쓰기하지 않는다.
- UI Kit 일반36/도구32px·14px·줄바꿈·390/768/1440 페이지 넘침0을 확인한다. 추가 설정은 기존 접힌 조건 영역에 두고 적용 범위와 해제만 간결하게 표시한다.

## 분담과 검증

SourceConditions 적용 버튼/회귀, SourceExplore/Pivot/저장 보기 FE 연결, 서버 저장 보기 검증, 서버 지표 basis/CSV 경합 검증을 파일 경계로 분담한다. Main은 통합·독립 검토·AIWF 문서·실제 isolated headless UI/fixture oracle을 담당한다. 사용자 제어 Ego96은 건드리지 않고 headless viewport를 실제 Ego/휴대폰 증거로 부르지 않는다.

실제 DuckDB의 포함OR/제외+날짜·필터/이전 기간·분류·추이·0행/0분모와 API/CSV 독립 정답을 연결한다. 조회 후 지표 변경→즉시 출력409, 완료 영속 CSV의 과거 기준 보존, 파일 변경/권한 회수/늦은 응답/명시 제거/보기 reload를 선택 검증한다. 관련 BE/FE 테스트·types/lint/build·브라우저·문서 strict/pin/check/packet·개인정보 검사 후 현재 develop-v2 commit/push한다. 실제 Ego/휴대폰·운영·전체16개/TC050 사람 수용은 별도 미완료로 유지한다.
