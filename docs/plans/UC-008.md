# UC-008 — 직접 편집과 AI 변경의 공통 초안

P1 / FR-009. 현재 DashboardEdit 로컬 초안/undo와 별도 AI 저장 흐름이 분리되어 있다. 가장 앞선 미완료 항목인 공통 초안부터 연결한다.

- 현재 제목·순서·크기·추가/삭제/복제한 items와 expectedRevision을 서버 editor compiler로 검증한다. 선택 key를 기준으로 기존 AI generation/SQL guard/preview를 재사용해 한 블록만 변경한다. 저장은 하지 않는다.
- AI 반환 블록은 명시적인 draft 종류로 로컬 초안에 담는다. 정의는 현재 소스의 SELECT FROM source만 허용하는 기존 validator와 실제 preview를 통과해야 한다. 클라이언트의 sourceId/definition.blockId는 권한·identity 근거가 아니다. existing 종류의 클라이언트 SQL 무시는 유지한다.
- 편집 화면에서 블록 선택 → 질문 → 전체 미리보기 → 명시 저장. AI 변경도 동일한50단계 undo/redo에 포함하며 비대상 내용·배치·제목은 유지한다. 저장 지표의 중앙 계산식은 이 요청으로 갱신하지 않는다.
- 실패·취소·경로 변경·revision 충돌은 작성 초안을 보존한다. AI 요청 중 직접 편집을 막고 취소할 수 있게 한다. 재조회 확인 이후에만 이력을 버린다.

검증: BE 소유권/선택 대상/SQL/source/identity/버전/비대상 보존, FE 미저장 직접 편집 전달·AI undo/redo·취소·지연 응답·저장 transport → 타입/린트/빌드 → 새 공식 Rill 비공개 fixture의 실LLM/preview/save/API reload. 실제 화면과 Rill 화면 재비교는 기존 브라우저 정책 차단이 해제되지 않으면 BLOCKED. 익명 공유는 하지 않는다.

종료는 이 공통 초안 단위의 구현·검증 기록·commit/push다. breakpoint별 자유 배치, 자동 저장/게시 의도 실행과 TC-005 전체 통과는 남는다.
