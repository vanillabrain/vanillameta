# UC027 실행 계획

Status: Draft. FR009/011·NFR003/004·UC017/025/026 후속.

1. UC027·설계·TC027을 먼저 작성하고 별도 의미 검토·strict 검사·pin을 남긴다.
2. 실제 실패를 확인해 필요한 최소 보완만 적용한다. 기존409 안내가 초안 폐기 재로드로 오해되지 않도록 상태 확인을 안내한다. 관련 회귀는503→재시도/병합→preview→409→재조회/병합→새 preview→성공 저장까지 연결한다.
3. Ego67에서 GET503은 테스트 프록시의 정확한1회 주입,409는 실제 둘째 탭 저장으로 재현한다. 질문은 보존하고 자동 AI 실행은 하지 않는다. UI390/태블릿/데스크톱 오류·충돌·재미리보기와 게시/reload를 확인한다.
4. 원본 계산/ID/모든 폭 배치·비대상 최신 변경·추가쓰기0·정리·중지404·정상 서버 복원을 확인하고 문서를 동기화해 commit/push한다.

A1 조회 실패 반복은 기존회귀/순수 상태 유지, A2 구조 변경 차단은 기존 UC017 회귀를 재사용한다. 물리기기/인증 갱신/운영/전체제품 수용은 미확인으로 유지한다.
