# UC040 — 홈 AI 생성 진입 통일

Status: Draft. P2/P3 · TC-005 생성 진입 지원.

목록의 AI 생성 메뉴는 이전 패널을 열고 시작 카드는 Studio로 이동한다. 같은 생성 의도에 서로 다른 제품 흐름이 노출되는 공백을 해소한다.

1. 목록의 ‘AI 대시보드 만들기’를 `/studio/new`로 연결한다. 기존 `aiSourceId` 직접 링크의 패널과 저장 후 이동 계약은 유지한다.
2. 메뉴 선택의 Studio 이동, 수동/추천 이동 및 기존 패널 저장 후 이동을 컴포넌트 회귀로 확인한다.
3. Ego에서 목록 메뉴 → Studio 데이터 선택/질문 화면을 확인하고 390/768/1440px 메뉴·인접 컨트롤·생성 화면 정렬을 측정·캡처한다. 이동만으로 생성/저장/게시 요청을 실행하지 않는다.
4. 관련 FE 검사·타입·변경 lint 후 증빙을 기록하고 commit/push한다. 생성 엔진·게시·복제 전체 여정은 변경하지 않으며 기존 증빙을 재사용한다.

종료 조건: 두 AI 생성 진입점이 같은 Studio를 열고, 기존 소스 지정 링크 및 수동 생성 동작이 유지된다. 실제 휴대폰/운영/전체 TC-005 수용은 별도 gate다.
