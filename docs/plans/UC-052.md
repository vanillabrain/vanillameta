# UC052 공통 시각 조건과 모집단 미리보기

2026-10-18 · 기준48fa3d7f · FR018/019/020·NFR005/006/007/008·TC050 E04/E05/E13. 전체16개 완료 목표를 유지한다. 첫 구현은 허용 DuckDB 소스의 조건 편집·전체 건수 미리보기·버전 저장/재조회다. 기존 Studio 필터/숫자/게시를 몰래 바꾸지 않으며 Studio/AI/출력 연결까지 후속으로 추적한다.

## 공통 정의

조건 정의는 `{ include: Node|null, exclude: Node|null }`다. Node는 `{kind:'group',operator:'and'|'or',children:Node[]}` 또는 `{kind:'predicate',column,operator,values?:Primitive[]}`다. 포함 null은 전체, 제외 null은 제외 없음이다. 그룹 깊이4/자식8/두 트리 합계32노드/값50개·문자2000자/전체32KiB를 한도로 서버 검증한다. 빈 그룹·알 수 없는 필드/열/유형·비정상 값은 전체 거절한다.

숫자/텍스트/boolean/원본 DATE·TIMESTAMP의 실제 스키마를 기준으로 eq/ne/in/notIn·순서 비교/between·텍스트 contains·isNull/isNotNull을 제한한다. 문자열 숫자/업무 날짜 형식을 추측 변환하지 않는다. 날짜는 유효한 ISO 날짜/UTC instant를 명시하고 비교한다. TIMESTAMP_NS는 나노초9자리/명시 유한 epoch-ns 구간(-9223372036854775806~9223372036854775806), 나머지 timestamp는 마이크로초6자리(후행0 정규화 후)까지이며 조용히 절삭하지 않는다. DECIMAL은 원본/입력 양쪽을 보존하는 최대38자리 공통 scale을 사용하고 정수 경계는 DOUBLE로 승격하지 않는다. 지원하지 않는 배열/구조/바이너리 유형은 NULL 검사만 가능하다. SQL 식별자는 현재 스키마로 확인 후 인용하고 값은 모두 binding한다. NULL 비교는 false이며 NULL 선택은 명시 연산자다. 따라서 제외는 true인 행만 제거하고 NULL을 은밀히 제외하지 않는다.

## 서버·저장

JWT 아래 POST `/bi/source-conditions/read|preview|save`를 추가한다. read는 sourceId, preview/save는 sourceId/sourceRevision/version/definition을 받는다. read/preview는 현재 source read, save는 edit를 요구하며 비활성/회수는 다음 보호 요청에서 차단한다. 권한·소스 metadata·최신 조건 entry·실제 파일 snapshot을 같은 metadata lease에서 캡처하고, DESCRIBE/집계는 그 lease 밖에서 실행한다. 현재 revision/schema를 확인하고 집계 후 권한/현재 원본·조건 버전을 새 캡처로 다시 확인한다. 새 캡처는 이전 snapshot 문맥을 계승하지 않는다. 응답은 SQL/행/접속정보 없이 정의·열 유형·전체/포함 충족/그중 제외/최종 건수와 전체 대비 비율만 반환한다. 전체0은 비율null이다.

`source_condition_entry`의 sourceId/version 복합 PK append로 CAS·actor/revision/정의/시각을 남긴다. 버전 불일치/중간 소스 교체/손상 저장본은409이며 데이터 수정0이다. 조건 값은 민감할 수 있으므로 권한 없는 목록/익명/게시/감사 요약에 노출하지 않는다. 원본 행 표본/분포·여러 이름 조건 세트·저장 결과 불명확 영수증 복구는 별도이며 현재 실패 시 입력을 보존하고 명시 재조회로 저장 버전을 확인한다.

## 화면

소스 탐색의 접힌 '조건과 분석 범위'에서 명시 조회한다. 포함/제외 트리·AND/OR·조건/그룹 추가/삭제·유형별 값 입력을 제공한다. 건수 미리보기는 현재 전체 소스/UTC임을 표시하고 입력 변경 시 무효화한다. 명시 저장은 성공한 정확한 미리보기 입력만 사용하고 저장 후 버전을 갱신한다. 조회가 초안을 덮을 때 명시 확인하며 실패/409는 입력을 보존한다. sourceId/권한 변경·unmount 뒤 지연 응답은 무시한다. 기본 입력/주요 버튼36px·도구32px/14px·모바일 세로 배치/긴 열명 줄바꿈·키보드 label을 따른다.
