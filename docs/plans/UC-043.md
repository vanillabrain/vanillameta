# UC043 — 새로고침 뒤 미전송 질문 명시 복구

Status: Draft · P3 · UC025/TC-005 반복 질문 복구 지원.

Studio 질문은 UC042에서 패널 닫기만 보존한다. 서버 권한 조회에 성공해 Workspace가 열린 뒤 같은 로그인 scope·대시보드·탭의 미전송 질문을 복구/폐기하도록 한다. 기존 editorDraftKey/로그아웃 정리를 재사용하며 다른 키 suffix로 기존 분석/생성 저장확인과 분리한다.

- sessionStorage에 질문/버전/시각만24h·8KiB·2000자로 보관한다. SQL·결과·블록·요청 envelope는 저장하지 않는다. 비어 있는 입력은 정리하고 전송의 기존 입력 정리도 반영한다.
- 조회/자동 key 준비 동안 입력한 새 질문을 늦은 복구가 덮지 않는다. 기존 보관 질문이 있으면 명시 선택 전까지 유지한다. 새 입력이 있으면 복구 버튼을 비활성화하고, 보관 질문 폐기는 현재 입력을 유지한다.
- storage 오류는 편집/전송을 막지 않고 보관할 수 없음을 안내한다. 자동 AI/저장/게시0. 다른 대시보드/로그인·만료/잘못된 payload는 복구하지 않는다.
- 단위: TTL/크기/키분리/깨진값/저장소거절 및 Workspace 복구/폐기/입력보존. Ego: 질문입력→reload→복구안내→명시복구/패널입력확인→다시reload/폐기,390/768/1440 안내 크기·정렬·GET만/저장본 불변.
- 블록 초안·전체 AI 실행/불명확 요청의 reload 복구·실휴대폰·고객 수용은 별도다. 관련 FE·type/lint/build·AIWF 동기화 뒤 commit/push한다.
