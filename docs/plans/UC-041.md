# UC041 — 저장 분석 목록에서 Studio 다시 열기

Status: Draft · P3 · TC-005 저장 후 재편집 진입 지원.

목록의 분석 저장본은 조회 화면을 거쳐야 Studio에 진입한다. 분석 정의가 있는 행에 별도 ‘Studio 열기’ 링크를 제공한다. 제목은 기존 조회 경로를 유지하고 일반 위젯 목록에는 이 링크를 표시하지 않는다. 링크는 지원/권한을 부여하지 않으며 Studio 서버의 기존 DuckDB·정의·권한 검사를 따른다.

1. Dashboard 목록에서만 분석 정의 존재에 따라 Studio 링크를 전달한다. BoardItem은 명시적 선택 속성을 사용하고 데이터 내용을 해석하지 않는다.
2. 행 링크 안의 버튼 중첩을 해소하고 이름 수정·삭제에 접근 가능한 이름을 부여한다. 기존 수정/삭제 동작을 보존한다.
3. 행 제목·Studio 링크/상대 경로·키보드 대상·수정/삭제 비전파를 단위 검증한다.
4. Ego에서 실제 목록의 저장45 → Studio 내용 조회 → 새로고침을 확인하고390/768/1440의 긴 제목/날짜/링크 정렬을 측정·캡처한다. 새 저장·AI·게시를 실행하지 않는다.
5. 관련 테스트·타입·lint 후 증빙/AGENTS를 동기화하고 commit/push한다. 기존 생성·편집·저장 엔진 검증은 재사용한다.
