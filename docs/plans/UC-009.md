# UC-009 — 화면 폭별 블록 배치

P1 / FR-009·010. 모바일4/태블릿8/데스크톱12열에서 블록별 x/y/w/h를 편집하고 공통 초안·undo/redo·AI·저장·재조회에 연결한다. 기존 분석 JSON에 responsiveLayouts를 기록하며 DB 컬럼 추가는 하지 않는다.

현재 서버 compiler와 저장 transaction을 재사용한다. 배치 입력은 소유 블록의 현재 순서에 연결하여 서버 논리 ID로 저장한다. 정수/범위/겹침 검증 실패는 전체 저장을 거절한다. 저장 배치가 없는 기존 분석은 좌표에서 도출하고 조회만으로 재저장하지 않는다. 내용 AI 변경과 기존 AI save는 세 배치를 보존한다.

이번 단위는 좌표 컨트롤을 통한 자유 배치와 반응형 읽기다. 포인터 드래그·프롬프트 이동과 실제390/768/1440 화면 검증은 별도 남는다. 이전 브라우저 정책 차단을 우회하지 않는다.

검증: 배치 validator·compiler·저장/AI 보존 회귀 → FE 배치/undo transport·읽기 배치 → 타입/린트/빌드 → 공개 Rill 데모의 새 비공개 fixture API 저장·재조회·실LLM 보존. UI BLOCKED와 구현 누락을 구별한다. commit/push 및 다음 범위 기록까지 진행한다.
