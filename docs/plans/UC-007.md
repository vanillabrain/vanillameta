# UC-007 — P1 블록 작업과 편집 이력

연결: FR-009 / P1 / UC-005 BR-003. 현재 차트·배치 편집기는 모바일 이동/크기 선택과 추가/삭제가 있지만 복제와 undo가 없고 설정을 모두 펼친다.

## 최소 구현

- 기존 DashboardEdit에서 제목·차트 설정·추가·삭제·순서·크기 변경을 최대50단계 undo/redo로 복원한다. 모든 복원은 미리보기를 무효화하고 새 편집은 redo를 버린다. 로딩/저장 중에는 변경하지 않으며 재조회/경로 전환에서 이력을 초기화한다.
- 1~6개 한도 내 블록 복제. 새 key/blockId로 생성하고 원본은 유지한다. 기존 SQL 차트는 소유 대시보드의 저장 블록 key를 copyOf로 명시하여 서버가 원본 계산을 가져온다. 클라이언트 SQL은 사용하지 않는다. 저장 지표 차트는 기존 검증·컴파일 경로를 재사용한다.
- 블록별 보조 설정을 접고 이동/복제/삭제를 기본 표시한다. 공통 AnalysisUiProvider를 사용하고 화면 전체의 버튼 minHeight 강제를 제거한다. 숫자 미리보기에는 기존 MetricTrend를 함께 표시한다.

## 검증과 종료

BE 복제 SQL/ID/소유권/변조/버전/한도 회귀, FE 복제·연속 undo/redo·미리보기 무효화·재조회 초기화·기존 편집 회귀 → 타입/린트/빌드 → 허용된 로컬 API preview/save/reload. 실제 화면은 기존 브라우저 정책 차단이 해제되지 않으면 BLOCKED로 기록하고 우회하지 않는다.

이번 단위는 순서·크기 편집을 개선한다. 자유 위치 드래그와 breakpoint별 독립 배치 저장, AI와 공유하는 전체 변경 작업/undo 계약은 후속이다. P1/TC-005 전체 완료를 선언하지 않는다. 익명 공개는 범위에서 제외한다.
