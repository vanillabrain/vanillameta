# TC050 검증 런타임 종료 복구

2026-10-23 · develop · 기존 제품 서버와 별도 검증 자원의 경계를 보존한다.

## 원인과 변경 범위

격리 drain probe에서 process.kill(-pgid, 0)의 일시 EPERM 뒤 동일 그룹 소멸과 matching drained 응답을 관측했다. 부모의 failed 플래그가 영구 유지되어 최신 소멸 증명까지 거절했다. 조회 오류는 그룹을 유지한 채 재관측하며 IPC/증명 전송 실패와 분리한다. 진행 중 그룹/불명 응답은 여전히 정리를 차단하며, admission fence 안의 현재 요청에 대한 그룹0 및 전송 callback 완료 증명만 완료로 인정한다. 부모의 치명적 실패 플래그를 단순 초기화하지 않는다.

## 검증

- 임시 EPERM → 그룹 생존 동안 거절 → 그룹 소멸 후 fresh drain 성공.
- 지속 조회 실패/잘못된 요청/IPC 종료/제한시간 초과는 자원 보존.
- 실제 자식/손자 수명과 새 spawn 차단·재시작·인증 stop·소유 Docker/임시 파일 정리.
- 이전 CI 결과와 수정 커밋 CI를 별도로 확인하고 기록한다.
- 구버전 supervisor가 보존한 자원은 별도 신원/현재 프로세스 증명 없이 강제 삭제하지 않는다.
