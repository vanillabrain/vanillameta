# UC028 실행 계획

Status: Draft. FR009/011·NFR003/004.

1. UC/설계/TC와 세션 경계를 먼저 작성·별도 의미 검토·strict 검사·pin한다.
2. editorDraftStorage 공유 메타데이터/세대와 authHelper 로그인·로그아웃 초기화, apiHelper 늦은 refresh 보호를 최소 구현한다.
3. 두 탭 저장소 모델과 실제 interceptor 회귀로 정상승계/새로그인분리/동일토큰재로그인/해시·서버대기 경합/저장소 실패를 확인한다. 기존 편집 복구 회귀·전체 FE/type/lint/build·격리core를 선택한다.
4. Ego68의 두 탭으로 초안 생성→둘째 탭 만료401(정확1회 주입)→서버 refresh201/원요청 재시도→첫 탭 reload→복구/preview/save/publish/reload를 검증한다. 공유 메타데이터에 원 토큰/본문이 없고 초안 본문은 첫 탭에만 있음을 확인한다.390/태블릿/데스크톱 정렬도 확인한다.
5. 문서/증빙·미확인을 동기화하고 임시 게시 중지·프록시 복원·commit/push한다.

동시 탭 refresh 단일화·모든 오류·실휴대폰·운영/전체 수용은 별도 gate다.
