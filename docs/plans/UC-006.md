# UC-006 P1 첫 구현 단위

FR-009/UC-005 BR-003의 첫 범위는 안정적 ID·서버 저장 배치 연결·선택 AI 수정이다. 기존 grid/SQL/메타데이터 DB를 재사용한다.

- dashboard-draft blockId 검증/보존, legacy 분석 응답의 결정적 ID와 저장 adapter.
- ai-dashboard save의 blockId geometry 연결, generation 선택 대상 merge/ID 요청. 기존 layoutSizes 명시 크기 변경은 비교 후 적용.
- BI editor는 blockId를 key로 전달하고 기존 ID를 보존한다. 모바일 편집/undo 통합은 후속.
- 관련 SQLite/LLM stub 회귀 → BE build/lint → FE 타입/선택 transport → 기존 Aside 실LLM 편집·저장·새로고침.
- 실패/미실행을 분리하고 관련 문서 sync/pin/check 후 commit push. P1 전체/TC-005 전체 완료를 주장하지 않는다.

조회용 blockLayouts는 서버 layout/mapping에서 읽어 반환하며 저장 geometry의 클라이언트 권한은 아니다. 실제 분석 Card가 이 좌표로 표시되도록 연결하고 768px header overflow를 수정했다. [실행 증빙](../testing/block-layout-continuity.md). P1의 남은 범위는 블록 추가/삭제/복제 작업 UI·undo와 breakpoint별 편집이다.
