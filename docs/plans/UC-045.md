# UC045 — Studio 블록·배치 초안 새로고침 복구

Status: Draft · P1/P3 · UC025/TC-005 중단 후 편집 지원.

현재 질문만 reload 복구한다. 같은 로그인 scope/탭/대시보드에 Studio 문서(블록·표시·모든 폭 배치·필터/기간)와 기준 revision/sourceRevision만24h/256KiB로 보관한다. SQL/정의 catalog/결과/AI 요청/undo 이력은 추가 저장하지 않는다. 권한 GET 성공 후 명시 복구/폐기한다.

- 같은 서버 revision/sourceRevision에서만 복구 버튼을 활성화한다. 사용자가 현재 편집을 시작했다면 복구로 덮지 않는다. 보관 기록 폐기는 현재 편집을 유지한다.
- 명시 복구는 기존 서버 prepare API로 검증/새 미리보기 후 초기 saved baseline과 restored draft를 함께 seed한다. 자동 저장/AI/게시0. 검증 실패·409·응답 도중 새 편집·이탈은 보관본/현재본을 유지한다.
- 성공 적용 후 pending 안내는 닫고 dirty 문서를 계속 보관한다. 정상 저장/undo clean에서는 기록을 정리한다. 저장중/결과 불명확 pending은 이전 보관 기록을 유지하며 저장 영수증 재시도를 복구한다고 주장하지 않는다.
- 기준이 바뀌면 자동 복구/저장을 차단하고 보관 상태를 알린다. 다른 버전 병합/불명확 저장/reload 전체 실행 복구는 후속이다. 기존 질문 복구는 별도 선택을 유지한다.

구현 전 helper/컴포넌트 회귀를 정의한다: 구조·TTL/용량/키분리, 권한 조회 후 명시 복구, prepare만 호출, 실패/기준변경/새 편집 차단, 저장 후 정리. Ego89에서46의 블록 제목+복제/배치→reload→명시복구→미리보기→저장→reload 및390/768/1440 안내·버튼 정렬을 검증한다. 원본45 불변,46 검증 변경은 마지막 정상 저장으로 원복한다. 관련 FE/type/lint/build·AIWF 문서 체크 후 commit/push한다.
