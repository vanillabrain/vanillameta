# UC044 — Studio 저장본 복제·소스 교체 후 편집 연결

Status: Draft · P5 · UC020/TC-005 재사용 진입 지원.

기존 소유 복제 화면을 재사용한다. Studio에서 마지막 저장본의 복제·소스 교체를 새 탭으로 열어 현재 원본 초안을 유지하고, 복사본 저장 후 새 ID의 Studio로 이동한다. 게시나 새로운 LLM 호출은 필요하지 않다.

1. Studio 도구줄에 ‘저장본 복제’(새 탭/noopener) 링크를 추가한다. `/dashboard/:id/reuse?editor=studio`만 전달한다.
2. 소유 reuse 화면에서만 `editor=studio`를 인식해 원본 링크와 저장 성공 후 새 복사본 Studio로 연결한다. 임의 return URL은 허용하지 않고 공유 수신자 흐름/기존 기본 이동은 유지한다. 미저장 편집 제외를 화면에 명시한다.
3. 관련 단위로 링크/저장본 문맥·기존/Studio 이동·잘못된 query·저장 실패/미리보기 계약을 검증한다.
4. Ego:45 원본 미저장 블록/질문 유지 → 새 탭 → 새 소스34 → 전체 미리보기 → 비공개 새 복사본 저장 → Studio/reload 확인. 소스 수치·원본 정의/배치/revision·게시 불변을 비교하고390/768/1440 크기·정렬을 확인한다. 검증 후 원본 초안만 undo/입력 정리한다.
5. 관련 FE/type/lint/build·AIWF 증빙 후 commit/push한다. 새 서버/저장 알고리즘/공개 게시·운영/실휴대폰/전체 고객 수용은 범위 밖이다.

## 복사본 AI 편집 후속

소스 교체로 생성한46/source34에서 선택 블록 제목만 AI로 변경 → 실제 계산 미리보기 → 명시 저장 → reload를 확인한다. 원본45·비대상 정의·블록ID·모든 폭 배치·10%/300 수치는 유지해야 한다. 새 지표·재복제·공개 게시 없이 진행하며 기존 생성/복제/게시 성공을 반복 통과로 집계하지 않는다. 공백이 발견되면 필요한 최소 수정과 관련 회귀만 추가한다. 검증 제목은 정상 저장으로 원복하며 revision 변경은 별도로 기록한다.
