# UC-010 — 블록 포인터 배치 편집

P1 / FR-009·010. 기존 react-grid-layout을 재사용하여 미리보기의 손잡이 이동과 모서리 크기 조절을 제공한다. 선택한 화면 폭의 배치만 공통 초안과 undo/redo에 기록한다. 드래그 종료에서만 반영하며 초기 렌더/차트 조작은 편집으로 취급하지 않는다.

배치만 변경하면 마지막 서버 결과를 화면에 유지하되 저장 권한은 무효화한다. 서버 미리보기의 범위·겹침 검증 후에만 저장한다. 내용 변경은 결과 캐시를 제거한다. 키보드 방향키 이동 및 Shift+방향키 크기 조절도 동일 경로를 사용한다. 충돌/범위 초과/요청 중 조작은 반영하지 않는다.

검증은 컴포넌트 이벤트·키보드·초안 transport·undo·저장 gate 회귀와 타입/린트/빌드다. 이전 브라우저 정책 차단 때문에 실제 포인터/터치, 390/768/1440 크기·정렬 및 Rill 실제 화면 비교는 BLOCKED로 남긴다. 우회하지 않는다. AI 배치 명령과 공유 화면 배치는 후속 범위다.
