# UC-010 — 블록 포인터 배치 편집

P1 / FR-009·010. 기존 react-grid-layout을 재사용하여 미리보기의 손잡이 이동과 모서리 크기 조절을 제공한다. 선택한 화면 폭의 배치만 공통 초안과 undo/redo에 기록한다. 드래그 종료에서만 반영하며 초기 렌더/차트 조작은 편집으로 취급하지 않는다.

배치만 변경하면 마지막 서버 결과를 화면에 유지하되 저장 권한은 무효화한다. 서버 미리보기의 범위·겹침 검증 후에만 저장한다. 내용 변경은 결과 캐시를 제거한다. 키보드 방향키 이동 및 Shift+방향키 크기 조절도 동일 경로를 사용한다. 충돌/범위 초과/요청 중 조작은 반영하지 않는다.

검증은 컴포넌트 이벤트·키보드·초안 transport·undo·저장 gate 회귀와 타입/린트/빌드다. 이전 브라우저 정책 차단 때문에 실제 포인터/터치, 390/768/1440 크기·정렬 및 Rill 실제 화면 비교는 BLOCKED로 남긴다. 우회하지 않는다. AI 배치 명령과 공유 화면 배치는 후속 범위다.

## Ego 후속 검증 — 2026-10-15

사용자의 최신 Ego 지정으로 실제 마우스 gate를 재검증했다. 검증 분석22에서 데스크톱/모바일 각각 모서리 resize·손잡이 drag→저장 차단→서버 미리보기→저장→브라우저 reload→편집기 좌표 재확인을 수행했다. 태블릿/두 KPI 유지와390/768/1440 저장 화면 grid·가로 넘침0·컨트롤 정렬도 확인했다. 코드 수정이 필요한 회귀는 발견되지 않았다.23개 관련 테스트 PASS. [실행 증빙](../testing/pointer-block-layout.md#ego-실제-포인터-후속--2026-10-15). 실제 휴대폰/터치·게시본 배치·모든 충돌 변형은 별도 gate다.

## Ego 터치·경계 검증 계획 — 2026-10-15

사용자 지정 Ego의390px 모바일 터치 에뮬레이션으로 분석22를 검증한다. trusted touch 입력/실제 접촉 대상과 UI 좌표를 함께 기록하고 초기 전환 애니메이션의 측정은 제외한다. 손잡이 이동·모서리 크기 변경→두 단계 undo/redo, 겹침 이동/리사이즈·좌상/우측 경계·최소/최대 너비를 확인한다. 변경 후 저장 차단→서버 미리보기→저장→reload→편집 좌표와 다른 폭 보존을 확인한다. 제품 회귀가 확인되면 해당 동작의 회귀 테스트 후 최소 수정하고 같은 터치 경로를 재검증한다. 종료는 실제 증빙·문서 검사·commit/push이며 실제 휴대폰·모든 브라우저/멀티터치를 완료로 간주하지 않는다.

### 터치 검증 중 발견한 작은 차트 표시 회귀

분석22의 모바일 OS 블록을2칸으로 줄이면 약150px canvas에서 category containLabel이 긴 범주명 폭을 확보해 막대 plot이 거의0이 된다. 블록·데이터 계약을 바꾸지 않고 기존 LineChart의 ECharts media 규칙을 확장한다.260px 이하에서는 범주 라벨을48px 말줄임하고 우측 여백을12px로 줄인다. 폭을 다시 늘렸을 때 라벨 제한이 해제되도록 중간/기본 규칙을 명시한다. 기존 카테고리/정확값/데이터 표 보존 회귀와 resize 테스트를 먼저 수정해 실패 확인→최소 구현→실제 Ego 작은/큰 카드 재검증한다.
