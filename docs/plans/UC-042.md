# UC042 — 초안을 유지하며 저장 목록 열기

Status: Draft · P3 · TC-005 반복 편집 진입 지원.

Studio 편집 헤더에는 목록 진입이 없다. 현재 탭을 이탈하거나 초안을 폐기하지 않고 저장 목록을 찾도록 캔버스 도구줄의 ‘목록’을 별도 탭 링크로 제공한다. 미저장 블록·질문·실행은 기존 편집 탭에 유지하고 자동 저장·AI·게시를 실행하지 않는다. 브라우저 뒤로/기존 보기 등 다른 이탈 경로 전체를 보호하는 기능으로 확장하지 않는다.

1. 실제 Studio 캔버스 도구줄에 기존 Button outline/sm과 native anchor(target blank, noopener noreferrer)를 재사용한다. 별도 product context 속성이나 시안 변경은 추가하지 않는다.
2. 저장됨/미저장 상태의 링크 목적지·새 탭·rel·쓰기 없음·편집 상태 보존을 관련 컴포넌트로 검증한다.
3. Ego에서45 편집 → 미저장 블록 복제/질문 입력 → 목록 새 탭 → 편집 탭 복귀 시 보존 → undo 원복을 확인한다.390/768/1440 헤더·도구줄 크기·정렬·넘침을 확인한다. 서버 저장본은 변경하지 않는다.
4. 관련 FE/타입/lint·증빙을 동기화하고 commit/push한다. 운영/실휴대폰/전체 이탈 가드·제품 수용은 별도다.

실제 검증에서 보조 패널 닫기/재열기 시 질문이 사라지는 기존 공백을 발견했다. 목록 링크 접근 전 패널을 닫는 흐름과 연결되므로 같은 편집 Workspace가 입력을 소유하고 Conversation에 선택적 controlled draft를 전달한다. 대시보드/Workspace 교체·페이지 reload까지 영구 복구하는 계약은 추가하지 않는다. 패널 닫기/재열기의 질문 보존 회귀와 실제 재검증을 추가한다.
