# Glossary

| Term        | Definition                                                                        | Avoid |
| ----------- | --------------------------------------------------------------------------------- | ----- |
| 운영 담당자 | 질문하고 분석을 검토·저장하는 커머스 팀 구성원.                                   |       |
| 데이터 소스 | 분석할 원본 파일과 연결 메타데이터.                                               |       |
| 지표 정의   | 계산 기준·단위·표시 정밀도의 의미. 현재 저장 지표는 Metric.definition을 사용한다. |       |
| 분석 화면   | 지표와 분류별 결과의 표현 및 조회 상태.                                           |       |
| 시계열      | 같은 지표를 시간 버킷별로 계산한 결과.                                            |       |
| 미리보기    | 아직 저장하지 않은 분석 정의를 실행한 결과.                                       |       |

| 저장 지표 | 기존 Metric.definition에 저장한 소스별 구조화 계산 정의. | |

Definition version은 저장 지표 계산식을 변경할 때 증가시키는 양의 정수다. UC-003은 미리보기 당시 버전과 분석 revision을 함께 확인하며, 승인이나 자동 전체 분석 전파를 의미하지 않는다.

| Term            | Definition                                                                    | Avoid |
| --------------- | ----------------------------------------------------------------------------- | ----- |
| Measure         | 재사용하는 저장 지표의 계산 의미와 버전. 고객 화면에서는 지표로 표현한다.     |       |
| Dimension       | 그룹/필터의 분류 기준. 현재 원본 열 기반이며 목표는 명시 정의·재사용이다.     |       |
| Block           | 안정적 논리 ID로 내용·표시·배치를 편집하는 대시보드 요소. 목표 모델이다.      |       |
| Publication     | 편집 초안과 구분된 게시 버전, 공유 범위와 데이터 시점의 계약. 목표 모델이다.  |       |
| 복제본          | 원본을 변경하지 않는 새 소유자의 대시보드 정의와 배치. 새 소스 접근은 별도다. |       |
| 데이터 snapshot | 특정 조회 조건/시점의 저장 결과. 정의 snapshot 및 live 조회와 구분한다.       |       |

## UC-012 design terms

| Term             | Definition                                                                                                                                                                              | Avoid                               |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| AnalysisProposal | 지표·원본 차원·블록의 구조화 제안. 제안/미리보기는 DB를 쓰지 않으며 저장 권한이나 완료 증거가 아니다. A/B API와 기존 질문 UI 연결이 구현됐으며 실제 화면 검증은 승인 차단으로 미완료다. | AI SQL을 그대로 저장 정의로 간주    |
| 계산 정규형      | 소스·집계·검증 열·계산 인자·단위로 만든 지표 의미. 표시명·정밀도·축약은 별도 블록 표시다.                                                                                               | 이름만 같으면 재사용                |
| CreationReceipt  | 같은 사용자/requestId의 동일 저장 분석 ID를 찾는 영수증. B에서 지표·분석과 같은 transaction에 기록하며 로컬 SQLite로 검증했다.                                                          | 메모리 mutex만으로 모든 재시도 보장 |

| 보관 초안 | UC025가 같은 로그인 세션·브라우저 탭에 최대24시간 보관하는 미저장 블록 정의·질문. 저장본/게시본/서버 미리보기와 구분한다. UC028의 정상 토큰 갱신은 동일 scope를 유지하고 새 로그인은 분리한다. | 자동 저장본 |

## 기업 사내 분석 용어 — 목표 계약

| Term          | Definition                                                         | Avoid                            |
| ------------- | ------------------------------------------------------------------ | -------------------------------- |
| 분석 카탈로그 | 관리자가 이용 범위와 업무 변수 의미를 관리하는 승인 원천 목록.     | 모든 업로드의 자동 공식 등록     |
| 업무 변수     | 실제 열과 연결된 표시명·유형·날짜 형식·단위·분류 기준.             | 이름만 같은 열의 무조건 치환     |
| 수신자 전달   | 조회 접근 부여와 독립 사본 전달을 명시 구분하는 관계.              | 공유 취소 시 본인 사본 자동 삭제 |
| 실행 문맥     | 소스/지표 버전·조건·기간/시간대·제외/결과 범위를 고정한 비교 기준. | 샘플과 전체 결과 혼합            |
| 개인 보관     | 본인 기본 목록에서 숨기고 현재 권한으로 복원하는 상태.             | 원본 삭제·공유 중지              |

새 용어의 구현/검증 상태는 [기업용 설계](architecture/enterprise-analysis.md)와 TC050을 따른다.
