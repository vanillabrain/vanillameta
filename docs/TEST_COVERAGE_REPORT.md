## 3. 핵심 모듈 상세 분석

### 높은 커버리지 모듈 (90% 이상) ✅

#### auth 모듈 (95.2%)
- **강점**: 모든 인증 플로우가 완벽하게 테스트됨
- **테스트 완료 항목**:
  - JWT 토큰 생성/검증
  - 리프레시 토큰 로직
  - 권한 검사 (Guards)
  - 비밀번호 암호화

#### utils 모듈 (94.8%)
- **강점**: 유틸리티 함수들의 엣지 케이스까지 커버
- **테스트 완료 항목**:
  - 데이터 변환 함수
  - 검증 헬퍼
  - 날짜/시간 유틸리티
  - 암호화 유틸리티

### 중간 커버리지 모듈 (80-90%) ⚠️

#### widget 모듈 (86.3%)
- **개선 필요 영역**:
  - 복잡한 차트 옵션 변환 로직
  - 에러 처리 분기
- **추가 테스트 필요**:
  - 대용량 데이터 처리
  - 동시성 시나리오

#### database 모듈 (84.5%)
- **개선 필요 영역**:
  - 다양한 DB 엔진별 처리
  - 연결 실패 시나리오
- **추가 테스트 필요**:
  - 타임아웃 처리
  - 트랜잭션 롤백

### 낮은 커버리지 모듈 (80% 미만) ❌

#### pages (프론트엔드) (79.8%)
- **원인**:

  - 외부 라이브러리 의존성
- **개선 계획**:
  - E2E 테스트로 보완
