# 사내 시각화 산출물 제품 범위

2026-10-18 사용자 지시: MK AI는 별도 프로젝트로 구현하며 연동 계약은 현재 우선순위에서 제외한다. VM 단독 사내 기능을 먼저 만든다. 기존 제작·편집·저장·게시·복제 계약을 유지한다. 이 문서는 구현/고객 수용 완료를 뜻하지 않는다.

| 순서 | 결과           | 범위/완료 조건                                                                                                   |
| ---- | -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 1    | 산출물 보관함  | 현재 허용 목록 검색·유형/정렬(UC049 첫 단위), 이후 즐겨찾기·보관을 사용자별 영속 기능으로 설계                   |
| 2    | 사내 권한·공유 | 조직/부서/초대 수신자, 열람/편집/게시 권한과 서버 데이터 권한 검증. 현재 소유자/링크 권한으로 완료 처리하지 않음 |
| 3    | 공식 지표·출처 | 공식/임시 지표·단위·기간/기준시각·확정/잠정 표시, 변경 영향과 검토                                               |
| 4    | 갱신형 게시    | 승인 정의 버전과 데이터 실행 이력 분리. 갱신 실패 시 마지막 정상 결과와 지연 표시. 확정 snapshot 유지            |
| 5    | 재사용·조합    | 템플릿/복제·소스 교체, 독립 복사와 원본 참조를 구분하는 EIS 조합/사용처 추적                                     |
| 후속 | 협업·배포      | 댓글/검토, 구독/출력/활용 현황. MK AI API/MCP 계약은 이후 요청에 따라 진행                                       |

기본 화면은 결과물 목록과 검색/필터, 편집은 선택 블록 설정을 사용한다. 내부 Source/Measure/Dimension 파일 관리나 통합 모드를 고객에게 선행 선택으로 요구하지 않는다. UC049는 현재 서버 허용 목록 안의 탐색만 개선하며 부서 공유·공식지표·갱신 기능을 구현했다고 주장하지 않는다. Rill은 공통 지표/Canvas→Explore, Claude Artifacts는 대화와 결과물 편집·공유 흐름을 참고한다. 외부 제품 기능은 VM 구현 증거가 아니다.

## 사내 분석 추가 요건

[기업용 설계](../architecture/enterprise-analysis.md)에 FR014~025/NFR005~008·UC050~055·TC050을 연결했다. 데이터 카탈로그/업무 변수·직원/서버 권한을 사내 공유의 선행 단위로 포함하고 조건/분포·수신자 전달/알림·비동기 출력·보관 영향까지 일반화한다. 기존 FR004~006/012/013은 재사용하며 새로운 구현 완료로 중복 집계하지 않는다. 제품별 한도와 운영 목표는 별도 설계하며 서버 권한과 독립 사본 보존을 유지한다. MK AI 연동 보류는 유지한다.
