# 외부 초대 베타 전략 (2026-10-23)

## 결정

- 1차 목표는 **Claude Artifacts와 같은 데이터 시각화 경험을 외부 사용자에게 배포**하는 것이다.
  - 흐름: 가입(초대) → 파일 업로드 또는 샘플 → 프롬프트 → 스트리밍 생성 → 채팅 수정 → 저장 → 공개 링크·임베드·리믹스.
- 최종 목표는 Rill과 같은 BI 솔루션이다. 1차 목표의 스펙은 선언형·직렬화 가능으로 유지해 메트릭 레이어와 BI-as-code로 확장한다.
- 이 문서는 [internal-artifacts.md](internal-artifacts.md)의 "사내 Artifact 우선"과 AGENTS.md의 "다음 최우선은 고객 한업무질문·독립정답 파일럿" 우선순위를 **대체한다.** 엔터프라이즈 거버넌스(UC050~055)는 구현된 범위를 유지하고 신규 확장은 중단한다.

## 범위

| 항목 | 베타 결정 |
| --- | --- |
| 인프라 | 단일 VM + Docker Compose, MySQL, 영속 볼륨, HTTPS 프록시. Lambda 경로는 폐기 |
| LLM | AI SDK 제공자 레지스트리(Anthropic/OpenAI/호환). 로컬 Codex CLI는 개발 전용 |
| 가입 | 초대 코드 또는 대기자 승인. 공개 가입은 닫는다 |
| 데이터 | 업로드(CSV/JSON/Parquet)와 샘플만. 외부 DB 연결은 막는다(SSRF 방지) |
| 표현력 | 선언형 스펙 확장. 임의 코드 실행(HTML/JS 샌드박스)은 포함하지 않는다 |
| 공유 | Studio publication을 유일한 외부 경로로 한다 |

## 출시 게이트

1. 법무: 이용약관·개인정보처리방침(AI 제공자를 처리 위탁자로 명시)·제공자의 무보존/학습 미사용 조건 확인·계정/데이터 삭제 경로.
2. 운영 기준선: 빈 DB를 `migrate-prod` 부트스트랩(엔티티 스키마 + 참조 데이터 + 마이그레이션 이력 기록)으로 구성 가능, 위험한 설정은 부팅 거부, 백업 복원 실증.
3. 사용자 간 데이터 격리 증명, 공개 링크 데이터 노출 고지·기본 만료.
4. 사용자별 쿼터와 전역 월간 비용 차단기, 사용량 원장.
5. 실제 LLM 1개 제공자로 운영 URL에서 전체 여정 실행 증빙.

## 전제와 제약

- 일부 상태(게시 티켓, 제안, 실행 멱등성, Codex 동시성 카운터)가 프로세스 메모리에 있어 **단일 인스턴스**만 지원한다.
- 운영/실기기/사람 수용은 출시 게이트 증빙과 별도로 Open이다. 미실행 항목을 통과로 보고하지 않는다.
