# VanillaMeta 초기 시장 진입 제안

작성: 2026-10-12 KST. 결정용 가설이며 고객 인터뷰·실매출·시장 규모를 측정한 결과가 아니다. 경쟁 기능은 공식 문서, 제품 기반은 현재 README 및 구현/검증 이력 기준이다. 기존 제품 코드 변경·커밋·공개·고객 연락은 수행하지 않았다.

## 추천 결정

초기 타깃은 **두 개 이상 판매 채널의 주문 파일을 매주 엑셀로 합치는 소규모 커머스 운영팀**으로 정한다. 구매자는 대표 또는 운영 책임자, 사용자는 파일 취합·주간 보고 담당자다. 모집에서는 데이터팀 없음, 주간 수작업 2시간 이상, 안정적인 내보내기 형식, 같은 원화 기준을 확인한다. 이 조건은 모집 가설이며 실제 수요 통계가 아니다.

초기 메시지: **주문 파일을 넣으면 채널·상품별 주간 성과를 같은 기준으로 보여주고, 다음 파일을 넣어도 중복 없이 갱신되는 BI.**

사용자가 직접 데이터를 넣고 확인하는 셀프서비스 BI가 중심이다. Claude/MCP는 추후 진입 경로로 추가할 수 있지만 첫 유료 가치로 삼지 않는다. 현재 README의 MCP는 로드맵이며 구현 완료로 설명하지 않는다.

이는 경쟁사가 원천적으로 구현할 수 없는 기능이라는 주장과 다르다. 파일·업무별 매핑, 계산 검증 사례, 빠른 온보딩, 반복 사용 습관을 축적해야 방어력이 생긴다. 오픈소스·MCP·차트 수 자체는 차별화 근거가 부족하다.

## 최소 제품

기존 기반: CSV/JSON/Parquet 분석·저장 데이터셋·차트·대시보드·공유·AI SQL/추천·메트릭. 아직 최소 제품 전체 완료를 의미하지 않는다. XLSX/Sheets, 예약 보고, 제한된 임베드 토큰/테넌트, MCP는 README 로드맵이다.

1. **실제 파일 두 형식부터 지원**: 인터뷰에서 반복되는 판매 채널 두 개를 선정한다. 컬럼 매핑을 미리 제시하고 사용자가 날짜·금액·상태·주문 단위를 확인한다. CSV 우선. XLSX만 가능한 고객은 파일을 받아 전환 부담을 측정하고, 빈도가 높으면 XLSX를 출시 필수로 승격한다.
2. **한 개의 주간 성과 템플릿**: 주문 수, 주문일 기준 상품 순판매액, 같은 기준의 객단가, 채널별·상품별 성과와 완결된 전주 비교. 데이터로 확인 못 하는 원가·이익·광고 ROAS·재구매율은 표시하지 않는다.
3. **반복 업로드의 정확성**: 출처/쇼핑몰/주문/주문행 식별키로 중복 검토·upsert. 신규 행과 변경 행, 거부 행 수를 미리 보여준다. 키가 없으면 임의 삭제·병합 대신 확인을 요구한다. 부분 파일과 전체 스냅샷의 의미를 구분하며 파일에서 사라졌다고 자동 삭제하지 않는다.
4. **갱신의 지속성**: 매핑·지표·레이아웃 유지, 적용 전후 합계·데이터 기준 시점·파일 이력·복원 기능. 같은 파일을 다시 넣어도 값이 늘지 않아야 한다.
5. **근거와 오류 표시**: 수치마다 필터·계산 기준·대상 기간·집계 대상·제외 행 수 확인. 누락 금액은 0으로 숨기지 않는다. AI 요약은 검증된 지표를 설명하고 매출 변화의 원인을 단정하지 않는다.
6. **한 팀의 보고 흐름**: 읽기 전용 공유 또는 로그인한 구성원 확인, 데이터 내보내기·삭제. 이름/연락처/주소는 기본 분석에서 제외한다. 파일 데이터의 브라우저/서버 저장 경로를 설명한다. 공개 공유는 명시적으로 선택하며 개인정보를 포함하지 않도록 한다.

지표 약속: 원화·KST, 주문행 기준. 상품 순판매액은 배송비·세금·할인·환불의 파일 표현을 확인해 고객과 계산 기준을 합의한 뒤 저장한다. 환불 이력이 지원되면 상품 결제금액에서 해당 상품 환불액을 빼고, 취소와 환불을 중복 차감하지 않는다. 주문일 기준에 누적 환불을 반영하는 지표는 현금흐름·회계 매출로 부르지 않는다. 과거 수치는 늦은 환불로 바뀔 수 있으며 적용 시점을 표시한다. 객단가의 분모는 같은 필터·기간의 고유 주문 수다. 다중 상품 행에 반복된 주문 총액을 더하지 않는다. 공통 상품키가 없으면 채널별 상품을 유지하고 무리하게 합치지 않는다.

파일 크기·행 수 상한은 현재 지원을 추정하지 않고 대표 실제 파일로 성능을 확인해 공개한다. 모집 대상 파일이 그 상한을 넘으면 BLOCKED로 기록한다.

초기 제외: 모든 쇼핑몰 API, 광고·재고·회계 통합, AI 에이전트 자동 실행, 새 차트 종류, 대기업 기능. 공개 멀티테넌트 SaaS 전에 격리·권한 검증이 필요하다. 유료 파일럿은 팀별 격리 인스턴스로 제공할 수 있다.

정확성·기본 권한·중복 방지·데이터 반출을 결제 장벽으로 삼지 않는다. 비기술 구매자에게 오픈소스는 주 구매 이유가 아니라 통제·신뢰의 보조 근거다. 개발자·운영 파트너가 설치·개선·추천하게 만드는 유입 경로로 활용한다. GitHub 공개 범위/현재 공개 여부는 이번에 변경하지 않았다.

가격 실험: 한 팀 월 **49,000원**의 관리형 파일럿을 제안한다(VAT 별도, 최종 가격/원가 검증 전). 같은 조건으로 실제 첫 달 결제와 다음 결제를 확인한다. 무제한 AI·저장·맞춤 개발은 포함하지 않는다. AI 요약은 생략 가능하게 하고 원가 상한/BYOK 선택을 명확히 한다. 호스팅·AI·지원 시간을 포함한 팀별 원가를 측정한다. 창업자 상시 대행이 필요하면 SaaS 가치로 판정하지 않는다.

## 4주 고객 검증

일정은 검증 단계 제안이며 모든 구현을 4주 내 완료한다는 개발 견적이 아니다.

- **1주: 인터뷰 10팀**. 지난 주 실제 보고서, 데이터 파일 2개 이상, 수행 단계, 빈도, 소요시간, 오류 사례, 기존 도구, 구매자를 확인한다. 익명화된 샘플 파일·보고서 제공 동의를 받는다. 상상한 기능 선호 대신 실제 마지막 업무를 관찰한다.
- **2주: 파일럿 6팀 고정 모집**. 최초 템플릿 준비에는 수동 작업을 허용하고 비용/시간을 별도로 기록한다. 독립 수작업 정답과 지표를 대조한다. 최소 두 종류 파일 형식이 여러 팀에서 반복되는지 확인한다.
- **3주: 담당자 직접 사용**. 창업자가 클릭하지 않는 첫 분석과 다음 주 갱신을 관찰한다. 기본 교육 시간을 분리하고 수행 단계별 개입을 기록한다. 정상 업데이트·동일 파일 중복·수정 주문·부분 환불·잘못된 날짜·빈값·같은 주문의 여러 상품을 확인한다.
- **4주: 결제와 유지 신호**. 동일 가격 제안, 실제 결제, 기존 작업 대체 여부, 제품에 반영한 업무 결정 사례를 확인한다. 월별 갱신 결제는 다음 달까지 계속 관찰하며 4주 내 확인했다고 주장하지 않는다.

모집 경로 후보: 셀러 운영 커뮤니티·독립몰 운영 파트너·주문 취합을 담당하는 컨설턴트. 먼저 동의를 얻어 개별 모집한다. 이번 작업에서 외부 연락은 하지 않았다. 시장 규모·현재 네트워크·획득 비용은 미확인이다.

| 유료 가치 | 3/6팀 이상 월49,000원 실제 결제; 다음 달 재결제로 지속성 확인 |
| 제품화 | 온보딩 후 팀당 주간 지원 20분 이하를 목표로 관측; 맞춤 코드 없이 반복 형식 처리 |

금액·중복·권한 오류는 고객이 만족해도 출시 중단 사유다. 위 기준은 작은 표본의 진행/중단 판단이며 전체 시장 수요 통계로 일반화하지 않는다.

첫 분석만 빠르고 갱신·결제가 안 되면 차트 생성 기능을 늘리지 않는다. 연결이 구매 병목이면 가장 공통인 채널 연결 한 개를 추가한다. 파일 형식이 모두 달라 지원 비용이 높으면 동일 업종/판매 채널 쌍으로 더 좁힌다. 기본 플랫폼 통계로 충분하다는 반응이 많으면 타깃을 바꾸고, 연락 가능한 유료 후보가 다른 고객군에 집중되면 순위를 재평가한다.

## 공식 근거와 미확인 사항

- [Claude Dashboards 안내](https://support.claude.com/en/articles/17454700-get-started-with-claude-dashboards): 자연어/SQL/연결 데이터/갱신 시점. 실제 사용 성능 비교는 미실행.
- [Google CSV 업로드 문서](https://docs.cloud.google.com/data-studio/upload-csv-files): 무료 업로드와 append, 중복 제거 없음. 조회 중 기존 Looker Studio URL이 Data Studio 문서로 리다이렉트됨.
- [Power BI 가격](https://www.microsoft.com/en-us/power-platform/products/power-bi/pricing): 무료 작성·유료 공유. 현재 미국 표시 Pro $14/user/month 연간 결제; 국내 견적과 동일하다고 가정하지 않음.
- [Cafe24 통계](https://www.cafe24.com/commerce/manage/statistics.html): 기본 매출·상품/취소 랭킹. 이것만 필요한 고객은 제외.
- [Whatagraph 공식 가격](https://whatagraph.com/pricing): 현재 Max €699/month 연간 결제, 50 source credits부터. 저가 경쟁 전체를 대표하는 가격 아님.
- [Metabase AI](https://www.metabase.com/features/metabase-ai): 오픈소스 AI/MCP 포함. 오픈소스 자체가 고유 차별점은 아님.
- [Datarize 공식 소개](https://whitepaper.datarize.ai/): 행동/구매 데이터와 개인화 마케팅 실행. 파일 통합 BI와 인접 경쟁.
- 내부 근거: README.md의 기능·지원 DB 상태·로드맵, 최근 차트/공유/파일 화면 검증. 실제 타깃 파일 형식·XLSX·반복 upsert·복합 계산은 별도 검증/구현 필요.

고객 접근성·실제 지불 의사·시장 규모·획득 비용·지원 원가는 미확인이다. 이 제안은 고객 6팀의 반복 사용과 결제 증거로 수정한다.
