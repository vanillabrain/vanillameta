## 1. 시작하기 전에

### 📋 필수 요구사항

#### 시스템 요구사항
- **OS**: Windows 10+, macOS 10.15+, Ubuntu 18.04+

- **저장공간**: 5GB 이상 여유 공간

#### 설치 필요 소프트웨어

**옵션 1: Docker 사용 (권장) - 가장 빠른 방법**

- Git

**옵션 2: 로컬 개발 환경**
- Node.js 18+
- Redis Server
- Git

## 2. 환경 구축 (10분)

### 🚀 방법 1: Docker Compose 사용 (권장)

#### 2.1 프로젝트 다운로드
```bash
# 프로젝트 클론
git clone https://github.com/vanillabrain/vanillameta.git
cd vanillameta

# 헬퍼 스크립트 권한 부여
chmod +x docker-compose-helper.sh
```

#### 2.2 로컬 개발 모드 실행
```bash
# SQLite를 사용한 로컬 개발 모드 실행
./docker-compose-helper.sh local

# 백그라운드 실행을 원하는 경우
./docker-compose-helper.sh local -d
```

#### 2.3 서비스 확인
```bash
# 서비스 상태 확인
./docker-compose-helper.sh status

# 로그 확인 (문제 발생시)
./docker-compose-helper.sh logs
```

#### 2.4 접속 확인

**프론트엔드 접속**: http://localhost:3001
**백엔드 API**: http://localhost:3000/api/v1

### 🛠️ 방법 2: 로컬 개발 환경

#### 2.1 Redis 설치 및 실행
```bash
# macOS (Homebrew)
brew install redis
redis-server --daemonize yes

# Ubuntu/Debian
sudo apt-get install redis-server
sudo systemctl start redis

# Windows (Chocolatey)
choco install redis-64
redis-server
```

#### 2.2 백엔드 실행
```bash
cd backend-api

# 의존성 설치
yarn install

# 환경 변수 설정
cp .env.local .env

# 데이터베이스 초기화 및 시드 데이터 생성
yarn seed:run

# 서버 시작
yarn start:local
```

#### 2.3 프론트엔드 실행
```bash
# 새 터미널에서
cd frontend-web

# 의존성 설치
yarn install

# 개발 서버 시작
yarn start
```

### ✅ 환경 구축 완료 확인

브라우저에서 http://localhost:3001 접속 시 다음 로그인 화면이 나타나면 성공입니다.

## 3. 데모 시나리오 실습 (15분)

### 🎯 시나리오 1: 첫 로그인 및 대시보드 탐색 (3분)

#### 3.1 로그인
1. http://localhost:3001 접속
2. 기본 계정으로 로그인:
   - ID: `guest`
   - 비밀번호: `Admin!@12`

#### 3.2 대시보드 살펴보기
1. 메인 대시보드 화면 확인
2. 좌측 메뉴 구성 확인:
   - **대시보드**: 대시보드 관리
   - **위젯**: 차트 위젯 관리
   - **데이터**: 데이터소스 및 데이터셋
   - **템플릿**: 대시보드 템플릿

### 🎯 시나리오 2: 데이터소스 연결 (SQLite) (3분)

#### 3.1 데이터소스 추가
1. **"데이터" → "데이터소스"** 메뉴 클릭
2. **"데이터소스 추가"** 버튼 클릭
3. 다음 정보 입력:
   ```
   연결 이름: Demo SQLite DB
   데이터베이스 타입: SQLite
   데이터베이스 파일: sqlite.db
   ```
4. **"연결 테스트"** → **"저장"**

#### 3.2 샘플 데이터 확인
```sql
-- 기본 제공되는 샘플 테이블 조회
SELECT * FROM sample_sales LIMIT 10;
```

### 🎯 시나리오 3: 데이터셋 생성 (3분)

#### 3.1 매출 분석 데이터셋
1. **"데이터" → "데이터셋"** 이동
2. **"데이터셋 추가"** 클릭
3. **Demo SQLite DB** 데이터소스 선택
4. 다음 SQL 쿼리 입력:

```sql
-- 일별 매출 추이 데이터셋
SELECT 
    DATE(order_date) as 날짜,
    COUNT(*) as 주문수,
    SUM(amount) as 총매출,
    AVG(amount) as 평균주문액
FROM sample_sales
WHERE order_date >= DATE('now', '-30 days')
GROUP BY DATE(order_date)
ORDER BY 날짜 DESC
```

5. **"실행"** 버튼으로 결과 확인
6. 데이터셋 이름: **"일별 매출 분석"**
7. **"저장"**

#### 3.2 카테고리별 매출 데이터셋
```sql
-- 제품 카테고리별 매출 분석
SELECT 
    category as 카테고리,
    COUNT(*) as 주문수,
    SUM(amount) as 매출액,
    ROUND(AVG(amount), 2) as 평균단가
FROM sample_sales
GROUP BY category
ORDER BY 매출액 DESC
```

데이터셋 이름: **"카테고리별 매출 분석"**

### 🎯 시나리오 4: 다양한 차트 위젯 생성 (4분)

#### 4.1 라인 차트 - 매출 추이
1. **"위젯" → "위젯 생성"** 클릭
2. **"일별 매출 분석"** 데이터셋 선택
3. **"라인 차트"** 선택
4. 데이터 매핑:
   - **X축**: 날짜
   - **Y축**: 총매출
   - **시리즈**: (없음)
5. 차트 제목: **"일별 매출 추이"**
6. **"저장"**

#### 4.2 파이 차트 - 카테고리 비중
1. 새 위젯 생성
2. **"카테고리별 매출 분석"** 데이터셋 선택  
3. **"파이 차트"** 선택
4. 데이터 매핑:
   - **카테고리**: 카테고리
   - **값**: 매출액
5. 차트 제목: **"카테고리별 매출 비중"**
6. **"저장"**

#### 4.3 바 차트 - 카테고리별 주문수
1. 새 위젯 생성
2. **"카테고리별 매출 분석"** 데이터셋 선택
3. **"바 차트"** 선택
4. 데이터 매핑:
   - **X축**: 카테고리
   - **Y축**: 주문수
5. 차트 제목: **"카테고리별 주문수"**
6. **"저장"**

#### 4.4 영역 차트 - 누적 매출
1. 다음 SQL로 새 데이터셋 생성:
```sql
-- 누적 매출 데이터
SELECT 
    DATE(order_date) as 날짜,
    SUM(amount) as 일매출,
    SUM(SUM(amount)) OVER (ORDER BY DATE(order_date)) as 누적매출
FROM sample_sales
WHERE order_date >= DATE('now', '-30 days')
GROUP BY DATE(order_date)
ORDER BY 날짜
```

2. **"영역 차트"** 로 누적매출 시각화

#### 4.5 게이지 차트 - 목표 달성률
1. 다음 SQL로 KPI 데이터셋 생성:
```sql
-- 월간 목표 달성률
SELECT 
    '이번 달 매출' as 지표,
    SUM(amount) as 실제값,
    500000 as 목표값,
    ROUND(SUM(amount) * 100.0 / 500000, 1) as 달성률
FROM sample_sales
WHERE strftime('%Y-%m', order_date) = strftime('%Y-%m', 'now')
```

2. **"게이지 차트"** 로 달성률 표시

### 🎯 시나리오 5: 대시보드 구성 및 공유 (2분)

#### 5.1 대시보드 생성
1. **"대시보드"** 메뉴 클릭
2. **"새 대시보드"** 생성
3. 대시보드 이름: **"매출 분석 데모 대시보드"**

#### 5.2 위젯 배치
1. 생성한 모든 위젯을 대시보드에 추가
2. 드래그 앤 드롭으로 레이아웃 조정:
   ```
   [매출 추이 라인차트      ] [KPI 게이지]
   [카테고리 파이차트] [카테고리 바차트]
   [누적 매출 영역차트      ]
   ```

#### 5.3 대시보드 공유
1. **"공유"** 버튼 클릭
2. **"공개 링크 생성"**
3. 생성된 URL을 새 탭에서 열어 확인

## 5. 트러블슈팅

### 🚨 일반적인 문제 해결

#### Docker 관련 문제

**문제**: `docker-compose: command not found`
```bash
# 해결: Docker Compose V2 사용
docker compose up -d

# 또는 헬퍼 스크립트 수정
sed -i 's/docker-compose/docker compose/g' docker-compose-helper.sh
```

**문제**: 포트 충돌 (3000, 3001 포트가 이미 사용 중)
```bash
# 사용 중인 포트 확인
lsof -i :3000
lsof -i :3001

# 프로세스 종료 후 재시도
kill -9 <PID>
```

**문제**: 컨테이너가 시작되지 않음
```bash
# 로그 확인
./docker-compose-helper.sh logs

# 완전 초기화 후 재시작
./docker-compose-helper.sh reset
./docker-compose-helper.sh local
```

#### 로컬 환경 문제

**문제**: Redis 연결 실패
```bash
# Redis 실행 상태 확인
redis-cli ping

# 응답이 없으면 Redis 시작
redis-server --daemonize yes
```

**문제**: SQLite 파일 권한 오류
```bash
# 권한 수정
chmod 666 backend-api/sqlite.db
```

**문제**: 의존성 설치 실패
```bash
# 캐시 정리 후 재설치
rm -rf node_modules package-lock.json
npm install

# 또는 yarn 사용
rm -rf node_modules yarn.lock
yarn install
```

#### 브라우저 관련 문제

**문제**: 로그인 화면이 나타나지 않음
- **해결**: 브라우저 캐시 삭제 (Ctrl+Shift+Delete)
- **확인**: 개발자 도구 콘솔에서 오류 메시지 확인

**문제**: 차트가 표시되지 않음
- **해결**: 브라우저 새로고침 (F5)
- **확인**: 데이터셋에 유효한 데이터가 있는지 확인

**문제**: 한글이 깨져서 표시됨
- **해결**: 데이터베이스 연결 설정에서 UTF-8 인코딩 확인

### 🔍 로그 분석

#### 유용한 로그 명령어
```bash
# 전체 로그 확인
./docker-compose-helper.sh logs

# 특정 서비스 로그만 확인
./docker-compose-helper.sh logs -f api
./docker-compose-helper.sh logs -f frontend

# 로컬 환경에서 백엔드 로그
cd backend-api && yarn start:local --verbose
```

#### 자주 발생하는 오류 메시지

**"Connection refused"**
- 원인: 데이터베이스 서버 미실행 또는 포트 차단
- 해결: 서버 실행 상태 및 포트 확인

**"CORS policy error"**
- 원인: 프론트엔드-백엔드 간 CORS 설정 문제
- 해결: `.env.local` 파일의 CORS_ORIGIN 설정 확인

**"Module not found"**
- 원인: 의존성 패키지 누락
- 해결: `npm install` 또는 `yarn install` 재실행
