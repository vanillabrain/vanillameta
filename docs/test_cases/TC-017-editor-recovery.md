# Test Case: Editor Request Recovery

## Overview

**ID:** TC-017
**Goal:** [UC-017](../use_cases/UC-017-editor-recovery.md)의 초안 보존·저장 상태 확인·충돌 선택·재시도.
**Priority:** High
**Status:** Draft

## Roles

- 운영 담당자: 초안·질문 유지, 저장 상태 확인, 충돌 선택, 다시 미리보기/저장.

## Preconditions

공개 Rill 분석22, 현재 revision, 기존 Codex/gpt-6-luna·Ego. 다른 작업의 서버는 종료하지 않는다.

## Flow

1. 두 편집 화면의 변경으로 실제409를 만들고 내 초안과 최신본을 확인한다.
2. 비대상 보존·명시 충돌 선택→다시 미리보기→저장/reload를 확인한다.
3. 실제commit뒤 응답을 유실시키고 상태 확인만으로 동일 저장을 확인한다.
4. 전달 전 실패는 초안을 유지한 채 확인→재미리보기/저장으로 복구한다.
5. 실LLM AI 요청을 취소하고 같은 질문을 재시도한다.
