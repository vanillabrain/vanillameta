# Test Case: Prompt Block Target

## Overview

**ID:** TC-015
**Goal:** [UC-015](../use_cases/UC-015-prompt-target.md)의 사전 선택 없는 단일 대상 수정과 모호 대상 복구.
**Priority:** High
**Status:** Draft

## Roles

- 운영 담당자: 질문·후보 선택·미리보기·저장.

## Preconditions

공개 Rill 검증 분석22·지정 Codex/gpt-6-luna, 기존UC014 실행과 저장.

## Flow

1. 미선택 상태에서 번호/정확 제목으로 수정+저장하고 reload한다.
2. 대상 없는 질문으로 후보를 받고 초안/이력/DB 무변경을 확인한다.
3. 후보 선택 후 같은 질문을 실행하고 비대상 보존과 대표UI를 확인한다.
