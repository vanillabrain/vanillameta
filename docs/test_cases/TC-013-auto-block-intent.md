# Test Case: Automatic Block Intent

## Overview

**ID:** TC-013
**Goal:** UC-013의 모드 선택 없는 질문 수정과 기존 저장 경계 보존.
**Priority:** High
**Status:** Draft

## Roles

- 운영 담당자: 소유 분석의 선택 블록 질문·미리보기·저장.

## Preconditions

[UC-013](../use_cases/UC-013-auto-block-intent.md), 공개 Rill 검증 분석·지정 LLM. 실제 기기·다른 사용자 원본은 변경하지 않는다.

## Flow

1. 모드 선택 없이 선택 블록의 소수 표시를 질문한다.
2. 같은 블록을 아래 한 칸 이동하도록 질문한다.
3. 복합/모호 질문의 고정 안내와 초안 보존을 확인한다.
4. undo/redo·미리보기·저장·reload 후 비대상과 다른 폭을 비교한다.
