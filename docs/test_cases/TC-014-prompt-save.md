# Test Case: Explicit Prompt Save

## Overview

**ID:** TC-014
**Goal:** [UC-014](../use_cases/UC-014-prompt-save.md)의 명시 저장 실행과 실패 보존.
**Priority:** High
**Status:** Draft

## Roles

- 운영 담당자: 소유 분석 편집·질문·저장.

## Preconditions

공개 Rill 검증 분석22와 지정 Codex/gpt-6-luna 및 기존 저장 API.

## Flow

1. 선택 없이 직접 수정 후 “현재 초안을 저장해 줘”를 요청한다.
2. 선택 블록 소수 변경과 저장을 함께 요청한다.
3. 각 미리보기/저장/reload·비대상 유지와390/1440 UI를 확인한다.
