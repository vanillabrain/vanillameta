# VanillaMeta 개발 가이드

## 🚀 시작하기

### 필수 요구사항

- Node.js 14.x 이상
- npm 또는 yarn
- Git
- (선택) Docker

### 초기 설정

1. **저장소 클론**

```bash
git clone [repository-url]
cd vanillameta
```

2. **의존성 설치**

```bash
# Backend
cd backend-api
npm install

# Frontend
cd ../frontend-web
npm install
```

3. **환경 설정**

Backend (.env 파일 생성):

```env
NODE_ENV=local
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=your_password
DB_DATABASE=vanillameta
JWT_SECRET=your_jwt_secret
```

Frontend (.env 파일 생성):

```env
REACT_APP_API_URL=http://localhost:4000/api
```

4. **데이터베이스 초기화**

```bash
cd backend-api
npm run seed
```

5. **서버 실행**

```bash
# Terminal 1: Backend
cd backend-api
npm run start:local

# Terminal 2: Frontend
cd frontend-web
npm run start:local
```

## 🛠️ 개발 워크플로우

### 1. 새로운 기능 개발

#### Backend 새 API 추가하기

1. **Entity 생성**

```typescript
// src/example/entities/example.entity.ts
@Entity("example")
export class Example extends BaseEntity {
  @Column()
  name: string;

  @Column({ type: "text", nullable: true })
  description?: string;
}
```

2. **DTO 생성**

```typescript
// src/example/dto/create-example.dto.ts
export class CreateExampleDto {
  @IsString()
  @IsNotEmpty()
  name: string;

  @IsOptional()
  @IsString()
  description?: string;
}
```

3. **Service 생성**

```typescript
// src/example/example.service.ts
@Injectable()
export class ExampleService {
  constructor(
    @InjectRepository(Example)
    private exampleRepository: Repository<Example>
  ) {}

  async create(createExampleDto: CreateExampleDto) {
    const example = this.exampleRepository.create(createExampleDto);
    return await this.exampleRepository.save(example);
  }
}
```

4. **Controller 생성**

```typescript
// src/example/example.controller.ts
@Controller("api/examples")
@UseGuards(JwtAuthGuard)
export class ExampleController {
  constructor(private readonly exampleService: ExampleService) {}

  @Post()
  create(@Body() createExampleDto: CreateExampleDto) {
    return this.exampleService.create(createExampleDto);
  }
}
```

5. **Module 등록**

```typescript
// src/example/example.module.ts
@Module({
  imports: [TypeOrmModule.forFeature([Example])],
  controllers: [ExampleController],
  providers: [ExampleService],
})
export class ExampleModule {}
```

#### Frontend 새 페이지 추가하기

1. **API Service 생성**

```typescript
// src/api/exampleService.ts
export const exampleService = {
  getList: async () => {
    const response = await authAxios.get("/examples");
    return response.data;
  },

  create: async (data: CreateExampleData) => {
    const response = await authAxios.post("/examples", data);
    return response.data;
  },
};
```

2. **페이지 컴포넌트 생성**

```tsx
// src/pages/Example/index.tsx
const ExamplePage = () => {
  const [examples, setExamples] = useState([]);
  const { setLoading } = useContext(LoadingContext);

  useEffect(() => {
    fetchExamples();
  }, []);

  const fetchExamples = async () => {
    setLoading(true);
    try {
      const data = await exampleService.getList();
      setExamples(data);
    } finally {
      setLoading(false);
    }
  };

  return <div>{/* UI 구현 */}</div>;
};
```

3. **라우터 등록**

```tsx
// src/router/index.tsx
```

## 🧪 테스트 작성

### Backend 테스트

```typescript
// example.service.spec.ts
describe("ExampleService", () => {
  let service: ExampleService;
  let repository: Repository<Example>;

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        ExampleService,
        {
          provide: getRepositoryToken(Example),
          useClass: Repository,
        },
      ],
    }).compile();

    service = module.get<ExampleService>(ExampleService);
    repository = module.get<Repository<Example>>(getRepositoryToken(Example));
  });

  it("should create an example", async () => {
    const createDto = { name: "Test" };
    jest.spyOn(repository, "create").mockReturnValue(createDto as any);
    jest
      .spyOn(repository, "save")
      .mockResolvedValue({ id: 1, ...createDto } as any);

    const result = await service.create(createDto);
    expect(result).toHaveProperty("id");
    expect(result.name).toBe("Test");
  });
});
```

## 🎨 코딩 컨벤션

### TypeScript/JavaScript

- 파일명: camelCase (예: `exampleService.ts`)
- 클래스명: PascalCase (예: `ExampleService`)
- 함수/변수명: camelCase (예: `getUserData`)
- 상수: UPPER_SNAKE_CASE (예: `MAX_RETRY_COUNT`)

### React

- 컴포넌트: PascalCase (예: `ExampleComponent`)
- Props 인터페이스: `I{ComponentName}Props`
- Custom Hook: `use`로 시작 (예: `useExample`)

### 폴더 구조

- 도메인별로 폴더 구성
- index.ts(x)로 기본 export
- 관련 파일은 같은 폴더에 위치

## ❓ 자주 묻는 질문

### Q: 새로운 환경 변수를 추가하려면?

A: `.env` 파일에 추가하고, 필요한 경우 타입 정의를 업데이트하세요.

### Q: 마이그레이션은 어떻게 실행하나요?

A: 현재는 TypeORM의 synchronize를 사용중입니다. 프로덕션에서는 마이그레이션 사용을 권장합니다.

### Q: CORS 에러가 발생합니다.

A: Backend의 `main.ts`에서 CORS 설정을 확인하고, 필요한 origin을 추가하세요.

### Q: 차트가 렌더링되지 않습니다.

A: 1) 데이터 형식 확인 2) ECharts 옵션 유효성 확인 3) 컨테이너 크기 확인
