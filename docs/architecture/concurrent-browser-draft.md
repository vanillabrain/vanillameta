# UC026 다른 탭 변경 후 초안 복구 설계

P3/P4·Draft. UC025 보관 기준본과 UC017 세 방향 비교·명시 충돌 선택을 연결한다. 새 API/DB/의존성을 만들지 않는다.

최신 editor 조회와 보관 후보 hydration 후 baseRevision 차이가 있으면 복구 전 안내를 추가한다. 버전 차이와 실제 항목 충돌을 구분하고 기존36px 액션·14px 안내·wrap 토큰을 재사용한다. 복구는 보관 기준본을 editor로, 로컬 내용을 폼으로 유지하고 conflict 잠금을 세운다. 상태 확인은 새 GET으로만 수행한다. 병합 helper는 기준·내 초안·최신본을 비교해 다른 필드 변경을 보존하며 같은 필드는 명시 로컬 선택을 요구한다. 최신 revision 기준 재미리보기 전 저장 불가, 저장 중 재경합은 기존 CAS로409다.

검증: 컴포넌트 remount→복구 전 안내→실패한 GET/재시도→같은필드 명시 선택/비충돌 합치기→최신 revision 미리보기/저장 회귀. 구조 변경은 기존 UC017 회귀를 재사용한다. Ego66 두 탭은 같은 공개 Rill 복사본35를 사용해 대시보드 제목 충돌과 비대상 OS 제목 변경을 실제 저장한다. 첫 탭의 질문/숫자/계산/배치를 보존하고 전체 미리보기→저장→게시→reload를 비교한다. 다른 계정·외부 공개 데이터는 사용하지 않는다. 임시 게시 링크는 종료 전 중지한다.
