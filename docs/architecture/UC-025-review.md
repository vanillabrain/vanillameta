# UC025 범위 리뷰

기준 `c4936ee1`+UC025 변경, 원격 `90ff73a8` 통합을 구분한다. 별도 executor 리뷰는 제공자400으로 미실행이며 Main이 구현 후 별도 diff/명세 패스로 확인했다. 사람 승인/독립 검토로 표기하지 않는다.

- 보관 데이터는 실행 명령·미리보기 결과가 아니며 editor 권한 조회가 먼저다. SHA256 namespace/탭·분석 분리와 로그인·로그아웃 정리는 기존 사용자 저장소를 지우지 않는다.
- 정상 인증 refresh의 별칭 승계는 성공 경로에만 있고 다른 로그인은 승계하지 않는다. 저장소 오류가 인증 갱신을 실패로 바꾸지 않는다.
- hydration 동안 후보 덮어쓰기를 막고 명시 복구 후 preview를 무효화한다. 버전 다름·불명확 저장은 기존 read/CAS 복구에 연결하고 임의 덮어쓰기·자동 게시를 하지 않는다.
- 성공 응답 확인 후 key 제거와 자동보관 중지→navigate 순서를 사용한다. 실패는 보관하며 UI 회귀로 복구/재질문/저장 한 번을 확인했다.
- 손상·만료·크기·판별 타입은 실행 전에 검사하고 정상 폼은 서버 preview 검증을 다시 거친다. 범용 SQL 의미 검증이나 보관 암호화 보장이 아니다.
- Source/Measure/Dimension·서버 DB·게시 계약에는 변경이 없다. 동작/디자인/승인·운영 수용 증거는 구분한다.

남은 gate: 다른 탭 인증 갱신 경합·모든 오류/자연어·물리 휴대폰·운영MySQL/제품 수용. [최종 증빙](../testing/browser-draft-recovery.md)을 따른다.

통합 재검증에서 발견한 두 AI 경계도 별도 대조했다: 표시 기본값 생략을 무변경으로 정규화하는 키합집합 비교, 원 질문에 제목만/이름만을 명시했을 때 생성 결과 제목만 선택 정의에 투영하는 내부 flag다. 생성기의 다른 일반 내용 변경은 유지한다. 보완 전실패/보완후회귀와 실제 재질문 수치 검증을 구분한다.
