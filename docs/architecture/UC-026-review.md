# UC026 범위 리뷰

Draft. Main이 구현·문서 작성 후 별도 diff 대조 패스로 확인했다. 독립 리뷰나 사람 승인이 아니다.

- 복구 전은 같은 source의 revision 차이만 안내하고 실제 필드 충돌을 단정하지 않는다.
- 기존 UC025는 보관 기준본을 유지하고 UC017 읽기 비교까지 AI/preview/save를 잠근다. 명시한 로컬 충돌 항목 외 최신 변경을 유지한다.
- 병합 후 기준 revision 갱신·옛 preview 무효화·CAS 재경합·성공 후 보관 제거는 기존 경로를 사용한다. 새2개 회귀는 재reload/조회 실패/비충돌·같은항목 충돌/재409를 검증한다.
- 새 UI는 기존36px/32px 토큰을 바꾸지 않고 Ego66의390/769/1440 대표 상태에서 넘침0을 확인했다.
- 게시한 것은 공개 Rill 데이터의 로컬 검증 복사본뿐이다. 최종 링크는 중지12/404다.
