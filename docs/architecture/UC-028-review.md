# UC028 범위 리뷰

Draft. 별도 code-reviewer 요청은 제공자400으로 실행되지 않았다. Main이 작성 후 별도 diff·명세 패스로 확인했고 독립 리뷰나 사람 승인으로 표기하지 않는다.

- 공유 메타데이터는 세대/현재 tokenHash/scope이며 본문은 탭별이다. 서버 editor 권한 조회가 복구보다 먼저다. 같은 계정의 동일 토큰 재로그인도 새 세대를 사용한다.
- refresh 시작 토큰·세대를 캡처하고 해시 대기 전후 확인한다. 늦은 성공/실패는 새 인증을 덮거나 로그아웃시키지 않는다. helper에도 expectedEpoch를 전달해 검사와 helper 진입 사이의 세대 교체를 막는다.
- Main 검토에서 갱신 별칭 게시와 토큰 저장 사이에 이전 토큰의 key 계산이 별칭을 덮는 짧은 경합을 발견했다. 이미 바인딩된 hash가 다르면 거절하고 최종 쓰기 전 hash/세대/기존 accessToken 문자열의 변경을 재검사한다. 관련 회귀를 추가했다.
- 기존 별칭의 최초 공유 바인딩, 다른 탭2회 갱신 후 이벤트 없는 복구·동일토큰 새로그인/로그아웃 분리·해시 중 세대 교체·공유 저장 오류의 인증 비차단을 회귀로 확인했다.
- 다른 탭 정상 갱신 후 첫 탭의 미갱신 별칭→실제 reload→기존 scope 복구를 Ego68 최종 여정으로 확인했다. 복구/권한/게시 자동 실행은 없다.

다중 탭 동시 refresh 전역 단일화·모든 오류·실휴대폰·운영/전체 수용은 미확인이다. [검증 기록](../testing/cross-tab-token-draft.md)을 따른다.
