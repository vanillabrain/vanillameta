# Saved creation publication continuation

Status: Draft. [UC037](../use_cases/UC-037-creation-publication.md).

최근 성공 생성 실행을 저장 전/저장 후 대상으로 나눈다. 저장 후 입력창은 엄격한 단독 게시 준비 문구만 처리한다. 긍정 문구면 StudioWorkspace에 저장 영수증 dashboardId/revision을 전달한다. AI 보조 패널을 닫고 기존 상위 StudioPublish를 해당 기준으로 마운트한다. 모바일 Sheet와 게시 Dialog를 중첩하지 않아 폭 전환 때 포커스/클릭을 가로채지 않는다. 새 대시보드 번호와 저장 버전 기준임을 대화/게시 창에 표시한다. 게시 창을 닫고 AI를 다시 열면 최근 실행 영수증에서 대상을 유지하며 reload는 실행 영수증만 복원하고 창은 열지 않는다. 원본 복귀는 기존 명시 버튼이다. 상단 원본 게시 버튼은 새 대시보드 대상을 지우고 원본의 revision/dirty를 사용한다. 서로 다른 게시 대상은 key로 구분한다. 준비 질문은 처리 후 소비하며 패널을 닫을 때의 메모리 대화를 영속 저장하지 않는다.

공개 준비 자체는 읽기만 수행한다. 기존 게시 창은 기본 비공개·명시 공개 범위/게시 버튼·동일 requestId 재시도·409 보호를 유지한다. 이전 영수증의 revision이 낡으면 기존 CAS가 거절하며 최신 revision으로 조용히 교체하지 않는다. 새 대시보드를 열어 확인하도록 링크를 제공한다. 원본의 미저장 편집/선택/필터·onApply/onSaved는 건드리지 않는다.

새 설정 UI·전역 크기 예외·의존성·LLM 분류기를 만들지 않는다. 기존 대화의 32px 보조 버튼과 게시 창의 36px 버튼/입력을 재사용한다. 신규 데이터 미리보기 화면을 추가하지 않으며 저장 때 확인한 생성안과 새 대시보드 열기로 내용을 확인한다. 게시 설정 준비를 집계 snapshot 미리보기와 혼동하지 않는다.
