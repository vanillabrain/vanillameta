# UC024 누락 열의 영향 블록 제외 재사용

TC005 A4/UC005 BR005·FR012를 보완한다. 기존 복제 화면은 열이 빠지면 전체 저장을 차단하지만 필요한 블록을 제외하는 경로가 없다. 기본은 기존처럼 모든 블록을 포함하고 자동 제외하지 않는다.

- 소유/공유/게시 reuse draft에 원본 순서의 블록 ID·제목·필요 열 이름만 추가한다. SQL·결과·원본 소스/인증은 추가 공개하지 않는다. 원래 opt-in/로그인/소스 소유권·버전·중지 경계를 유지한다.
- 사용자가 복제할 블록을 명시 선택한다. 새 소스에 미연결/비호환 열이 있는 선택 블록을 이름과 필드로 표시한다. 제외한 블록 때문에 불필요한 열을 요구하지 않는다. 최소1개, 유효한 원본 ID·중복 없음. 요청 순서로 원본 순서를 바꾸지 않는다.
- preview의 선택적 blockIds를 서버에서 검증한 뒤 선택 widgets만 remap·실계산한다. 생략하면 기존 전체 동작을 유지한다. columnMap은 선택 블록에 필요한 열과 정확히 일치해야 한다. 임의 SQL/레이아웃 입력은 받지 않는다.
- 새 ID와 선택한 원본의 각 폭 좌표를 보존한다. 레거시 layoutSizes도 같은 원본 인덱스로 투영해 차트 개수와 일치시킨다. 빈 공간은 자동 압축하지 않는다. 전체 미리보기의 제외 개수와 포함 결과를 확인한 후 기존 ticket/requestId 원자 저장·재시도를 사용한다.
- 선택/소스/연결/제목 변경은 기존 preview/ticket을 무효화한다. 저장 결과 불명확 동안 선택을 바꾸지 않는다. 제외는 복사본에만 적용되며 원본/기존 게시 버전은 변하지 않는다. 새 DB/의존성 없음.

종료: BE 소유/수신자 선택·빈/타 ID/중복·원본 순서/배치/원자 저장·권한, FE 제외/복원/ticket 무효화, Ego 누락 소스→영향 확인→블록 제외→미리보기→저장/reload·390/768/1440 대표 UI. 공개된 원본을 사용할 때는 공개 Rill 검증 fixture만 임시 게시하고 마지막에 중지한다. 운영/실기기·사람 수용은 별도다.
